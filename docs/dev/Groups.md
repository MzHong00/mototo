## 0단계 기반

| 그룹 | 맡는 일 |
| --- | --- |
| 하루 설계 | 24분 하루에 하는 일, 하루 → 1년 성장 변환. 매년 하루가 달라야 함 (지루함 위험) |

## 1단계

| 그룹 | 맡는 일 |
| --- | --- |
| 인생 규칙 | 능력치·상태·성격 특성·병·죽음·노숙·자녀·병역·세금·연금·은퇴·업적·리포트 |
| 직업 조사 | 32개 실제 연봉·학력·자격 |
| 진로 설계 | 학교·수능·대학·자격증 → 직업 조건 |
| 지도 변환 도구 | OSM → 2m 칸 지도 (역 1개부터) |
| 캐릭터·동작 | 아기·노년·얼굴 단계, 생활 동작 (오래 걸려 따로 계속) |
| 화면 흐름 | 화면 스케치 (카드 길이·선택지 수 결정) |
| 대화 서버 | AI 대화 프록시·비용 제한 |
| 대표 한 판 | 역 1, 직업 3, 0~30살 끝까지 |

## 2단계

| 그룹 | 맡는 일 |
| --- | --- |
| 경제 | 생활비·월세·전세·매매·주식·대출 |
| 이벤트 | 나이대 4묶음 카드 (0~6은 튜토리얼 겸함) |
| 사람 | AI 주민 대화·호감도·관계 |
| 행인·길찾기 | 칸 지도 위 걸어다니기 |
| 행동·미니게임 | 일상·직업 행동, 틀 6~8개에 데이터만 바꿈 |
| 장소·건물 기능 | 역마다 학교·병원·회사·집·가게 배치, 실내 여부 |

## 3단계

51역 배치 · 도시 부품(OSM 건물 윤곽 + 우리 그림체) · 화면 구현 · 화면 연결 · 낮밤·날씨 · 소리 · 성능 예산

## 계속

권리 검사(OSM·상표·라이선스) · 밸런스

## MVP

역 2~3, 직업 6~8, 카드 50~80. 미룸: 주식·AI 대화·미니게임 대부분(자동 근무)
