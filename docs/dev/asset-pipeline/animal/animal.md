# 동물 만들기

> 사육 동물 1종 (강아지·고양이·소 등). 모양은 **AI로**, 움직임은 리깅. 결과: `web/creatures/ani_<이름>.glb` ⬜ 아직 해 본 적 없음.

## 1. 사용자에게 물을 것

- 무엇? (예: 시바견, 젖소) + 참고 그림

## 2. 컨셉 이미지 → 3D

[이미지→3D 1·2](../index.md#이미지--3d-ai로-모양-만들-때만). `<대상>` = `shiba dog, standing on four legs, side view` 처럼.

## 3. 정리 (Claude)

`fix_orient.py` → `finalize.py` (2만 면 이하)

## 4. 리깅 + 동작 (Claude)

- Blender Rigify 네발 리그 **1개를 표준**으로 → 동물마다 메시만 바꿔 끼움 (동작 재사용)
- 첫 동물 때 표준 리그를 만든다
- 동작: 서기 · 걷기 · 앉기 · 반응(기뻐함) · 자기

## 5. 확인 → 마무리

동작 렌더를 보여주고 OK 받기 → 게임 폴더로 복사
