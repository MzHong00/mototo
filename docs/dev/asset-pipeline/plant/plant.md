# 식물 만들기

> 나무·꽃·풀·바위 같은 자연물 1개. 모양은 **CC0 무료 팩**에서 가져온다. 결과: `public/world/plant_<이름>.glb` ⬜ 계획만.

## 1. 사용자에게 물을 것

- 무엇? (예: 참나무, 해바라기, 덤불)

## 2. 재료 찾기 (Claude)

- CC0 팩 Kenney · Quaternius · KayKit 에서 찾아 받는다
- 없으면 [이미지→3D 1·2](../index.md#이미지--3d-ai로-모양-만들-때만)
- 후보 그림을 보여주고 고르게 한다

## 3. 우리 톤으로 바꾸기 (Claude)

- 파스텔 색, 외곽선, 크기 (1칸 = 1m) — 변환 스크립트는 첫 작업 때 만든다
- 채집 대상이면 다 자란 모양·베인 모양 2개
- 지금 맵의 나무·꽃은 코드 도형(`src/features/world/constants/mapObjects.ts`) — 에셋이 생기면 교체

## 4. 확인 → 마무리

렌더 보여주고 OK → 게임 폴더로 복사, 출처를 `CREDITS`에 기록
