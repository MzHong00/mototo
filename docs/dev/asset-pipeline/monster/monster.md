# 몬스터 만들기

> 몬스터 1종 (일반·엘리트·보스). 모양은 **AI로**, 움직임은 리깅. 결과: `web/creatures/mon_<이름>.glb` ⬜ 아직 해 본 적 없음 — 첫 작업(슬라임) 때 이 문서를 고친다.

## 1. 사용자에게 물을 것

- 무엇? (예: 초록 슬라임, 버섯 몬스터) + 참고 그림
- 일반 / 엘리트 / 보스 (보스는 크기·장식만 키움)

## 2. 컨셉 이미지 → 3D

[이미지→3D 1·2](../index.md#이미지--3d-ai로-모양-만들-때만). `<대상>` = `round slime monster, neutral standing pose, all limbs separated` 처럼.

## 3. 정리 (Claude)

`fix_orient.py` → `finalize.py` (2만 면 이하)

## 4. 리깅 + 동작 (Claude)

| 모양 | 방법 |
| --- | --- |
| 둥근 몬스터 (슬라임·버섯) | 뼈 2~4개 직접 + 통통 튀는 동작 직접 |
| 네발 몬스터 | 동물과 같은 표준 네발 리그 ([animal.md](../animal/animal.md)) |
| 사람형 몬스터 | 우리 몸 뼈 재사용 + Mixamo 동작 |

동작 5개: 서기 · 이동 · 공격 · 맞기 · 쓰러짐

## 5. 확인 → 마무리

동작 5개 렌더를 보여주고 OK 받기 → 게임 폴더로 복사
