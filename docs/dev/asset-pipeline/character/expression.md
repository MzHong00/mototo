# 표정

> 잠깐 바뀌는 감정. 모든 얼굴 외형이 같이 씀. 지금은 F1~F4로 재생(임시)

- 있는 것: 놀람 · 크게 웃음 · 귀여움 · 피곤
- 규칙: 볼터치 없음

## 순서

1. 사용자: 제미나이에 [base_body.png](../reference/base_body.png) 첨부 + 아래 프롬프트 보내기 → 받은 그림을 Claude에게 주기
2. Claude: 그림을 `refs/expr_sheet.png`에 저장 → `face_from_sheet.py refs/expr_sheet.png out/expr --single`
3. Claude: `face_preview.py`로 렌더 → 사용자 OK
4. Claude: `out/expr/expr_<id>.png`로 이름 붙임 → `face_export.py` → `EXPRESSION_CATALOG`에 추가 → `sync_game.sh`

## 프롬프트

```
첨부한 치비 기본 캐릭터를 정확한 기준으로 삼아 표정 스프라이트 시트 한 장을 만들어 줘.

[배치]
- 가로 3칸 × 세로 3줄, 같은 크기의 정사각형 칸 9개. 순서는 왼쪽 위부터 오른쪽으로, 줄 바꿔 아래로.

[모든 칸 공통]
- 기준 이미지와 같은 대머리 둥근 머리, 완전 정면, 칸 가운데, 모든 칸에서 같은 크기·같은 위치(칸의 약 80%).
- 같은 피부색(#F6C9B0), 같은 부드러운 3D 장난감 같은 렌더 느낌, 강한 그림자 없는 고른 조명.
- 연회색 단색 배경. 머리카락·장신구·글자·숫자·칸 구분선 없음.
- 귀여운 한국 캐주얼 MMORPG 치비 스타일. 기본 눈은 기준 이미지와 같은 크고 동그란 갈색 눈.
- 감정은 눈·눈썹·입·작은 만화 기호(땀방울, 눈물)로만 표현. 볼터치 없음. 머리 모양은 그대로.

[표정 9가지]
1. 기쁨 — 부드럽게 웃는 눈, 미소
2. 슬픔 — 처진 눈썹, 눈물 맺힌 눈, 삐죽한 입
3. 화남 — 찌푸린 눈썹, 뾰로통한 입
4. 당황 — 동그래진 눈, 이마에 땀방울, 물결 입
5. 부끄러움 — 살짝 내리깐 눈, 작은 입 (볼터치 없이)
6. 윙크 — 한쪽 눈 감기, 미소
7. 아픔 — 질끈 감은 눈(><), 꽉 다문 입
8. 졸림 — 거의 감긴 눈, 하품하는 입
9. 뿌듯함 — 눈 감고 웃는 입, 살짝 올라간 눈썹
```
