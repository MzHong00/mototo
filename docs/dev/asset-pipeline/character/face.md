# 얼굴 외형

> 눈·눈썹 모양. 꾸미기에서 고름. 몸 텍스처에 그리는 그림. 감정은 [expression.md](expression.md)

- 있는 것: `look_1~5` 동그란 눈 · 졸린 눈 · 날카로운 눈 · 순한 눈 · 굵은 눈썹
- 입: 모두 무표정 (입은 표정 담당)
- 볼터치: 없음 (따로 고름)

## 순서

1. 사용자: 제미나이에 [base_body.png](../reference/base_body.png) 첨부 + 아래 프롬프트 보내기 → 받은 그림을 Claude에게 주기
2. Claude: 그림을 `refs/faces_sheet.png`에 저장 → `face_from_sheet.py refs/faces_sheet.png out/faces` (입 다르면 `--mouth-from 대상:원본`)
3. Claude: `face_preview.py`로 렌더 → 사용자 OK
4. Claude: `out/look/`에 복사 → `face_export.py` → `face_iris_mask.py`(눈 색 마스크) → `FACE_CATALOG`에 추가 → `sync_game.sh`

## 프롬프트

```
첨부한 치비 기본 캐릭터를 정확한 기준으로 삼아 얼굴 스프라이트 시트 한 장을 만들어 줘.

[배치]
- 가로 6칸 × 세로 3줄, 같은 크기의 정사각형 칸 18개.
- 칸 두 개가 한 쌍: 왼쪽 칸은 눈 뜬 얼굴, 바로 오른쪽 칸은 같은 얼굴의 눈 감은 얼굴(깜빡임용, 부드럽게 휜 속눈썹 선).
- 한 줄에 3쌍, 총 9쌍. 순서는 왼쪽 위부터 오른쪽으로, 줄 바꿔 아래로.

[모든 칸 공통]
- 기준 이미지와 같은 대머리 둥근 머리, 완전 정면, 칸 가운데, 모든 칸에서 같은 크기·같은 위치(칸의 약 80%).
- 같은 피부색(#F6C9B0), 같은 부드러운 3D 장난감 같은 렌더 느낌, 강한 그림자 없는 고른 조명.
- 연회색 단색 배경. 머리카락·장신구·글자·숫자·칸 구분선 없음.
- 귀여운 한국 캐주얼 MMORPG 치비 스타일, 큰 애니메이션 눈, 작은 코.

[얼굴 9가지 — 눈·눈썹만 다르게. 입은 모두 똑같은 작은 무표정 입, 감정 표현 없이 차분하게]
1. 크고 동그란 반짝이는 눈
2. 졸린 듯 반쯤 감긴 눈
3. 날카롭게 올라간 눈
4. 처진 순한 눈
5. 가늘고 긴 눈, 얇은 눈썹
6. 작고 동그란 눈, 짧은 눈썹
7. 굵고 곧은 눈썹, 또렷한 눈
8. 긴 속눈썹, 반짝이는 눈
9. 다크서클이 살짝 있는 피곤한 눈
```
