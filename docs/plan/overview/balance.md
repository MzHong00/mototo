# 밸런스 목표

> 인생 1만 번을 자동으로 돌렸을 때 나와야 할 분포. 현실보다 조금 극적으로. 자동 시뮬 검사의 합격 기준. 상태 🟡

## 규칙

- 검사 = 봇 4종 × 2,500인생 = 1만 인생, 결과가 아래 범위 안이면 합격
- 계층은 **65살 시점 가구 순자산**으로 나눔 (집·저축·주식 − 빚)
- 노숙은 "인생 중 1번이라도 노숙" 비율
- 현실 값은 참고, 게임 목표는 재미 위해 양 끝을 조금 넓힘

| 봇 | 행동 |
| --- | --- |
| 무작위 | 행동·카드 무작위 |
| 게으름 | 자유 블록 놀기, 의무 블록 자동 |
| 공부형 | 공부·자격 우선, 안정 직업 |
| 돈형 | 근무·저축·투자·사업 우선 |

## 수치·데이터

| --- | --- | --- |

| 그중 100억+ (업적) | 1% 미만 | 1~2% |

| --- | --- | --- |
| 평균 수명 (전체 봇) | 83.7살 | 80~85살 |
| 건강 관리 잘한 인생 (건강 지수 상위 20%) | — | 평균 95살+, 100~105살 50%+ |
| 건강 관리 못한 인생 (하위 20%) | — | 평균 70살 이하 |
| 50살 전 사망 | — | 3~5% (사고·병) |
| 100살 도달 (전체) | 1% 미만 | 10~15% (업적) |

| 직업 분포 | 목표 |
| --- | --- |
| 한 직업 최대 비율 | 25% 이하 (MVP 6~8개 기준) |

| 무직 기간 1년+ | 20~30% |

| 난이도 (봇별) | 게임 목표 |
| --- | --- |
| 게으름 봇 부자 비율 | 5% 이하 (운·유산으로만) |
| 공부형·돈형 봇 부자 비율 | 20~30% |
| 부모 재력 상위 vs 하위 부자 비율 차 | 2~3배 (현실감, 역전 가능) |
| 하위 재력 → 부자 | 5% 이상 |
| 능력치 하나 90+ 도달 | 집중한 인생 50%+ |

## 열린 질문

1. 노숙 경험 3~5% (현실 수십 배) — 제안: 유지. "노숙자에서 재기" 업적이 가능하려면 필요
2. 계층 기준 시점 — 제안: 65살 순자산. 죽을 때는 상속·지출로 흔들림
3. 부모 재력 영향 2~3배 — 제안: 유지. 노력으로 역전 가능한 정도
