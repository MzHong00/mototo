# 시대

> 세계는 **2026년 서울에 멈춰 있다.** 내 나이만 흐르고 물가·기술·제도는 100년 동안 그대로. 상태 ✅ (사용자 확정: 2026-03-01 출생, 2026 물가·제도 고정)

## 규칙

- 모든 인생은 2026년 3월 1일에 태어남. 화면 날짜는 "N살 M월" 위주, 연도는 리포트에만(2026 + 나이)
- **물가·연봉·집값 기준 = 2026년 실제 값**, 물가 상승률 0%
- 대신 **변동은 있음**: 경기(호황·불황)·집값·주가는 기준값 주변을 오르내림 (평균 회귀, 장기 추세 0)
- 기술(휴대폰·지하철·가전)·직업 목록·법·제도(병역·정년·연금)도 2026년 그대로
- 내가 늙는 건 "주변 사람의 세대 교체"로 표현: 부모·조부모가 늙고 죽음, 친구가 늙음, 새 주민은 어린 얼굴
