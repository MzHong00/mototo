# 하루 구조

> 하루 = 그해의 대표 하루. 시간을 어디에 쓰는지가 1년 성장이 되고, 매년 "올해의 주제"가 하루를 바꾼다. 상태 🟡

## 규칙

- 하루는 **블록 5개**(아침·오전·점심·오후·저녁) + 밤. 시간표 → [time.md](time.md)
- 오전·오후 = **의무 블록**(학교·근무). 들어가면 고름: 자동(보통 결과) / 미니게임(잘하면 ×1.5) / 땡땡이(평판 −)
- 아침·점심·저녁 = **자유 블록**. 동네를 걸어 다니며 행동 1~3개(학원·운동·데이트·쇼핑·알바)
- **0~12살은 "카드로 1년 넘기기" 선택 가능**(확정): 그해 카드 3~5장 골라 능력치를 받고 바로 다음 해로. 결과는 3D로 보낸 해의 평범한 수준(같은 공식, 행동 시간 대신 카드 보상). 3D로 직접 보내도 됨
- 하루 동안 한 행동 시간을 모아 **1년 성장으로 변환**. 생일(06:00)에 "올해 결과" 화면
- 하루 = 1년이므로 같은 행동을 오래 = 그해 습관. 행동마다 하루 상한(같은 행동 4시간 넘으면 효과 절반)

### 1년 변환 (요약)

- 행동한 시간만큼 능력치가 오르고, 높을수록·나이 들수록 덜 오르며, 40살부터 노화로 줄어듦
- 공식·나이 상한·노화 표 → [life/stats.md](../life/stats.md) (유일한 기준)
- 근무 블록: 연봉 1년치 지급 + 직업 경험 +1년 (승진 조건)
- 상태(배고픔·기분)는 하루 안에서 실시간, 건강·평판은 1년 결과로 반영

## 수치·데이터

- 목표: 한 능력치를 열심히 올리면 1년 +4~8, 100 도달은 20년 이상 집중 (검사 기준 → [balance.md](balance.md))

### 매년 하루가 달라지는 장치 (지루함 방지)

| 장치 | 내용 | 빈도 |
| --- | --- | --- |
| 올해의 주제 | 나이·상황으로 1개: 입학·수능·첫 연애·취업·이사·결혼·출산·승진·병·은퇴. 그날 목표 3개와 카드가 바뀜 | 매년 |
| 올해 카드 | 아침에 1~2장, 블록 사이에 1장. 같은 카드 인생 1회 원칙 | 매년 3~5장 |
| 인생 단계 전환 | 학교→대학→직장→은퇴로 의무 블록·장소·주변 사람이 바뀜 | 5~15년마다 |
| 장소 변화 | 이사·이직으로 다른 역(맵)에서 하루 | 인생 4~8회 |
| 사람 변화 | 친구·동료·가족이 늙고 바뀜, 자녀가 자람 | 매년 조금 |
| 경기·사건 | 호황·불황, 집값 급등 등 세계 사건 | 3~5년마다 |
| 카드로 넘기기 | 0~12살은 언제든 카드 몇 장으로 1년 넘김 | 선택 |
| 빠른 해 | 13살 이후 주제가 "평범"인 해는 "자동으로 보내기"(실제 30초, 결과는 자동 근무 수준) | 선택 |

- 주제 고르는 순서: 정해진 나이 이벤트 > 내 인생 목표 > 무작위(운). 같은 주제 2년 연속 금지(입시·수련 제외)

## 열린 질문

1. "자동으로 보내기"를 넣을지 — 제안: 넣음. 단 결과는 직접 한 해보다 낮게(×0.8)
2. 의무 블록 안 시간 — 제안: 건물에 들어가면 근무 장면 + 휴대폰 사용 가능, "빨리 감기"(×8, 4시간 = 실제 30초) 버튼. 인생 길이는 그만큼 짧아짐
3. 같은 행동 상한 4시간 — 제안: 4시간. 한 가지만 파는 인생도 가능하되 효율 손해
