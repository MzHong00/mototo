# 원칙

> 실제 서울, 가상 상호. 무료 에셋, AI는 아껴서, 아픈 주제는 담담하게. 상태 🟡

## 규칙

### 권리
- 실제 쓰는 것: 지명·구·역 이름·노선 색·지하철 요금·공공기관 종류(구청·주민센터)
- 안 쓰는 것: 상호·브랜드·회사·학교·병원 실명, 실제 인물, 로고·간판 글꼴
- 가상 이름은 규칙으로 만듦: 지명+업종("신촌 분식"), 가상 회사("한별전자")
- 이름이 우연히 실제 상호와 겹치면 바꿈 (출시 전 검색 검사)
- 대학은 실명 대신 등급("최상위 국립대")으로

### 라이선스
| 대상 | 규칙 |
| --- | --- |
| 지도 | OpenStreetMap, 화면에 "© OpenStreetMap contributors". 변환 지도 파일은 ODbL로 공개 |
| 3D·소리·글꼴 에셋 | CC0만. 예외: Mixamo 동작(약관 범위) |
| 구글 3D 지도·위성 사진 | 안 씀 |
| 기록 | 루트 `CREDITS.md`에 출처 전부 |
| AI 생성 에셋 | 도구 약관이 상업 이용·한국 허용인지 확인 후 사용 |

### AI 비용
- AI 대화는 **중요한 순간만**: 고백·청혼·이별·장례·부모와 마지막 대화·면접 등
- 평소 대화 = 정해진 대사(상황 태그로 고름)
- AI 실패·한도 초과 → 정해진 대사로 대체 (게임 진행 막지 않음)

### 표현
- 범죄 직업·도박 없음. 주식은 가상 회사
- 병·죽음·가난·노숙은 담담하게, 놀림 없이. 자살·자해는 다루지 않음
- 연애(확정): 성인(19살~)은 연애·스킨십·동침·임신 모두 있음. 노골적 장면 없이 암시 연출(화면 가림·암전). 미성년은 손잡기·포옹까지
- 연애·결혼 상대 성별은 자유, 효과 같음
- 차별 금지: 외모·성별·직업으로 비웃는 대사 없음. 외모 점수는 숫자로 안 보임(매력만)
- 연령 등급: **15세 이용가**(확정)

## 수치·데이터

| 항목 | 제안값 |
| --- | --- |
| AI 대화 | 한 인생 장면 최대 30회 × 장면당 10턴 = 300턴. 넘으면 정해진 대사 |
| 한 인생 AI 비용 | 100원 이하 (저가 모델, 짧은 문맥) |
| 기억 요약 | 사람마다 300자, 큰 사건 때만 갱신 |
| 입력 | 자유 입력 80자 + 선택지 3개 |
