# 시간

> 60배, 게임 하루 24분 = 1살. 하루 시계의 2시간 = 1달, 잠은 겨울 달을 건너뛴다. 상태 🟡

## 규칙

- 기본 배율 60배: 실제 1초 = 게임 1분. 하루(24게임시간) = 실제 24분 = 1년
- **하루 시작 06:00 = 3월 1일 = 생일(나이 +1)**. 학년 시작과 맞춤
- 게임 2시간 = 1달. 달이 바뀔 때 월 정산(월세·이자·주식·월급) 1번
- 낮(06~22시) = 3~10월, 밤(22~06시) = 11~2월. 밤 = 겨울이라 하늘·옷이 겨울로
- 0~6살: 06~18시만 깨어 있음, 게임 1시간 = 1달, **실제 12분 = 1살**
- 잠: 22시 이후 침대 → 다음 날 06:00로 건너뜀. 건너뛴 달은 한 번에 정산 후 "겨울 요약" 카드 1장
- 22시~02시 안 자면: 기분 −, 건강 −. 02시 넘으면 강제 잠(쓰러짐, 건강 −5)
- 접속 안 하면 멈춤. 탭이 가려지면(visibility hidden) 자동 일시정지
- 일시정지: Esc·메뉴·카드·대화 화면 열리면 멈춤. 3D 걷기·근무 장면에서만 시간이 흐름
- **걷는 동안도 항상 60배 그대로**(확정). 순간이동·시계 늦추기 없음. 걸어서 400m ≈ 게임 100분이 정상, 멀리는 지하철
- **0~12살 "카드로 1년 넘기기"**(확정): 아침에 3D로 보낼지, 카드 몇 장 고르고 바로 다음 해로 갈지 고름. 0~6살 기어다니기도 넘길 수 있음 → [day.md](day.md)
- 정해진 나이 이벤트(입학·수능·입사·정년)는 그 달 진입 때 카드로. 잠 중이면 아침 첫 카드

## 수치·데이터

| 항목 | 값 |
| --- | --- |
| 1달 | 게임 2시간 = 실제 2분 (0~6살은 1분) |
| 하루 실제 길이 | 최대 24분, 잠으로 겨울 건너뛰면 약 16분 |
| 한 인생 (보통) | 0~6살 7년×12분 + 7~105살 99년×16~24분 ≈ **28~41시간** (최대 105살. 카드 넘기기·빨리 감기·자동 해 쓰면 더 짧음) |
| 카드로 1년 넘기기 | 1년 ≈ 실제 1~2분 (0~12살만) |

| 하루 시간표 (7살~) | 게임 시각 | 달 | 주로 하는 일 |
| --- | --- | --- | --- |
| 아침 | 06~08 | 3월 | 씻기·먹기·올해 카드 |
| 오전 | 08~12 | 4~5월 | 학교·근무 블록 1 |
| 점심 | 12~14 | 6월 | 먹기·사람 만나기 |
| 오후 | 14~18 | 7~8월 | 학교·근무 블록 2 |
| 저녁 | 18~22 | 9~10월 | 자유 시간(학원·운동·취미·데이트) |
| 밤 | 22~06 | 11~2월 | 잠(건너뛰기) 또는 야근·공부 |

| 배속 설정 | 실제 분 / 1년 | 배율 | 한 인생(대략) |
| --- | --- | --- | --- |
| 빠름 | 12 | 120배 | 14~21시간 |
| 보통(기본) | 24 | 60배 | 28~41시간 |
| 느림 | 48 | 30배 | 56~82시간 |

- 배속은 인생 중 언제든 바꿈. 리포트에 "주로 쓴 배속" 기록(비교용)
