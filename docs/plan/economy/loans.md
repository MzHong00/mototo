# 대출·저축

> 은행 1곳(가상)에서 대출 4종·저축 3종. 이자는 게임 1달마다 붙고, 못 갚으면 연체 → 신용불량 → 파산. 상태 🟡

## 규칙
- 은행 건물 또는 휴대폰 은행 앱. 19살~ (학자금은 대학 입학 때)
- **신용점수 0~1000**: 시작 700. 연체 1달 −50, 제때 갚기 1년 +10, 소득·재산 있으면 +. 대출 금리·한도에 반영
- 이자는 매달 정산([income.md](income.md))에 포함. 원리금 균등상환 기본
- 상환 공식: `월 상환 = 원금 × r(1+r)^n ÷ ((1+r)^n − 1)`, r = 연금리÷12, n = 개월
- **연체 단계**
  1. 1달: 경고 알림, 신용 −50
  2. 3달: 신용불량. 새 대출 불가, 평판 −10, 기분 −10
  3. 6달: 압류(예금 → 주식 → 집 순서로 강제 상환)
- **파산(개인파산)**: 부채 > 자산이고 신용불량일 때 신청 가능. 빚 전부 탕감, 주식·집·저축 모두 처분, 5년 대출 금지, 평판 −20. 리포트에 기록 → [life/homeless](../life/homeless.md)로 연결 (65살~는 기초연금으로 노숙 안 됨)
- 저축 이자에는 15.4% 이자소득세

## 수치·데이터

**대출 (2026 기준, 기준금리 2.5~3% 시기)**

| 종류 | 한도 | 금리(연) | 기간 |
| --- | --- | --- | --- |
| 신용대출 | 연봉 × 1 (최대 1.5억), 무소득 300만 | 신용 900↑ 4.5% / 700 5.5% / 500 9% | 5년 |
| 주택담보대출 | 집값 × 40%(생애 첫 집 70%), **최대 6억**, 월 상환 ≤ 월급 40% | 4.0% | 30년 |
| 전세대출 | 보증금 × 80%, 최대 2억 | 3.5% | 계약 기간, 이자만 |
| 학자금대출 | 등록금 전액 + 생활비 연 350만 | 1.7% | 취업 후 상환 |

- 학자금: 졸업 후 연봉 2,600만 넘으면 초과분의 20%를 매년 상환. 못 갚아도 연체 아님
- 사업자 대출은 [business.md](business.md)
- 예: 주담대 4억, 30년, 4% → 월 약 191만

**저축**

| 종류 | 금리(연) | 규칙 |
| --- | --- | --- |
| 입출금 통장 | 0.1% | 잔고 자동 |
| 정기예금 | 2.8% | 1년 묶음, 중도 해지 시 1% |
| 적금 | 3.3% | 매달 정액 넣기, 1~3년, 중도 해지 시 1% |
| 청년 적금 | 5%(정부 보탬 포함) | 19~34살, 월 최대 70만, 5년 |

- 금리는 경기 따라 ±1%p([cycle.md](cycle.md))
