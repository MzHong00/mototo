# 세금·보험·연금

> 월급에서 "4대보험 + 소득세"를 표 한 장으로 떼고, 65살부터 연금을 받는다. 실제 세법을 게임용으로 단순화. 상태 🟡
> **국민연금 공식의 기준 문서.** career/retirement 등은 이 공식을 링크만 한다

## 규칙
- 매달 정산 때 자동 공제. 연말정산·환급 없음(이미 반영된 실효세율 사용)
- **공제액 = 4대보험(9.7%) + 소득세 실효세율(연봉 구간표)**. 지방소득세 포함
- 국민연금 부분은 월 최대 30만 원(소득 상한 반영)
- 사장·프리랜서: 순이익에 같은 세율 + 지역보험 15%(연금+건강 전액 본인)
- 부동산: 살 때 취득세, 매년 재산세. 주식: 팔 때 0.2%만([stocks.md](stocks.md))
- **국민연금**: 일한 해마다 "가입 1년" 쌓임. 10년 이상이면 65살부터 매달 받음. 10년 미만은 65살에 낸 돈 일시금
- **기초연금**: 65살~, 재산 + 연소득×5 < 5억이면 월 35만(부부 56만)
- **실업급여**: 해고·계약 만료 시(자진 퇴사 X), 고용보험 1년 이상 → 월급 60%(월 최소 198만·최대 204만), 4~9달(나이·가입연수)

## 수치·데이터

**연봉별 공제 (2026 요율 기준)**

| 세전 연봉 | 소득세 실효 | 4대보험 | 총 공제 | 월 실수령 |
| --- | --- | --- | --- | --- |
| 2,600만(최저임금) | 1% | 9.7% | 10.7% | 193만 |
| 3,000만 | 1.5% | 9.7% | 11.2% | 222만 |
| 5,000만 | 5% | 9.7% | 14.7% | 355만 |
| 7,000만 | 8% | 9.7% | 17.7% | 480만 |
| 1억 | 12% | 9% | 21% | 658만 |
| 2억 | 22% | 7% | 29% | 1,183만 |
| 5억 이상 | 35% | 5% | 40% | — |

- 구간 사이는 직선 보간. 근거 세율(과세표준): 6%(~1,400만)·15%·24%(~8,800만)·35%(~1.5억)·38%·40%·42%·45%(10억 초과)
- 4대보험 근로자분(2026): 국민연금 4.75% + 건강 3.595% + 장기요양 약 0.47% + 고용 0.9%

**연금**

| 항목 | 값 |
| --- | --- |
| 받는 나이 | 65살 (일찍 받기 60살~ 1년당 −6%, 늦게 받기 ~70살 1년당 +7.2%) |
| 월 연금 | (310만 + 내 평균 월급[상한 637만]) ÷ 2 × 1.075% × 가입연수 |
| 예: 평균 월급 300만 × 30년 | 약 98만/월 |
| 실제 평균(참고) | 노령연금 월 약 68~70만 |

**기타 세금**

| 세금 | 게임 값 |
| --- | --- |
| 취득세 | 집값 6억 이하 1%, 9억 이하 2%, 초과 3% |
| 재산세 | 매년 집값의 0.2% (1월 정산) |
| 이자소득세 | 이자의 15.4% |
| 상속세 | (유산 − 10억) × 30% (자녀가 받을 때) |
