# 게임 기획 (v2)

> **서울에서 치비로 한 번의 인생(0~최대 105살)을 사는 브라우저 3D 게임.** 1인용.
> 인생이 끝나면 인생 리포트와 업적이 남는다.

## 핵심 루프

태어남(부모 직업 2개 고름) → 어린 시절 이벤트로 능력치가 쌓임 → 학교·진로 → 직업·돈·연애·친구 → 늙음 → 죽음 → 인생 리포트 + 업적

## 시간

| 항목 | 값 |
| --- | --- |
| 기본 배율 | 60배 (실제 1초 = 게임 1분, 게임 하루 = 실제 24분) |
| 나이 | **게임 하루 = 1살.** 0~6살은 반나절 = 1살 |
| 한 인생 | 약 40시간 (설정: 빠름 12분 · 보통 24분 · 느림 48분 / 1년) |
| 접속 안 할 때 | 시간 멈춤 |
| 잠 | 밤에 자면 아침으로 건너뜀 |
| 걷기 | 걸어도 시간은 그대로 60배 (400m ≈ 게임 100분). 멀리는 지하철 |
| 어린 시절 | 0~12살은 "카드로 1년 넘기기" 선택 가능 (카드 고르고 능력치 받고 다음 해) |
| 시대 | 모두 2026-03-01 출생, 2026 물가·제도 고정 |
| 돈 | 실제 금액 그대로 (연봉 3,200만 원 = 하루 근무 수입 합). 100억 같은 업적이 현실 감각과 맞음 |
| 하루 | 그해의 대표 하루. 학교·회사 하루 = 1년 다님. 시험·입사·결혼은 정해진 나이에 이벤트 |
| 1달 | 실제 2분. 주식·월세가 이 단위로 움직임 |

- 실제 시간과 같게 하면 100년 = 100년, 24배여도 4년이 걸려서 버렸다.

## 캐릭터

- 모습 3단계: **아기**(0~6살, 모두 같은 얼굴, 기저귀만 바꿈) → **지금 몸**(7살~) → **노년**(65살~, 주름·흰머리만 추가)
- 0~6살: 카드 선택지 + **집 안에서 기어다니기**(3D). 7살부터 동네를 돌아다님
- **외모**: 부모 외모(못생김~예쁨)를 고르면 7살 때 얼굴 생김새가 정해짐 → 매력 시작값. 머리·옷은 자유. 성형외과로 바꿀 수 있음(돈)
- 능력치: 지능 · 힘 · 체력 · 매력 · 손재주 · 감성. 어릴 때 이벤트·학교·습관으로 쌓임
- 상태: 배고픔 · 건강(병) · 기분(스트레스) · 돈 · 평판
- 연예인·유튜버 직업일 때만 **팬 수**
- 수명은 건강 지수로 정해짐 (성별 차이 없음, 최대 105살). 병·사고로 일찍 죽을 수 있음 (드물게)
- 남성은 20~30살 사이 군대 필수 (군부대 맵 1개)

## 부모

- 부모 직업 2개를 고름 → **집안 재력**(용돈·학원·유산)이 정해짐
- 부모 직업은 능력치 시작값에도 조금 영향 (예: 운동선수 부모 → 힘 +)
- **집 위치**: 재력에 맞는 동네(역) 중 무작위. 집 종류도 재력 따라 (원룸·빌라·아파트·고급 아파트)

## 직업

- 범죄 직업·도박은 없음
- 실제 직업 **32개**부터 (웹 조사로 고름: 광부·요리사·의사 등)
- 해금 없음. 모든 직업에 갈 수 있지만 **실제 인생 같은 조건**이 있음
  - 예: 의사 = 지능 → 의대 합격 → 6년 → 국가고시 → 수련
- 근무: 직업마다 짧은 미니게임 + "자동 근무" 선택
- 망하면 노숙자가 될 수 있고, 다시 일어설 길도 있음

## 사람

- 배우자·친구·동료 = AI 주민 (LLM 대화 + 호감도)
- 연애 상대 성별 자유. 성인 연애·동침·임신은 암시 연출, 미성년은 손잡기·포옹까지. 연령 등급 15세
- 결혼·자녀 있음. 자녀로 이어 하기는 없음

## 돈

- 일·저축·대출
- **부동산**: 부모 집에서 시작. 재력에 따라 월세·전세·매매. 집값이 오르내림
- **주식**: 아주 단순하게. 가상 회사, 게임 1달마다 오르내림
- 옷은 가게에서 삼. 비싼 옷은 매력 조금 +

## 인생이 끝나면

- **인생 리포트** 한 장: 직업 이력, 재산, 가족·친구, 주요 사건
- **업적**: 의사 되기, 100억 부자, 팬 1억 명, 노숙자에서 재기 등. 다음 인생에 해금은 없음

## 세계 (서울)

- 묶음: **서울 > 구 > 역**. 역 하나 = 맵 하나 (반경 약 400m, **2m 칸**). 경계는 가장 가까운 역 기준으로 나눔
- 땅은 평평. 고가도로는 없애고 다리만 남김
- **길 구조만 실제와 맞춤** (OpenStreetMap 도로). 건물은 우리 그림체의 일반 모양
- 지하철 = 맵 사이 빠른 이동 (전동차 타고 역 고르기). 요금은 실제와 같게 (성인 1,550원·청소년 900원·어린이 550원, 2025.6~)
- 자동차·버스는 나중
- 1차: **2호선 51역** (모두 서울 안) → 2차: 서울 안에서만 다니는 노선(6·9호선·우이신설·신림) → 나중: 다른 도시

## 저장

- 진행 중 인생 최대 5개. 되돌리기 없음 (버리고 새 인생)
- 끝난 인생은 리포트 목록으로 남음

## 원칙

- 실제 지명·역 이름은 씀. 실제 상호·브랜드·회사 이름은 안 씀
- 지도 데이터는 OpenStreetMap (게임 안에 "© OpenStreetMap contributors" 표기). 변환한 지도 파일은 ODbL로 공개. 구글 3D 지도는 쓰지 않음
- 외부 에셋은 CC0만. 예외: Mixamo 동작
- AI 대화는 중요한 순간에만. 평소는 정해진 대사
