# 65살~ 카드

> 노년 카드. 연금·건강·손주·정리가 중심이고, 죽음과 인생 리포트로 이어짐. 상태 🟡

## 규칙

- 하루 고정 0~1 + 무작위 1장. 카드 사이 시간이 길어 여유로운 노년 느낌
- 건강 태그 비중이 나이마다 오름: 65~74 30% · 75~84 45% · 85~ 60%
- 능력치 감소 카드 위주가 아니라 **남길 것**(돈·관계·기록)을 고르게 함 → 리포트·업적에 반영
- 수명: 성별 차이 없음, 평생 건강 지수로 정해짐. **최대 105살** (관리 잘하면 100~105) → [life/illness-death.md](../life/illness-death.md)
- 마지막 카드: 건강이 0이 되거나 수명이 다하면(늦어도 105살) "마지막 하루" 고정 카드 → 리포트
- 65살 첫날 고정 카드로 노년 모습 전환 연출

## 수치·데이터

**카드 주제**

| 나이 | 주제 |
| --- | --- |
| 65~74 | 연금 시작, 노인 일자리, 여행, 손주 돌보기, 경로우대 |
| 75~84 | 지병, 친구 부고, 유언, 집 줄이기, 배우자 간병 |
| 85~99 | 요양, 자서전, 장수 축하 |
| 100~105 | 100살 잔치, 마지막 하루 |

**예시 카드**

| id | 나이 | 조건 | 글 | 선택지 → 효과 |
| --- | --- | --- | --- | --- |
| o_fixed_65 | 65 | 고정 | 거울 속 머리가 하얗다. 국민연금이 나오기 시작했다 | 아껴 쓴다: 매달 연금 저축 / 여행 간다: 기분+20·돈-300만 |
| o_senior_job | 65~79 | 은퇴, 건강>=40 | 동네 노인 일자리 모집 (월 30만 원) | 한다: 돈+30만/월·체력+2·평판+5 / 쉰다: 기분+5 |
| o_grandchild | 65~85 | 손주 있음 | 손주를 봐달라는 부탁 | 봐준다: 기분+10·체력-5·자녀 호감+10 / 거절: 자녀 호감-5 |
| o_friend_funeral | 70~ | cooldown:5 | 오랜 친구의 부고 | 간다(10만): 감성+3·기분-10 / 못 간다: 기분-15 |
| o_will | 75~ | once, 돈>=1억 | 유언장을 써둘까? | 자녀에게: 리포트 "유산" 기록 / 기부: 평판+20·업적 후보 / 미룬다: 상속 다툼 확률 |
| o_downsize | 70~ | 아파트 이상 | 큰 집이 버겁다 | 작은 집으로: 돈+차액 / 그대로: 기분+5 |
| o_memoir | 80~ | once | 지난 인생을 적어볼까? | 쓴다: 리포트에 한 줄 소감 선택 / 그만: 변화 없음 |
| o_fixed_last | 수명 끝 | 고정 | 오늘은 유난히 조용한 하루다 | 가족에게 인사 / 창밖을 본다 → 인생 리포트 |

**MVP 10장**: 고정 2(65살 첫날, 마지막 하루) · 무작위 6 · 연쇄 2(지병→간병, 유언→상속)
