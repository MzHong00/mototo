# 20~64살 카드

> 성인 시기 카드. 병역·취업·연애·결혼·출산·집·건강까지, 인생의 대부분 갈림길. 상태 🟡

## 규칙

- 하루 고정 0~1 + 무작위 1~2장. 출퇴근·근무 시간은 피해서 뜸 (아침·퇴근 후)
- 조건의 중심은 깃발: `직업`, `married`, `kids`, `집 종류`, `빚`. 직업별 카드는 MVP 직업 6~8개에 2장씩까지만
- 나이대 가중치: 20대 연애·취업 ×2 / 30대 결혼·출산·집 ×2 / 40~50대 건강·자녀 교육 ×2 / 60~64 은퇴 준비 ×2
- 결혼·출산은 고정 나이 아님. 연애 상대 호감도 조건을 채우면 연쇄로 뜸 (청혼 → 결혼식 → 신혼집)
- 입영은 남성 필수. 20~30살 사이 반드시 입대 ([career/military.md](../career/military.md))
- 연애 카드: 스킨십·동침·임신 있음, 화면 가림 암시 연출만. 상대 성별 자유, 결혼 효과 같음
- 큰 돈 카드는 반드시 "안 한다" 선택지 포함

## 수치·데이터

**카드 주제**

| 나이 | 주제 |
| --- | --- |
| 20~29 | 입영, 대학 생활, 아르바이트, 첫 취업, 첫 자취, 연애, 학자금 |
| 30~39 | 결혼, 출산, 이직, 전세·대출, 승진, 부모 용돈 |
| 40~49 | 자녀 학원, 건강검진, 내 집 마련, 동창회, 번아웃 |
| 50~64 | 부모 간병·상속, 명예퇴직, 창업 유혹, 자녀 결혼, 정년 |

**예시 카드**

| id | 나이 | 조건 | 글 | 선택지 → 효과 |
| --- | --- | --- | --- | --- |
| a_fixed_army | 20~30 | 고정, 남, 현역 판정 | 입영 통지서가 왔다 | 육군(18개월) / 해군·공군 지원 → **군부대 맵**(서울 밖 유일한 맵) 이동, **부대 하루 4배속**(1.5일 ≈ 실제 9분) + 군대 카드 10장 / 연기(학업 등): 1년 미룸, 30살엔 연기 선택지 없음(강제 입대) |
| a_first_job | 22~34 | flag.no_job, 지능 or 손재주>=40 | 합격 문자가 두 곳에서 왔다 | 연봉 우선: 연봉 +5%·기분 -5/년 / 분위기 우선: 기분 +5·승진 빠름 |
| a_moveout | 22~35 | 부모 집 거주 | 독립할까? | 원룸 월세(보증금 1,000만·월 60만): 기분+15·돈 감소 / 그냥 산다: 돈 절약·부모 호감-5 |
| a_proposal | 27~45 | 연인 호감 최고 단계 | 오늘 청혼할까? | 한다: chance 70%(매력) 성공 flag.engaged→결혼식 연쇄, 실패 기분-30·이별 / 아직: 1년 뒤 다시 |
| a_wedding | 27~46 | 연쇄(engaged) | 결혼식 준비 | 크게(3,000만): 평판+10 / 작게(500만): 감성+3 / 식 없이: 돈 그대로·부모 호감-10 |
| a_baby | 28~44 | 연인 or married | 아이를 가질까? | 갖는다: 동침 암시 연출 → 다음 해 출산 연쇄·기분+20·양육비 시작 / 아직: 3년 뒤 다시 |
| a_checkup | 40~64 | cooldown:5 | 건강검진에서 재검 안내가 왔다 | 정밀검사(30만): 건강+10 / 무시: chance 80% 무사, 실패 건강-30·병 발생 |
| a_early_retire | 50~59 | 회사원 | 명예퇴직 신청을 받는다 (퇴직금 + 위로금 1억) | 신청: 돈+1억·실직 / 버틴다: 기분-10·정년까지 |

**MVP 26장**: 고정 5(입영, 30살·40살 건강검진, 부모 상(50~60대), 정년 60살) · 무작위 17 · 연쇄 4(청혼→결혼식, 출산, 독립→첫 집, 퇴직→창업)

1. 결혼 평균 나이에 맞춰 압박 카드 넣을까 → **제안: 35살 이후 "부모 잔소리" 카드 1장만, 효과 작게**
2. 저출산 반영 → **제안: 출산 카드 기본 weight 3, 강요 없음**
