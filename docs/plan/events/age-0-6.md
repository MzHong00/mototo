# 0~6살 카드

> 아기·유아 시기 카드. 부모 선택이 능력치 시작값을 다듬고, 튜토리얼을 겸함. 상태 🟡

## 규칙

- 0~6살은 반나절(실제 12분) = 1살. 집 안 기어다니기 + 카드 **3장**
- **1년 넘기기** 가능: 후보 5장 중 3장 골라 그해를 끝냄 (규칙 → [cards.md](cards.md)). 기어다니기 생략
- 선택하는 사람: 0~2살은 **부모가 고름**(부모 시점 문장), 3~6살은 아이가 고름
- 효과는 작게: 능력치 ±1~3 위주. 한 시기 합이 시작값을 ±10 넘게 바꾸지 않음
- 재력 조건 카드 있음 (학원·영어유치원은 재력 중 이상)
- 첫 카드(0살)는 조작 안내를 겸함: 반드시 선택지 2개, 둘 다 좋은 결과

## 수치·데이터

**카드 주제**

| 나이 | 주제 |
| --- | --- |
| 0 | 첫 울음, 이름 짓기, 분유/모유 |
| 1 | 돌잡이, 첫걸음, 첫 말 |
| 2~3 | 어린이집, 낯가림, 장난감 고르기, 감기 |
| 4~5 | 유치원, 그림·블록·공놀이, 형제 다툼, 놀이터 |
| 6 | 한글 떼기, 학원 맛보기, 초등 입학 준비(→7살 고정 카드) |

## 열린 질문

1. 돌잡이 선택지 수 → **제안: 3개(규칙 예외 없음), 물건은 무작위**
