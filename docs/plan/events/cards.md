# 카드 규칙

> 나이마다 화면에 뜨는 선택 카드(BitLife·Reigns식)의 형식·출현·효과 규칙. 상태 🟡

## 규칙

- 카드 = 상황 글 1~2줄 + **선택지 2개(기본)~3개**. 4개 이상 없음
- 종류 3가지
  - **고정 카드**: 정해진 나이에 반드시 뜸 (입학·수능·입영·은퇴 등). 하루 첫 카드
  - **무작위 카드**: 조건 맞는 카드 중 가중치(weight)로 뽑음
  - **연쇄 카드**: 앞 카드 선택이 깃발(flag)을 세우고, N년 뒤 다음 카드를 예약
- 뜨는 때: 하루(=1년) 안 정해진 시각(아침 기상·점심·저녁 귀가)에 화면을 멈추고 띄움. 선택 전까지 시간 멈춤
- 반복 방지
  - `once`: 인생에 1번 (기본값)
  - `cooldown`: N년 안에 다시 안 뜸 (반복 카드만, 기본 5년)
  - 같은 하루에 같은 태그(tag) 카드 2장 금지
- **1년 넘기기 (0~12살)**: 3D로 하루를 보내는 대신 고를 수 있음
  - 그해 고정 카드(있으면) + 무작위 후보 **5장 중 3장** 고름 → 각 카드 선택지 고름 → 바로 다음 해
  - 능력치 = 카드 효과 + 그해 기본 성장([life/stats.md](../life/stats.md)). 3D 하루의 행동 성장은 없음
  - 0~6살 기어다니기도 넘기기 가능. 해마다 3D/넘기기 다시 고름
- **연애 수위** (15세 등급): 미성년(~18살) 손잡기·포옹까지 / 성인(19살~) 스킨십·동침·임신 있음, 노골적 장면 없이 화면 가림 암시 연출 / 자살·자해 소재 없음
- 확률 선택지: 선택지에 `chance`가 있으면 성공·실패 결과가 갈림. 성공률 = 기본값 + (관련 능력치−50)×0.5%p + 운 보정, 5~95%로 자름
- 효과 크기 표준 (능력치·상태 0~100 기준)

| 크기 | 능력치 | 상태 | 돈 |
| --- | --- | --- | --- |
| 작음 | ±1~2 | ±3~5 | 1만~10만 원 |
| 보통 | ±3~5 | ±10 | 10만~300만 원 |
| 큼 | ±8~10 | ±20~30 | 300만 원~수억 (실제 금액) |

## 수치·데이터

**카드 데이터 항목**

| 항목 | 형식 | 예 |
| --- | --- | --- |
| id | `나이대_주제_번호` | `a20_job_offer_01` |
| age | [최소, 최대] | [25, 39] |
| kind | fixed / random / chain | random |
| cond | 능력치·상태·재력·직업·깃발 조건 | `지능>=60 & !flag.married` |
| weight | 1~10 (기본 5) | 5 |
| repeat | once / cooldown:N | once |
| tag | 학교·돈·연애·가족·건강·일·놀이 | 일 |
| text | 상황 글 (정해진 문장) | "다른 회사에서 연락이 왔다." |
| choices[] | 2~3개: label·chance·effects·fail_effects | — |
| effects | stat·state·money·flag·next(id, 몇 년 뒤) | `지능+3, 기분-5` |

**하루당 카드 수**

| 나이 | 하루 길이(실제) | 고정 | 무작위·연쇄 | 합 |
| --- | --- | --- | --- | --- |
| 0~6 | 12분 | 0~1 | 2~3 | 3 |
| 7~19 | 24분 | 0~1 | 2 | 2~3 |
| 20~64 | 24분 | 0~1 | 1~2 | 1~3 |
| 65~ | 24분 | 0~1 | 1 | 1~2 |

- 0~6살 전체판은 해마다 3장씩 21장(반복 없음). MVP 12장은 cooldown으로 21번을 채움
- 군대 카드 10장은 [career/military.md](../career/military.md) 묶음으로 따로 셈 (70장 밖)
- 한 인생 약 170~200장 뽑힘. MVP 70장이라 무작위 카드의 절반은 `cooldown`(반복 가능)으로 만든다

## MVP / 나중

| MVP | 나중 |
| --- | --- |
| 선택지 2~3개, 고정·무작위·연쇄 | 시간 제한 선택(Reigns식 스와이프) |
| 정해진 문장 | AI가 쓰는 카드 글 (중요한 순간만) |
| 카드 70장 | 200장+, 직업별 전용 카드 묶음 |
| 확률 선택지 | 카드에 미니게임 연결 |

## 열린 질문

1. 카드가 뜨는 방식: 시각 고정 vs 장소 들어갈 때 → **제안: 시각 고정 3번 + 장소 카드는 나중**
2. 선택지 효과를 미리 보여줄까 → **제안: 방향만(↑↓ 아이콘), 수치는 숨김**
3. 카드 한 장 건너뛰기 허용 → **제안: 불가. "모르겠다" 선택지로 대신** (1년 넘기기와 별개)
