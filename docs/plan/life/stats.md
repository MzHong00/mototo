# 능력치

> 6개, 0~100. 행동한 시간만큼 오르고, 나이별 상한이 있고, 늙으면 몸 쪽부터 줄어든다. **성장 공식은 이 문서가 유일한 기준** (다른 문서는 링크만). 상태 🟡

## 규칙

- 시작값: [birth.md](birth.md) (모두 5 + 부모 보정). 화면엔 정수, 내부는 소수 1자리
- **오르는 법** (공식)
  - 기본값 = 행동표 값 ([daily/actions.md](../daily/actions.md), 예: 독서 60분 지능 +1). 표에 없는 행동은 1게임시간당 주 능력치 +1
  - 실제 증가 = 기본값 × 나이 배율 × 특성 × 기분 보정 × 장소 보정 × (1 − 현재값/120)
  - 기분 보정: 80↑ ×1.2, 20↓ ×0.7 / 장소 보정: 학원·헬스장 ×1.5 (행동표 값에 이미 들어 있으면 빼고)
  - **하루 상한**: 같은 능력치는 하루(=1년) 최대 +3 (반복 노가다 막기). 학교·회사 자동 시간도 포함
  - **카드로 넘긴 해 (0~12살)**: 3D로 보낸 해 기준값의 **×0.7** (상한도 +2.1) → [age-stages.md](age-stages.md)
- **나이 상한**: 단계마다 넘을 수 없는 값 (아래 표). 상한에 닿으면 "더 크면 오를 거예요" 안내
- **내리는 법**
  - 안 씀: 20살부터 그해(하루) 한 번도 안 쓴 능력치 −1
  - 노화: 정해진 나이부터 매년(매일 아침) 자동 감소 (아래 표)
  - 사건: 병·사고·노숙 카드로 일시·영구 감소
- 매력은 외모(얼굴) + 옷 + 꾸밈. 옷 보정은 입고 있을 때만, 성형은 영구

## MVP / 나중

- MVP: 6개, 성장식, 나이 상한, 노화, 안 씀 감소
- 나중: 세부 기술(악기·외국어 등) 숙련도

## 열린 질문

- 숫자를 보여줄까? — 제안: 숫자 + 막대. 상한은 점선으로 표시
- 안 씀 감소가 귀찮을 수 있음 — 제안: 20살부터, 1년 −1만 (거의 체감 없음)
