# 운

> 숨겨진 수치 하나(0~100). 무작위 사건이 좋은 쪽으로 갈 확률과 크기를 바꾼다. 상태 🟡

## 규칙

- 탄생 때 정해짐: 평균 50, 표준편차 15 정규분포, 5~95로 자름. 평생 고정
- 화면엔 숫자 대신 **별 1~5개**만 (0~20 ★ · 21~40 ★★ · 41~60 ★★★ · 61~80 ★★★★ · 81~ ★★★★★)
- 무작위 사건(카드·길에서 생긴 일·병·사고·시험 당일 컨디션)은 2단계로 굴림
  1. **좋음/나쁨**: 좋을 확률 = 50% + (운 − 50) × 0.5% → 27.5%~72.5%
  2. **크기**: 작음·보통·큼·인생급 (아래 표)
- **불운 보정**: 나쁜 일 3번 연속이면 다음 무작위 사건은 좋은 일 확정
- 일시 보정: 기분 100이면 +5, 모험심 특성이면 크기 한 단계 ↑
- 운은 확률만 바꿈. 시험 합격 등 실력 판정은 능력치가 주, 운은 ±5%만
- 도박·복권 없음. 큰돈 사건은 "유산·당첨 아닌 행운"(예: 잃어버린 지갑 주인의 사례금, 오래된 물건 가치 발견)

## 수치·데이터

| 크기 | 확률 | 좋은 예 | 나쁜 예 |
| --- | --- | --- | --- |
| 작음 | 70% | 5천~5만 원 줍기, 기분 +10 | 우산 잃음, 기분 −10 |
| 보통 | 22% | 상품권 30만, 능력치 +2 | 핸드폰 고장 50만, 감기 |
| 큼 | 7% | 스카우트 제안, 300만 원 | 골절 사고, 사기 300만 |
| 인생급 | 1% | 귀인 만남(직업 길 열림), 3천만 | 큰 사고·큰 병, 집 침수 |

| 운이 쓰이는 곳 | 효과 |
| --- | --- |
| 탄생 재력 | 상위 20% +1점, 하위 20% −1점 → [birth.md](birth.md) |
| 시험·면접 | 합격 확률 ±5% (운 0 → −5%, 100 → +5%) |
| 병·사고 | 나쁨 판정 쪽 크기 굴림에만 |
| 수명 | ±2년 → [illness-death.md](illness-death.md) |
| 주식 | 쓰지 않음 (가상 회사 변동은 독립) |

| 한 인생 기대 (목표) | 값 |
| --- | --- |
| 무작위 사건 수 | 연 3~5개, 평생 약 350개 |
| 인생급 사건 | 평생 3~4번 |
