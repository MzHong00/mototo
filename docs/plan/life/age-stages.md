# 나이 단계

> 5단계. 단계마다 모습·갈 수 있는 곳·할 수 있는 일·돈이 바뀐다. 상태 🟡

## 규칙

- 나이는 **잠에서 깰 때** 1살 먹음 (0~6살은 반나절마다). 단계가 바뀌면 "나이 먹는 순간" 연출
- 하루 = 그해 대표 하루. 정해진 나이 이벤트는 그날 아침 카드로 먼저 나옴
- **어린 시절 넘기기 (0~12살)**: 매년 아침 "3D로 보내기 / 카드로 넘기기" 중 고름
  - 넘기기 = 그해 카드 3장 고름 → 카드가 정한 능력치를 받음 → 바로 다음 해
  - **넘긴 해 능력치 = 3D로 보낸 해 기준값의 70%** (하루 상한 +3 → 약 +2.1). 계산은 [stats.md](stats.md)
  - 학교·학원은 자동 반영, 상태는 부모 돌봄 기본값(건강·기분 70)으로 처리. 0~6살 기어다니기도 넘기기 가능
  - 3D로 보내면 동네 탐험·숨은 카드·업적 기회. 13살부터는 3D만
- 단계마다 지하철 요금·성장 상한·건강 최대치가 바뀜 → 해당 문서 값 사용
