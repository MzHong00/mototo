# 상태

> 배고픔·건강·기분·평판, 0~100. 하루(=1년) 안에서 시간 단위로 움직이고, 끝에 가면 경고·불이익이 붙는다. 상태 🟡

## 규칙

- 모든 상태는 **100 = 좋음, 0 = 나쁨** (배고픔 100 = 배부름)
- 시간 단위 = 게임 1시간(실제 1분). 잠자는 동안은 배고픔만 절반 속도로 줄어듦
- 하루가 끝나면(잠) 다음 날 아침 값 = 그날 끝 값 기준 회복 (아래 표)
- 30 아래 = 노란 경고, 10 아래 = 빨간 경고 + 효과음
- 팬 수는 별도 → [people/팬](../people/)

## 다른 그룹과 연결

- 식비 → [economy/수입·생활비](../economy/) (가정: 한 끼 8천~1만 5천 원)
- 먹기·자기·놀기 → [daily/일상 행동](../daily/)
- 건강·기분 하루 평균 → 건강 지수 → 수명 [illness-death.md](illness-death.md)
- 기분 → 능력치 성장 [stats.md](stats.md) / 특성 배율 [traits.md](traits.md)
- 평판 → [career/근무](../career/), [people/](../people/)

## MVP / 나중

- MVP: 4개 전부, 0·100 효과, 건강 최대치
- 나중: 위생(씻기) 상태 추가 여부

## 열린 질문

- 0~6살 아기도 배고픔? — 제안: 있음, 단 0 되면 부모가 자동으로 먹임(기분 −10만)
- 위생 상태 추가? — 제안: 안 함. 씻기는 기분 +5, 안 씻으면 평판 −2로 처리
