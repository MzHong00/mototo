# 탄생·부모

> 부모 직업 2개 + 부모 외모 2개를 고르면 재력 등급·집·시작 능력치가 정해지고, 성별·이름을 정해 태어난다. 상태 🟡

## 규칙

- 고르기 흐름 (화면 5장, 뒤로 가기 가능)
  1. **부모 A 직업** 34장 중 1장 → 2. **부모 B 직업** 1장 (같은 직업 가능)
     - 34장 = [직업 목록](../career/jobs.md) 32개(이름 그대로) + 예외 2개 "전업주부"·"없음(한부모)"
  3. **부모 외모** 각자 5단계 슬라이더 (못생김~아주 예쁨)
  4. **성별**(여/남, 능력치·수명 차이 없음) · **이름**(성 1자 + 이름 1~3자, 한글. 성은 부모 A 성 기본, 🎲 무작위 버튼)
  5. 확인 → 카드 뒤집기 연출로 **재력 등급 · 집 · 성격 특성 2개 · 운(별)** 공개 → 아기 시기 시작
- 재력 점수 = 부모 A + 부모 B 직업 점수(각 0~5, 무작위 직업은 탄생 때 굴림) + 운 보정(−1/0/+1, 운 상위 20% +1, 하위 20% −1) → 0~10
- 집 위치 = [동네 등급](../world/district-tiers.md) 역 중 무작위: **같은 등급 70%, 한 등급 차이 30%** (위·아래 반반, 끝 등급이면 안쪽으로)
- 시작 능력치 = 모두 **5** + 부모 직업 보정 합(최대 +10) + 외모 → 매력 (7살 얼굴 확정 때 적용)
- 연애 상대 성별은 탄생 때 안 고름 → 연애 시작 때 자유 선택 ([people/romance.md](../people/romance.md))
- 아이 외모 등급 = 부모 외모 평균(반올림) + 무작위 −1/0/+1, 1~5로 자름

## MVP / 나중

- MVP: 흐름 5장, 부모 직업 34장(수치만이라 전부), 재력 5등급, 집 4종, 이름 직접 입력
- 나중: 형제 수 고르기, 조부모, 부모 외모 미리보기(얼굴 합성)

## 열린 질문

- 부모 직업을 완전 자유로? — 제안: 자유. 대신 "무작위 부모" 버튼(업적 "운명에 맡김")
- 한부모 재력 — 제안: 점수 0 그대로(불리함 = 현실). 전업주부와 합쳐도 하 등급
