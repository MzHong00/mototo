# 성격 특성

> 태어날 때 2개를 무작위로 받고, 살면서 1개까지 더 생기거나 바뀐다. 같은 부모·같은 운이어도 인생이 갈리게 한다. 상태 🟡

## 규칙

- 탄생 때 **2개** 무작위 (반대 짝은 같이 안 나옴). 플레이어는 못 고름, 공개만
- 최대 **3개**. 3번째 칸은 13살·20살·40살 "전환점" 카드로 생김
- 바뀜: 특정 행동을 오래 하면 반대 특성이 사라지거나 생김 (아래 "바뀌는 조건")
  - 한 번에 1개만, 나이 단계마다 최대 1번
- 효과는 곱해서 적용 (예: 부지런함 ×1.15 · 기분 80↑ ×1.2)

## 수치·데이터

| 특성 | 효과 | 반대 | 바뀌는 조건 |

| 부지런함 | 모든 성장 ×1.15, 기분 감소 ×1.1 | 게으름 | 3년 연속 하루 10시간↑ 일·공부 → 생김 |

| 튼튼함 | 병 확률 ×0.7, 체력 성장 ×1.1 | 허약함 | 체력 80↑ 5년 → 생김 |

| 사교적 | 호감도 상승 ×1.25, 평판 상승 ×1.2 | 내성적 | 친구 10명↑ → 생김 |
