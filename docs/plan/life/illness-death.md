# 병·죽음

> 병은 나이·건강·특성으로 걸리고 돈으로 고친다. 수명은 성별과 상관없이 **건강 지수**(평생 건강 관리)로 정해지고, 최대 105살. 일찍 죽는 건 드물게. 상태 🟡

## 규칙

- **병 판정**: 매일 아침 1번 + 무작위 사건. 확률 = 기본 × 나이 배율 × 특성 × (건강 100이면 ×0.7, 30↓면 ×2)
- 치료: 병원·약국 가서 돈 내면 정해진 시간 뒤 회복. 안 고치면 건강이 계속 깎이고 큰 병은 수명 −
- 치료비는 건강보험 적용 후 본인 부담 금액. 큰 병(암 등)은 산정특례(5%) 가정
- **건강 지수** (0~100, 숨김. 휴대폰 건강 앱에 "좋음/보통/나쁨"만)
  - 매일 밤(=1년) **그해 점수** 계산 = 건강 평균×0.4 + 기분 평균×0.2 + 체력×0.2 + 습관 점수(0~20)
  - 건강 지수 = 7살부터 그해 점수의 누적 평균 (0~6살은 부모 돌봄 70 고정)
  - 상태 값(건강·기분)은 [status.md](status.md)의 하루 평균을 그대로 씀
- **기대수명** = 60 + 건강 지수 × 0.45 + 수명 보정(아래 표), **최대 105**. 성별 차이 없음
  - 매년 다시 계산. 65살부터 "기대수명 −1년 안"이면 죽음 예고 카드, 나이 ≥ 기대수명이면 그날 밤 죽음
  - **부모·배우자·NPC도 같은 공식**. NPC 건강 지수는 생성 때 평균 55·표준편차 12 (재력 상위 +5, 하위 −5)
- **죽음**: 수명 도달 · 큰 병 치료 실패 · 큰 사고. 장례 연출 → 인생 리포트
- 자살은 다루지 않음. 우울증은 치료로 회복되는 병으로만
