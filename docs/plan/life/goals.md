# 인생 목표

> 버킷리스트에서 목표를 골라 휴대폰에 붙여 두면, 할 일을 단계별로 안내하고 이루면 보상을 준다. 상태 🟡

## 규칙

- **고르는 시점**: 10살(첫 1개) · 20살 · 40살 · 65살 "전환점" 카드. 그 밖엔 휴대폰에서 언제든 추가
- 동시에 **최대 3개**. 버리면 기분 −5, 언제든 다시 고를 수 있음
- 목표마다 **할 일 3~5단계** (예: 의사 = 지능 70 → 수능 → 의대 6년 → 국시 → 수련)
  - 현재 단계만 HUD 한 줄로 표시, 다음 행동 장소는 지도에 핀
- 이루면: 기분 +30, 평판 +5, 축하 연출, 리포트에 ★표시. 같은 이름 업적과 연결
- 65살에 못 이룬 목표 → "후회" 카드 1장 (기분 −10, 노년에 다시 도전 선택지)
- 목표 없이 살아도 됨 (불이익 없음)
