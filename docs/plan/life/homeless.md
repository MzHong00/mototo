# 노숙·재기

> 집세를 못 내고 돈도 기댈 사람도 없으면 노숙자가 된다. 쉼터·일자리·지원금으로 단계를 밟아 다시 일어설 수 있다. 상태 🟡

## 규칙

- **대상**: 20~64살만. 19살까지는 부모 집, **65살↑은 노숙 안 됨** (기초연금으로 고시원 이하로 안 떨어짐)
- **되는 조건 (모두)**
  1. 월세 3달(실제 6분) 밀림 또는 집 경매 → 퇴거
  2. 현금 + 예금 < 고시원 1달치(35만 원)
  3. 호감도 70↑ 가족·친구가 없음 (있으면 "얹혀 살기" 선택지 → 노숙 대신 그 집)
- **노숙 중**: 잠 = 역·공원 벤치 (잠 회복 반감), 평판 상한 30, 매력 −10(일시), 수명 −1/년
  - 무료 급식소(하루 2번, 한 끼 +40) 이용 가능
  - 일반 채용 서류 탈락 80% (주소 없음)
- **재기 단계** (각 단계는 휴대폰 목표처럼 안내)

| 단계 | 하는 일 | 조건 | 결과 |
| --- | --- | --- | --- |
| 1 쉼터 | 노숙인 쉼터 입소 | 상담 1번 | 잠 정상, 주소 생김 (채용 불이익 해소) |
| 2 지원금 | 기초생활수급 신청 | 재산 거의 없음 | 생계급여 월 82만 원 (1인, 2026) |
| 3 일 | 자활·공공근로 또는 일용직 | 건강 30↑ | 월 100~200만 원 |
| 4 방 | 고시원 → 원룸 월세 | 보증금 모으기 | 노숙 상태 끝 |
| 5 재기 | 정규 직업 1년(=하루) 유지 + 자기 집 | — | 업적 "노숙에서 재기", 평판 +20 |

## 수치·데이터

| 항목 | 값 |
| --- | --- |
| 고시원 | 월 35만 원, 보증금 없음 |
| 원룸 월세 | 보증금 500만, 월 55만 원 (가정) |
| 자활 일자리 | 일당 7만 원, 하루 6시간 |
| 일용직 | 일당 15만 원, 힘 40↑, 체력 소모 큼 |
| 무료 급식 | 0원, 하루 2번 |
| 노숙 중 기분 감소 | ×1.5 |
| 노숙 중 병 확률 | ×1.5 |
| 밸런스 목표 | 노숙 경험 인생 5%, 그중 재기 60% |

- 다시 노숙 → 같은 길. 업적은 1번만
