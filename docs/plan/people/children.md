# 자녀

> 결혼 후 출산, 하루에 1살씩 크는 자녀에 돈과 시간을 쓰고 결과가 리포트에 남는다. 상태 🟡

## 규칙

- 결혼(또는 같이 살기) 후 매년 "아이 갖기" 켬/끔. 켜면 그해 끝에 임신 판정 → 다음 날(=다음 해) 출산
- 자녀는 **플레이어 기준 하루에 1살** (반나절 규칙은 플레이어 0~6살에만). 20일이면 성인
- 자녀는 조작하지 않는 NPC. 이어 하기 없음
- 자녀 능력치 = 부모 둘 평균의 50% + 무작위 + 양육 투자
- 양육 투자 2종: **돈**(학원·사교육) / **시간**(그날 같이 보내기). 시간은 호감·감성, 돈은 지능·특기
- 19살에 간이 진로 판정 → 대학 등급 → 직업 1개. 25~35살 사이 독립·결혼, 손주 생김
- 플레이어가 죽으면 재산은 배우자·자녀에게 (리포트에 기록만)

## 수치·데이터

**임신 확률 (그해, 낳는 사람 나이)** — 동성 부부·임신 안 될 때는 입양(결혼 필수, 비용 약 300만 원 가정) 또는 시술(연 500만 원, 확률 위 표 ×0.5 가정)

| 나이 | 확률 |
| --- | --- |
| ~34 | 80% |
| 35~39 | 60% |
| 40~44 | 30% |
| 45~ | 5% |

- 쌍둥이 2%. 자녀 상한 4명

**출산 비용·지원 (2026)**

| 항목 | 값 |
| --- | --- |
| 출산 의료비 | 거의 0 (건강보험) |
| 산후조리원 | 선택, 400만 원 (가정) |
| 첫만남이용권 | 첫째 200만 · 둘째+ 300만 원 (한 번) |
| 부모급여 | 0살 월 100만 · 1살 월 50만 원 |
| 아동수당 | 0~8살 월 10만 원 |
| 육아휴직 | 선택 시 그해 연봉 대신 휴직급여(연봉의 약 50%), 승진 -1년 |

**양육비 (자녀 1명, 월, 기본 생활비만)**

| 나이 | 월 | 1년(=게임 하루) |
| --- | --- | --- |
| 0~6 | 110만 원 | 1,320만 |
| 7~12 | 100만 원 | 1,200만 |
| 13~18 | 130만 원 | 1,560만 |
| 학원 (선택) | 0 / 40만 / 100만 / 200만 원 | 지능 +0 / +2 / +4 / +6 /년 |
| 대학 (19~22) | 등록금 연 700만 원 + 용돈 | 자녀 직업 등급 +1 |

**자녀가 자라는 과정**

| 나이 | 일 |
| --- | --- |
| 0~6 | 집 안에 아기 모델(플레이어와 같은 아기), 카드 1장/년 |
| 7~18 | 지금 몸, 학교 성적 1줄/년, 사춘기 카드(13~16) |
| 19 | 진로 판정 |
| 25~35 | 독립 → 결혼 → 손주 0~2명 |

**자녀 성과 → 리포트**

| 항목 | 계산 |
| --- | --- |
| 진로 | 자녀 지능 70+ 상위 대학, 50+ 보통, 그 아래 바로 취업 |
| 직업 | 진로 등급 + 가장 높은 능력치로 [직업 목록](../career/jobs.md)에서 무작위 |
| 자녀 호감 | 시간 투자로 결정. 600+면 노년 돌봄 이벤트 |
| 업적 | "의사 자녀", "손주 5명" 등 |

## MVP / 나중

- MVP: 출산(1~2명), 양육비 자동 지출, 지원금, 19살 진로 판정
- 나중: 학원 선택, 사춘기 카드, 손주, 육아휴직, 쌍둥이

## 열린 질문

- 자녀 3D 표시 — 제안: 집 안에서만, 밖에선 안 따라다님
- 입양·시술 비용 — 제안: 위 가정값, MVP는 입양만
- 양육비를 매달(2분) vs 매일(1년) 빼기 — 제안: 매달 빼기, 다른 생활비와 같게
