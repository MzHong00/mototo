# 가족

> 부모·형제·조부모와 같이 시작해, 부모가 늙고 떠나며 유산이 남는다. 상태 🟡

## 규칙

- 태어날 때 부모 2명(고른 직업) + 형제 0~2명 + 조부모(살아 있는 사람만)가 정해진다
- 가족도 [호감도](dialogue.md)를 쓴다. 단, 가족은 "싫음"까지 떨어져도 관계가 끊기지 않고 의절 이벤트만 생김
- 0~18살: 부모 집에 같이 삶, 부모가 용돈·학원비를 냄. 19살부터 독립 선택 가능
- 부모도 매일(=1년) 1살씩 먹는다. 65살부터 노년 모습, 75살부터 돌봄 이벤트
- 부모 사망은 [병·죽음](../life/illness-death.md)의 수명 규칙을 따름. 첫 부모 사망 → 재산은 남은 부모에게. 둘째 부모 사망 → 자녀들이 나눠 상속
- 형제: 형·누나는 태어날 때 이미 있음. 동생은 1~5살 사이 출생 이벤트

## 수치·데이터

**가족 구성 (무작위)**

| 항목 | 값 |
| --- | --- |
| 출생 때 부모 나이 | 30~37살 (평균 엄마 출산 33.7살 반영) |
| 형제 수 | 외동 45% · 1명 40% · 2명 15% |
| 조부모 출생 때 나이 | 58~70살, 4명 각자 생존 판정 |
| 시작 호감도 | 부모 700 · 형제 400 · 조부모 500 |

**부모 노화**

| 부모 나이 | 일 | 비용(플레이어 부담 몫) |
| --- | --- | --- |
| 65~74 | 노년 모습, 가끔 병원 | 없음 |
| 75~84 | 돌봄 이벤트(연 1회): 직접 돌봄(그날 시간 -2시간) / 요양 서비스 | 요양 서비스 월 80만 원 |
| 85~ | 요양원 선택 가능 | 월 150만 원 |
| 수명 | 성별 차 없음. 건강 지수 기반 공식(최대 105살) → [life/illness-death](../life/illness-death.md) | 장례비 1,500만 원 |

**부모 재산 (재력 등급별, 가정)** → 유산 원본

| 재력 | 상 | 중상 | 중 | 중하 | 하 |
| --- | --- | --- | --- | --- | --- |
| 부모 순자산 | 50억 | 15억 | 5억 | 2억 | 3천만 |

- 부모가 오래 살수록 노후 생활비로 재산이 줄어듦: 75살 이후 매년 -3%
- 나눔: 형제 수로 똑같이 (법정 상속분)

**상속세 (2026 현행)** — 일괄공제 5억 원(배우자 생존 시 +최소 5억)

| 과세표준 | 세율 | 누진공제 |
| --- | --- | --- |
| 1억 이하 | 10% | 0 |
| 1~5억 | 20% | 1천만 |
| 5~10억 | 30% | 6천만 |
| 10~30억 | 40% | 1억 6천만 |
| 30억 초과 | 50% | 4억 6천만 |

**관계 변화 이벤트**

| 이벤트 | 조건 | 효과 |
| --- | --- | --- |
| 부모 기대 | 성적·직업이 부모 직업 등급 이하 | 부모 호감 -50 |
| 결혼·손주 | 결혼·출산 | 부모 호감 +100 |
| 독립 지원 | 결혼 때, 재력 중 이상 | 전세금 일부(재력별 0~3억) |
| 의절 | 부모 호감 -100 이하 | 용돈·유산 없음(유산은 유류분 50%만) |

- 상속받은 돈·집 → [economy/부동산](../economy/real-estate.md), 세금 → [economy/세금](../economy/tax.md)
- 리포트에 가족 목록 → [ending/인생 리포트](../ending/report.md)

## MVP / 나중

- MVP: 부모 2명, 형제 0~1명, 부모 사망·유산(상속세 포함)
- 나중: 조부모, 돌봄·요양원, 의절·유류분, 형제 간 유산 다툼

## 열린 질문
