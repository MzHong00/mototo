# 연애·결혼

> 만나서 썸 → 연애 → 프러포즈 → 결혼. 돈·집이 걸리고, 틀어지면 이별·이혼. 상태 🟡

## 규칙

- 연애 상대는 [친구·동료](friends.md)와 같은 NPC 중 "연애 가능"(미혼. 나이 차 제한 없음. 단, 성인과 미성년은 연애 불가)인 사람
- **상대 성별은 자유.** 성별과 상관없이 연애·결혼 효과 같음. 동성 부부의 아이는 입양·시술 경로 → [children.md](children.md)
- **표현**: 성인(19살~)은 스킨십·동침·임신까지 있으나 노골적 장면 없이 암시 연출(화면 가림·암전). 미성년(~18살)은 손잡기·포옹까지. 연령 등급 15세 기준
- 단계는 [호감도](dialogue.md) + 사귄 기간(게임 하루 = 1년)으로 오른다
- 고백·프러포즈 성공 확률은 규칙이 정함. AI 대화는 그 순간 말만 (나중)
- 상대마다 이상형 점수: 매력·돈(연봉)·직업 등급·성격 일치 중 2개를 중시 → 고백 확률 보정
- 동시에 연인 1명. 바람 = 들키면 호감 -300, 바로 이별
- 결혼하면 배우자도 나이를 먹고, 배우자 수입·생활비가 가계에 합쳐짐
- 배우자 사망(사별)·이혼 후 재혼 가능

## 수치·데이터

**단계**

| 단계 | 조건 | 할 수 있는 것 |
| --- | --- | --- |
| 썸 | 14살+, 호감 400+ | 데이트(+20), 고백 |
| 연애 | 고백 성공 | 데이트, 선물 ×1.5, 같이 살기·동침(19살+, 암시 연출) |
| 진지한 연애 | 연애 2년+, 호감 800+ | 부모님 만남, 프러포즈 |
| 약혼 | 프러포즈 성공 | 결혼 준비(그해 안에 결혼) |
| 결혼 | 20살+, 집 있음 | 출산, 가계 합침 |

**확률**

| 행동 | 성공 확률 |
| --- | --- |
| 고백 | (호감-400)/4 % + 이상형 보정 ±20%p, 5~95% |
| 프러포즈 | (호감-700)/3 % + 집(전세 이상) +20%p, 5~95% |
| 실패 시 | 호감 -50, 같은 해 재시도 불가 |

**결혼 비용 (2025 실제 기준)**

| 항목 | 값 |
| --- | --- |
| 예식 스몰 / 보통 / 호화 | 500만 / 2,100만 / 5,000만 원 |
| 축의금 회수 | 예식비의 60% (스몰 30%) |
| 신혼집 | 별도. 실제 평균 약 3억(전세·매매) → [economy/부동산](../economy/real-estate.md) |
| 반지·예물 | 0~1,000만 원 선택 |
| 효과 | 기분 +30, 평판 +5, 부모 호감 +100 |

**만나는 길**

| 경로 | 나이 | 비용 |
| --- | --- | --- |
| 학교·대학·회사 | 14~ | 없음 |
| 친구 소개 | 20~ | 없음, 단짝 필요 |
| 소개팅 앱(휴대폰) | 20~ | 월 3만 원, 후보 2명/년 |
| 결혼정보회사 | 28~ | 300만 원, 후보 5명, 연봉·직업 맞춤 |

**이별·이혼**

| 항목 | 값 |
| --- | --- |
| 이별 판정 | 연인 호감 300 미만 → 그해 끝 50% 이별 |
| 이혼 카드 | 부부 호감 200 미만 2년 연속 또는 바람 |
| 재산 분할 | 결혼 후 늘어난 재산의 50% |
| 위자료 | 바람(유책) 쪽이 3,000만 원 |
| 자녀 | 양육권 50%, 못 가지면 양육비 자녀당 월 80만 원 |
| 효과 | 기분 -40, 평판 -5 |
| 참고(실제) | 조이혼율 1.7/천명, 평균 이혼 나이 남 51·여 47.7 (2025) |

## 열린 질문

- 결혼 최소 나이 — 제안: 20살 (법은 만 18살·부모 동의)
- 결혼 안 하면 손해? — 제안: 손해 없음, 리포트에 "혼자의 삶" 업적 있음
