# 일상 행동

> 물건·장소를 눌러 행동을 고르면 걸어가서 한다(심즈식). 하루 안의 행동 = 그해의 습관. 상태 🟡

## 규칙

- 조작: 물건·건물 클릭 → 행동 메뉴(2~5개) → 캐릭터가 이동 후 수행. 대기열 최대 3개, 언제든 취소
- 시간: 게임 1분 = 실제 1초. 행동 중에도, **걷는 중에도 60배 그대로** (순간이동·시계 늦추기 없음). 걸어서 400m = 게임 약 100분 → 같은 역 맵 안 가게는 걸어가고, 멀리는 지하철 → [subway.md](../world/subway.md)
- 장소 행동의 실제 부담 = 이동 시간 + 행동 시간. 집 근처(100m 안) 가게를 고르는 게 이득
- **비용**: 1년치 식비·여가비는 생활 수준 생활비에 이미 포함 → [income.md](../economy/income.md). 직접 사 먹거나 이용하면 **그 자리에서 실제 가격 1회만** 냄 (표의 "비용")
- 하루 흐름(7살~): 07시 기상 → 학교·회사(자동, 약 8시간) → 자유 시간 약 6시간 → 23시 전 잠 = 1살 먹음
- 상태 자연 감소(깨어 있는 게임 1시간마다): 배고픔 -5, 기분 -1. 잠자는 동안 배고픔 -10(한 번)
- 표의 능력치 값은 **기본 상승량**. 나이 배율·하루 상한·나이 상한·노화·안 쓰면 감소 → [stats.md](../life/stats.md)
- 씻기 안 한 날 평판 -2·기분 -5
- 잠: 침대(21~03시) → 아침 07시로 건너뜀. 03시까지 안 자면 강제 잠 + 건강 -10·기분 -10
- 장소 나이 제한: 7살부터 동네 혼자. PC방·노래방 청소년 22시 이후 불가. 헬스장 14살~
