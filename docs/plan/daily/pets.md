# 반려동물

> 강아지·고양이 등을 키움. 기분이 오르고 돈이 든다. **나중 단계**. 상태 🟡

## 규칙

- 입양: 펫숍이 아니라 **보호소**(역 맵 건물)에서. 7~19살은 부모 동의 카드가 나와야 가능, 20살~ 자유
- 한 번에 최대 2마리
- 돌봄(하루 = 1년 습관): 밥주기·쓰다듬기·산책(개만). 안 하면 친밀도와 내 기분이 내려감. 벌로 떠나거나 죽지 않음
- 수명은 게임 하루 단위(1일 = 1살). 수명이 다하면 이별 카드 + 기분 -30 (1년 동안 회복)
- 반려동물은 집 안·산책 중 따라다님. 회사·학교엔 안 감
- 원룸 월세 집 일부는 "반려동물 불가" (부동산 매물 표시)

## 수치·데이터

| 동물 | 입양비 | 연 유지비 | 수명(살) | 특징 |
| --- | --- | --- | --- | --- |
| 강아지 | 10만 (보호소) | 180만 | 13~15 | 산책 = 조깅과 같은 체력 효과 |
| 고양이 | 10만 (보호소) | 150만 | 14~16 | 산책 없음, 혼자 둬도 친밀도 덜 내려감 |
| 햄스터 | 2만 | 10만 | 2~3 | 7살부터 부모 동의 쉬움 |
| 물고기 | 3만 | 5만 | 3~5 | 돌봄 = 밥주기만 |

| 돌봄 | 게임 시간 | 효과 |
| --- | --- | --- |
| 밥주기 | 5분 | 안 주면 친밀도 -20 |
| 쓰다듬기 | 10분 | 친밀도 +10, 기분 +5 |
| 산책(개) | 60분 | 친밀도 +15, 기분 +8, 체력 +1 |

- 친밀도 0~100. 70 이상이면 매일 기분 +5, 혼자 사는 사람은 +10
- 연 유지비는 하루가 끝날 때 한 번 빠짐

## MVP / 나중

- MVP: 없음
- 나중: 1단계 강아지·고양이 + 밥·쓰다듬기 → 2단계 산책·햄스터·물고기 → 3단계 이별 카드·반려 불가 매물

## 열린 질문

- 아기 시기(0~6)에 집에 원래 반려동물이 있을 수 있나 → 제안: 예, 부모 카드로 10% 확률. 아기가 쓰다듬기 가능
- 펫숍 넣을지 → 제안: 아니오, 보호소만 (실제 상호 문제도 없음)
