# 아기 시기

> 0~6살은 집 안 3D에서 기어다니며 물건을 만지고, 카드로 큰 선택을 한다. 해마다 조작 하나씩 배움. 상태 🟡

## 규칙

- 1살 = 반나절 = 게임 12시간(07~19시) = 실제 12분. 7년 = 실제 84분
- 19시 → 잠 연출 → 다음 나이 07시. 아침에 그해 성장 요약 팝업(능력치 변화)
- 이동: 0~2살 기어가기(1m/s), 3~6살 아장아장 걷기(1.5m/s). 모습은 같은 아기(기저귀)
- 집 밖 못 나감. 현관·베란다·가스레인지 쪽으로 가면 부모가 안아서 거실로 데려옴
- 물건 클릭 → 30분(30초) 놀기 → 능력치 +1. 같은 물건 그해 3번째부터 효과 절반
- 욕구: 배고픔·기분만 보임. 배고프면 `울기` → 부모가 와서 먹임(4살부터 식탁에 직접 앉기)
- 3~5살 어린이집·유치원: 09~13시 자동 장면(4시간 건너뜀, 지능·감성 +1). 재력 따라 종류만 다름
- 카드: 해마다 3장 (10시·14시·17시 무렵, 놀던 행동 멈추고 뜸). **전체 21장, MVP 12장** (MVP에선 해마다 1~2장) → [age-0-6.md](../events/age-0-6.md)
- **카드로 1년 넘기기**: 해마다 07시에 "3D로 보내기 / 카드로 넘기기" 고름. 넘기면 그해 카드 3장만 고르고 바로 다음 나이 (실제 약 1~2분)
  - 넘긴 해 놀기 능력치 = 3D 상한(그해 약 +8.5)의 **70%** → 고정 +6, 부모 직업 쪽 능력치에 먼저 배분 (제안)
  - 넘긴 해의 튜토리얼은 다음에 3D로 보내는 해로 밀림. 0~6살 모두 넘기면 7살 첫날에 몰아서
  - 7~12살 넘기기 규칙 → [age-stages.md](../life/age-stages.md) (같은 70% 가정)
- 아기 시기 능력치 합 최대 +60 (부모 시작값에 더함). 나이 상한·배율 → [stats.md](../life/stats.md)

| --- | --- | --- | --- |

| 그림책 | 넘기기 | 지능 +1 | 0~ |
| 공 | 굴리기·차기 | 힘 +0.5, 체력 +0.5 | 0~ |

| 크레파스 | 벽·종이에 그리기 | 손재주 +0.5, 감성 +0.5 | 2~ |

- 장난감 수·종류는 집안 재력 따라 (원룸 5개 ~ 고급 아파트 11개 전부)

| 나이 | 배우는 조작 (튜토리얼) | 대표 카드 |
| --- | --- | --- |
| 0 | 카메라 돌리기 → 기어가기(WASD) → 물건 클릭 → `울기`(욕구) | 첫 웃음 누구에게? |
| 1 | 카드 고르기 → 능력치 창 열기 | **돌잡이**(연필·실·돈·마이크·공·청진기) |
| 2 | 행동 메뉴(물건 하나에 행동 여러 개) → 대기열 | 첫 단어 |
| 3 | 걷기 → 시계·"하루 = 1살" 안내 | 어린이집 첫날 |
| 4 | 상태 바 보기 → 식탁에 앉아 직접 먹기 | 친구랑 장난감 다툼 |
| 5 | 씻기(욕실) → 잠자리 고르기 → 저장 | 학원 보낼까(부모) |
| 6 | 아침 성장 요약 읽기 → "7살부터 동네" 예고 | 초등학교 입학 준비 |

- 튜토리얼은 말풍선 1줄 + 화살표. 건너뛰기 가능(두 번째 인생부터 기본 꺼짐)

## MVP / 나중

- MVP: 물건 6개(블록·그림책·공·악기·TV·부모), 울기, 기어가기·걷기, 카드 12장(age-0-6.md MVP), 카드로 1년 넘기기, 튜토리얼 0~3살 분
- 나중: 거울·퍼즐·한글책·반려동물, 크레파스 벽 낙서 남기기, 형제와 놀기

## 열린 질문

- 넘기기 능력치 비율 → 제안: 70% (낮으면 아무도 안 넘기고, 높으면 3D가 무의미)
- 아기 사고(넘어짐 등) → 제안: 없음. 위험한 곳은 부모가 데려옴
