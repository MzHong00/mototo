# 휴대폰

> 메뉴 대신 휴대폰. 앱 하나 = 기능 하나. 10살에 처음 받음. 상태 🟡

## 규칙

- 열기: `P` 키 또는 HUD 폰 아이콘. **폰을 여는 동안 시간 정지**(메뉴 역할)
- 단, 메신저 대화·영상 시청처럼 "하는 행동"은 시간이 흐름 (행동으로 처리 → [actions.md](actions.md))
- 첫 폰: 10살 생일 카드에서 부모가 줌 (재력 상위면 8살). 그 전엔 `Esc` 메뉴(설정·저장)만
- 앱은 나이가 되면 자동으로 깔림 (해금 아님, 실제 법·관습 나이)
- 폰 바꾸기: 4년마다 "폰 낡음" 알림. 새 폰 사면 기분 +5 (기능 차이 없음)
- 65살~: 큰 글씨 모드 자동 (끌 수 있음)
- 폰 분실·고장 없음
