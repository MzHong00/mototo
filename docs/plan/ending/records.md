# 기록 비교

> 끝난 인생 목록, 두 인생 겹쳐 보기, 명예의 전당(최고 기록). 다음 인생 동기를 만드는 화면. 상태 🟡

## 규칙

- 끝난 인생은 **무제한** 보관(인생당 15KB). 삭제 가능, 삭제해도 업적은 남음
- 목록 → 하나 누르면 [리포트](report.md) 다시 보기
- 비교: 인생 **2개**를 골라 나란히. 그래프는 한 축에 겹침(색 2개)
- 최고 기록: 항목별 1위 인생 1개. 새 기록이면 리포트에서 "새 기록!" 표시
- 다음 인생 시작 화면에 "이번엔?" 한 줄 제안: 아직 못 딴 업적 중 하나 무작위 (강제 아님)
- 버린 인생(죽지 않고 삭제)은 기록에 없음

## 수치·데이터

### 목록 한 줄

| 항목 | 예 |
| --- | --- |
| 번호·이름 | #7 김모토 |
| 기간·향년 | 2026~2108, 82살 |
| 최종 직업 | 의사(과장) |
| 순자산·등급 | 42억 · A |
| 묘비 문구 | "평생 의사로 산 사람" |
| 업적 수 | 9 (희귀 2) |

- 정렬: 최근(기본) · 순자산 · 향년 · 업적 수. 필터: 직업 · 재산 등급 · 사인

### 비교 화면

| 칸 | 내용 |
| --- | --- |
| 숫자 | 리포트 ② 숫자 항목을 좌우로, 높은 쪽 굵게 |
| 그래프 | 재산 곡선 겹침, 능력치는 하나 골라 겹침 |
| 갈림길 | 처음 달라진 큰 사건 3개 (예: 19살 대학 vs 취직) |
| 출발 | 부모 직업·재력·집 역 (같은 출발 다른 결과 보기용) |

### 최고 기록 (명예의 전당)

| 기록 | 기준 |
| --- | --- |
| 최고 부자 | 최종 순자산 |
| 최고점 | 살면서 가장 많았던 순자산 |
| 장수 | 향년 |
| 최다 팬 | 팬 최고치 |
| 대가족 | 자녀+손주 수 |
| 최다 직업 | 거친 직업 수 |
| 최고 역전 | 시작 재력 등급 대비 최종 재산 등급 차 |
| 최단 노숙 탈출 | 노숙 → 재기까지 년 수 (작을수록) |

### 누적 통계 (전체 인생)

- 산 인생 수, 총 플레이 시간, 평균 향년, 평균 재산, 직업별 횟수, 사인 비율, 업적 달성률(n/51)

## 다른 그룹과 연결

- 데이터는 [저장](save.md) `records` 스토어, 항목은 [리포트](report.md)와 같음
- 업적 진행률 → [업적](achievements.md)
- 시작 재력 등급 → [탄생·부모](../life/birth.md)
- 화면 배치 → [화면](../presentation/ui.md)

## MVP / 나중

| MVP | 나중 |
| --- | --- |
| 목록·정렬·리포트 다시 보기, 최고 기록 4개(부자·장수·직업·역전), 누적 통계 일부 | 2개 비교, 갈림길, 필터, "이번엔?" 제안, 온라인 순위 |

## 열린 질문

- 온라인 순위(다른 사람과 비교) — 제안: 나중, 서버 생기면. 조작 막기 어려워 "최고 부자"만
- 같은 부모 조건으로 다시 태어나기 — 제안: 허용(시작 화면 "이 출발로 다시"), 운·사건은 새로 뽑음
