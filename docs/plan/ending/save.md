# 저장

> 진행 중 인생 슬롯 여러 개 + 끝난 인생 기록 + 업적. 처음부터 IndexedDB, 슬롯당 저장본 1개(되돌리기 없음). 상태 🟡

## 규칙

- **진행 중 슬롯 최대 5개** (확정). 끝난 인생은 무제한. 하다가 두고 새 인생 시작 가능. 꽉 차면 하나를 끝내거나 버려야 함
- **슬롯당 저장본 1개, 자동만.** 수동 저장·불러오기로 과거로 돌아가기 없음(한 번뿐인 인생, 확정). 다시 하려면 "버리기"로 새 인생
- 버리기 = 즉시 사망 처리 없이 삭제. 기록·업적에 안 남음 (확인 2번)
- 끝난 인생: 슬롯에서 빠지고 리포트 요약만 [기록](records.md)으로 옮김. 큰 데이터(맵·NPC)는 삭제
- 접속 안 하면 시간 멈춤 → 창 숨김·닫기 때 즉시 저장
- 저장 중 아이콘 1초. 실패하면 경고 + 내보내기 권유

### 저장 시점

| 시점 | 묶음 |
| --- | --- |
| 자동 60초(실제) | 바뀐 묶음 전부 |
| 잠 → 다음 해(생일) | 전부 + 연 스냅샷 추가 |
| 카드 선택 직후 | `life`, `log` (새로고침으로 다시 뽑기 막음) |
| 역 이동(지하철) | `world` |
| 큰 일(취직·결혼·집 매매·업적) | 관련 묶음 + `achievements` |
| 창 숨김(`visibilitychange`)·닫기 | 전부 |

## 수치·데이터

### IndexedDB `mototo` (스토어)

| 스토어 | 키 | 내용 | 크기 |
| --- | --- | --- | --- |
| `slots` | slotId | 목록용 요약: 이름·나이·직업·재산·역·마지막 접속·플레이 시간·썸네일 | 슬롯당 30KB |
| `life` | [slotId, 묶음] | 슬롯 본데이터 (아래 표) | 슬롯당 200~500KB |
| `records` | lifeId | 끝난 인생 요약 + 스냅샷 + 사건 → [기록](records.md) | 인생당 15KB |
| `achievements` | id | 처음 딴 날·달성 인생 수 | 전체 5KB |
| `meta` | key | `SAVE_VERSION`, 설치 id, 백업 | 1KB |
| (localStorage) `mototo:settings` | — | 배속·음량·키·그래픽 | 2KB |

### `life` 묶음

| 묶음 | 내용 |
| --- | --- |
| `character` | 이름, 외형(얼굴·머리·옷), 나이 단계 |
| `life` | 나이, 시각, 능력치 6, 상태 4, 팬 수, 성격·운, 부모 직업·재력 |
| `career` | 학교·성적·학력, 직업 이력·직급·자격 |
| `money` | 현금, 대출, 집(소유·월세·전세), 주식 |
| `people` | 가족·친구·배우자·자녀, 호감도, 기억 |
| `world` | 현재 역·위치, 방문한 역, 집 위치 |
| `inventory` | 옷·물건 |
| `log` | 사건 로그, 연 스냅샷(리포트용), 본 카드 id, 난수 시드 |

- 형태: `{ v, savedAt, slotId, data }`. 바뀐 묶음만 씀. 쓰기는 트랜잭션 하나로 묶어 반쯤 저장 방지
- 난수 시드 저장 → 같은 시점에서 다시 열어도 같은 결과

## 버전·마이그레이션

- `SAVE_VERSION` 정수. 형식 바뀌면 +1, 변환 함수 1개 추가. 옛 버전 → 차례로 변환
- 미래 버전 → 불러오지 않고 "새 버전에서 열어주세요"
- 변환 전 `meta`에 백업 1벌. 실패하면 원본 유지 + 슬롯에 "열 수 없음"
- 모르는 직업·아이템·카드 id → 직업은 "무직", 아이템은 삭제, 카드는 무시
- v1(판타지) 저장은 변환 안 함. 감지되면 삭제 안내
