# 인생 리포트

> 죽으면 나오는 한 장 요약. 스크롤 없이 한 화면, 이미지로 저장 가능. 상태 🟡

## 규칙

- 죽음 연출 직후 표시 → [닫기]하면 [기록](records.md)에 들어가고 슬롯은 "끝남"으로 잠김(다시 플레이 불가)
- 리포트는 인생 중에 쌓인 **연 1회 스냅샷**(생일마다)과 **사건 로그**로 만든다. 끝날 때 새로 계산하는 값 없음
- 한 장 = 5칸: ① 머리 ② 숫자 ③ 그래프 ④ 주요 사건 ⑤ 묘비·업적
- 주요 사건은 점수 높은 순 **최대 8개**를 나이순으로. 같은 종류는 1개만(예: 승진 여러 번 → 가장 높은 것)
- 묘비 문구는 규칙으로 고름(AI 안 씀). 해당 규칙 여럿이면 우선순위 높은 것
- 공유: PNG 저장(1080×1350). 게임 속 이름만 표시

## 수치·데이터

### ① 머리 · ② 숫자

| 칸 | 항목 |
| --- | --- |
| 머리 | 이름, 태어난 해~죽은 해, 향년, 사인(노환·병·사고), 마지막 모습(치비 이미지) |
| 숫자 | 최종 순자산, 최고 재산과 그 나이, 최종 직업·최고 직급, 직업 수, 배우자·자녀 수, 친구 수("친구" 단계 이상), 팬 최고치(해당 시), 평생 번 돈, 살았던 역 수 |
| 등급 | 재산 등급 S~F (아래 표) |

| 재산 등급 | S | A | B | C | D | F |
| --- | --- | --- | --- | --- | --- | --- |
| 최종 순자산 | 100억+ | 30억+ | 10억+ | 3억+ | 0+ | 빚 |

### ③ 그래프 (가로축 나이 0~사망, 최대 105살)

| 그래프 | 값 | 비고 |
| --- | --- | --- |
| 재산 곡선 | 매년 순자산 | 로그 눈금(빚은 0 아래 빨강). 최고점 표시 |
| 능력치 곡선 | 6개 선, 0~100 | 범례 탭으로 하나씩 켜고 끔 |
| 띠 | 학교·직업 구간 색띠 | 그래프 아래 한 줄 (예: 초중고 → 대학 → 의사) |

- 스냅샷 1년 = `{age, netWorth, stats[6], status[4], job, station}` ≈ 80바이트 × 최대 106년(0~105살) ≈ 8.5KB

### ④ 주요 사건 점수

| 사건 | 점수 | 사건 | 점수 |
| --- | --- | --- | --- |
| 첫 취직 | 50 | 결혼 / 이혼 | 60 / 50 |
| 최고 직급 도달 | 70 | 자녀 출생 | 60 |
| 대학 합격 | 40 | 노숙 시작 / 재기 | 80 / 90 |
| 국가고시 합격 | 60 | 큰 병·사고 생존 | 50 |
| 첫 집 매매 | 50 | 재산 등급 오름 | 40 |
| 전설 업적 달성 | 70 | 부모 사망·유산 | 40 |

### ⑤ 묘비 문구 (우선순위 순)

| 조건 | 문구 예 |
| --- | --- |
| 105살 (최대 수명) | "주어진 삶을 끝까지 산 사람" |
| 노숙 → 재기 | "바닥에서 다시 일어선 사람" |
| 순자산 100억+ | "서울에서 손꼽히던 부자" |
| 팬 1억+ | "1억 명이 사랑한 사람" |
| 90살+ & 자녀 2+ | "자식 손주 품에서 눈감다" |
| 한 직업 30년+ | "평생 ○○으로 산 사람" |
| 40살 전 사망 | "너무 일찍 떠난 사람" |
| 빚으로 끝남 | "갚지 못한 것이 남았다" |
| 기본 | "○○역 근처에 살던 사람" (가장 오래 산 역) |

- 아래 줄: 이번 인생에서 딴 업적 아이콘(희귀도 높은 순 최대 6개) → [업적](achievements.md)

## 다른 그룹과 연결

- 사인·수명 → [병·죽음](../life/illness-death.md) (사인 3종 노환·병·사고, 수명은 건강 지수로 정해짐, 최대 105살)
- 순자산 = 현금+집+주식−대출 → [돈](../economy/income.md)
- 직급 이름 → [근무](../career/work.md), 친구 = 호감도 "친구" 단계 이상 → [대화·호감도](../people/dialogue.md)
- 죽음 → 리포트 연출 → [연출](../presentation/staging.md), 화면 배치 → [화면](../presentation/ui.md)
- 스냅샷 저장 → [저장](save.md)

## 열린 질문

- 리포트 뒤 그 인생을 이어서 구경할 수 있나 — 제안: 안 됨(한 번뿐인 인생)
- 묘비 문구를 플레이어가 고르나 — 제안: 해당 후보 최대 3개 중 고르기
