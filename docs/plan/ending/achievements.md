# 업적

> 인생을 넘어 남는 유일한 것. 51개, 8분류, 희귀도 4단계. 보상은 없고 기록만. 상태 🟡

## 규칙

- 계정(브라우저) 단위로 남음. 한 번 따면 영구. **다음 인생에 혜택 없음**(해금 없음 원칙)
- 판정 시점: 조건 달성 즉시(토스트 2초) 또는 죽을 때(수명·최종 재산류)
- 같은 업적 여러 번 달성 → "달성 인생 수"만 +1
- 숨김 업적: 조건을 "???"로 표시, 이름만 보임 (★ 표시)
- 희귀도는 설계 목표. 출시 뒤 실제 달성률로 다시 매김 (나중)

| 희귀도 | 목표 달성률(인생당) | 색 |
| --- | --- | --- |
| 흔함 | 30%+ | 회색 |
| 보통 | 10~30% | 초록 |
| 희귀 | 2~10% | 파랑 |
| 전설 | 2% 미만 | 금색 |

## 열린 질문

- 업적에 아무 보상도 없나 — 제안: 없음. 대신 프로필 칭호 1개 고르기(꾸미기만)
- 인생 합산 업적(job_all8) 허용? — 제안: 이것 하나만 허용
- 희귀도 목표 확인 — [밸런스 목표](../overview/balance.md)와 맞출 것
