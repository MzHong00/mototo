# 조작

> 키보드 + 마우스. WASD로 걷고 F로 상호작용, 카메라는 비스듬히 위에서 따라옴. 상태 🟡

## 규칙

- 키는 `KeyboardEvent.code` 기준(한/영 무관). 키 설정은 v1 방식(자판 그림에 끌어 놓기) — 나중
- 글 입력 칸에 포커스면 게임 키 무시. 창 포커스 잃으면 눌린 키 모두 해제 + 일시정지
- 상호작용: 2칸(4m) 안 가장 가까운 대상 1개에 "[F] ○○" 표시. 클릭으로도 가능
- 0~6살(집 안): 이동·F만. 달리기·점프 없음, 기어다니기 속도
- 카드·창이 열리면 이동 입력 무시. 카드는 숫자키·클릭으로 고름
- 넘어짐·추락 없음(평평한 땅). 막히면 미끄러지듯 비켜감

## 수치·데이터

| 키 | 기능 | MVP |
| --- | --- | --- |
| WASD / 방향키 | 이동 | ✅ |
| Shift | 달리기(체력 소모) | ✅ |
| Space | 점프 | 나중 |
| F / 클릭 | 상호작용 (들어가기·말 걸기·먹기·자기) | ✅ |
| 1 / 2 / 3 | 카드 선택지 | ✅ |
| Tab | 휴대폰 열기 | ✅ |
| M | 서울 노선도(지하철 안에서만 이동 가능) | ✅ |
| C | 꾸미기(옷장, 집 안에서만) | ✅ |
| Z | 배속 바꾸기(빠름·보통·느림 돌기) | ✅ |
| H | HUD 숨기기 | 나중 |
| Q / E | 카메라 45° 회전 | 나중 |
| 휠 | 카메라 확대·축소 | ✅ |
| Esc | 닫기 / 일시정지 (고정) | ✅ |

| 이동 | 값 |
| --- | --- |
| 걷기 / 달리기 | 1.4 / 3.0 m/s (어른 키 1.1m 기준, 화면 체감 맞춤) |
| 아기 기기 / 아장걸음 | 0.5 / 0.8 m/s |
| 노년 | [외형](appearance.md) 나이별 감속 |
| 가속 / 방향 전환 | 0.15초 / 0.1초 |

| 카메라 | 값 |
| --- | --- |
| 기본 | 내려다보는 각 50°, 거리 12m, 북쪽 고정 |
| 확대 범위 | 6~24m (휠) |
| 실내 | 각 60°, 거리 8m, 앞 벽 투명 |
| 건물이 가리면 | 그 건물 투명 30% |
| 지하철 | 전동차 안 옆모습 고정 → 노선도 화면 |

## 열린 질문

1. 클릭해서 그 칸으로 걷기(클릭 이동) — 제안: 나중에 넣음. 키보드가 기본
2. 카메라 회전 — 제안: MVP는 북쪽 고정(노선도·미니맵과 방향 일치)
3. 점프 — 제안: 도시에선 필요 없음. 뺌
