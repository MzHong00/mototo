# 연출

> 하루 = 1년이라 낮밤이 곧 계절. 생일마다 자라는 순간, 죽으면 담담한 회상 → 리포트. 상태 🟡

## 규칙

- 하루 06:00 = 3월 = 생일, 22~06시 = 겨울 ([시간](../overview/time.md)). **하늘·빛·나뭇잎 색이 시각=달을 따라 감**
- 날씨는 달마다 1번 뽑음(게임 2시간 유지). 비·눈은 소리·입자·길 젖음만, 이동 영향 없음
- 연출 중 시간 정지, 입력은 [건너뛰기]만(첫 1번은 못 건너뜀: 7살·65살·죽음)
- 무섭거나 슬픈 그림 없음. 죽음은 조용하고 따뜻하게
- 연령 등급 15세. 자살·자해 소재 없음

## 수치·데이터

| 시각(달) | 빛·하늘 | 나무 |
| --- | --- | --- |
| 06~08 (3월) | 연분홍 아침, 해 낮게 | 벚꽃 |
| 08~14 (4~6월) | 맑은 하늘색 | 연두 |
| 14~18 (7~8월) | 진한 하늘·강한 빛 | 진초록, 매미 |
| 18~22 (9~10월) | 노을 주황 → 보라 | 단풍 |
| 22~06 (11~2월) | 남색 밤, 가로등·창문 불 | 앙상한 가지, 지붕 눈 |

| 날씨 확률 | 맑음 | 흐림 | 비 | 눈 |
| --- | --- | --- | --- | --- |
| 3~5월 | 60 | 30 | 10 | 0 |
| 6~8월 | 40 | 25 | 35 | 0 |
| 9~10월 | 65 | 25 | 10 | 0 |
| 11~2월 | 45 | 30 | 5 | 20 |

**나이 먹는 순간 (매 06:00 생일)**

| 나이 | 연출 | 길이 |
| --- | --- | --- |
| 평소 | 화면 하얗게 0.3초 → 나이 숫자 넘어감 → 키 커짐(0.5초) → "올해 결과" 화면 | 3초 |
| 7살 | 아기 → 지금 몸 변신(빛) → **얼굴 공개** → 꾸미기 창 처음 열림 | 8초 |
| 20살 | "어른이 되었어요" 배너, 교복 → 사복 | 4초 |
| 65살 | 머리에 흰 물결이 퍼짐, 주름 겹침 | 5초 |
| 100살 | "100살!" 케이크 연출 | 5초 |
| 105살 | 마지막 생일(최대 나이) → 그날 밤 잠들며 끝 | — |

**암시 연출 (성인 19살~ 스킨십·동침)**

| 순서 | 내용 | 길이 |
| --- | --- | --- |
| 1 | 두 사람이 침대·방으로 → 카메라가 창밖·하늘로 돌아감 | 1초 |
| 2 | 화면 가림(커튼·하트 무늬) 또는 검은 페이드, 효과음만 | 2초 |
| 3 | 아침 장면으로 페이드 인, 결과 토스트(호감도 +, 임신 카드 확률) | 1초 |

- 몸 노출·노골적 동작 없음. 옷 그대로, 3D는 가림 뒤에서 위치만 이동
- 미성년(~18살): 손잡기·포옹 애니메이션까지. 가림 연출 없음

**죽음 → 리포트**

| 순서 | 내용 | 길이 |
| --- | --- | --- |
| 1 | 그 자리에서 앉음/누움, 음악 끊김, 화면 서서히 흑백 | 2초 |
| 2 | 검은 화면 "○○, ○○살로 잠들다" | 2초 |
| 3 | 회상: 주요 사건 최대 8장(사진 틀 + 나이), 타이틀 테마 느린 편곡 | 8장×1.5초 |
| 4 | 묘비 + 묘비 문구, 꽃 한 송이 | 2초 |
| 5 | [리포트](../ending/report.md) 펼쳐짐 | — |

- 사진 = 사건 순간에 자동 저장한 3D 화면(320×180) 최대 20장 중 고름

## 열린 질문

1. 날씨 MVP 포함 — 제안: 나중(시간 문서도 나중으로 둠)
2. 회상 사진 저장 — 제안: 썸네일 20장 이하, 저장 용량 약 300KB/인생
3. 죽음 직전 예고(노년 병세 표시) — 제안: 건강 10 미만이면 화면 가장자리 어둡게
