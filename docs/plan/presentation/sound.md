# 소리

> 장소·시간·나이로 바뀌는 잔잔한 음악 + 서울 생활 소리. 지하철 안내음은 "그 느낌"만 새로 만듦. 상태 🟡

## 규칙

- 외부 소리는 CC0만(출처 `CREDITS`). 실제 지하철 안내 방송·환승 음악·상표 소리 녹음 안 씀 → 비슷한 느낌으로 직접 만듦
- 배경음은 **장소**가 곡을, **인생 단계**가 악기를 정함 (같은 곡을 4가지 편곡)
- 곡 바뀔 때 1초 교차 페이드. 같은 곡이면 이어 감. 첫 재생은 사용자 입력 뒤
- 곡 1.5~3분 루프, OGG + MP3, 2MB 이하. 효과음 음높이 ±5%, 변형 2~3개
- 동시 16개, 같은 소리 50ms 안 중복 금지. 3D 위치 소리 최대 20m
