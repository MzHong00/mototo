# 화면

> 타이틀 → 인생 목록 → 부모 고르기 → 게임 → 리포트. 3D를 가리지 않는 작고 둥근 파스텔 UI. 상태 🟡

## 규칙

- UI는 캔버스 위 DOM. 3D 안에는 이름표·말풍선만
- 창은 한 번에 1개. Esc = 닫기, 창 없으면 Esc = 일시정지 메뉴
- **시간은 3D 걷기 중에만 흐름**. 카드·창·대화가 열리면 정지 ([시간](../overview/time.md))
- 둥근 한글 글꼴 1종(OFL). 글자 14px 이상, 버튼 40×40 이상. 최소 화면 1024×600
- 색은 디자인 토큰만. 상태 바 색: 배고픔 주황 · 건강 빨강 · 기분 노랑 · 평판 보라

## 수치·데이터

**화면 흐름**

| 화면 | 내용 | 다음 |
| --- | --- | --- |
| 타이틀 | 서울 미니어처 위 로고, [시작]. 첫 입력에 소리 켬 | 인생 목록 |
| 인생 목록 | 진행 중 카드(이름·나이·역·돈) / 끝난 인생(리포트 썸네일), [새 인생] | 이어하기 → 게임 / 새 인생 → 부모 |
| 부모 고르기 | ① 부모 직업 2개 ② 부모 외모·생김새 ③ 아이 이름·성별 → 재력·동네 미리보기 | 탄생 연출 → 게임 |
| 게임 | 3D + HUD | 죽음 → 리포트 |
| 리포트 | 한 장 요약 ([리포트](../ending/report.md)), [이미지 저장] [닫기] | 인생 목록 |

**HUD (1280×720 기준)**

| 위치 | 요소 |
| --- | --- |
| 왼쪽 위 | 이름 · **나이** · 시각(오전 9:12) · 달(5월), 하루 진행 바 |
| 왼쪽 위 아래 | 상태 4개 작은 바 (30 미만이면 깜빡임) |
| 오른쪽 위 | 돈(₩ 1,234,500), 미니맵 + 역 이름·구 |
| 오른쪽 아래 | 휴대폰 버튼(메신저·지도·은행·쇼핑·능력치), 배속 표시(×1) |
| 캐릭터 위 | 상호작용 안내 "[F] 들어가기" (가장 가까운 1개) |
| 왼쪽 가운데 | 알림 토스트 최대 4개 (돈 ±, 능력치 ±, 호감도) |
| 위 가운데 | 지금 할 일 1줄 ("학교 가기 08:00까지") |

**카드 화면**

| 항목 | 값 |
| --- | --- |
| 배치 | 화면 가운데 카드 1장(400×520), 뒤는 흐림 + 어둡게 40% |
| 카드 | 위 그림(일러스트 or 3D 캡처) · 상황 글 1~2줄 · 선택지 버튼 2~3개 |
| 확률 선택지 | 버튼에 성공률 표시 안 함, 관련 능력치 아이콘만 |
| 결과 | 카드 뒤집힘 0.4초 → 결과 글 + 변화 숫자(능력치 +3) → [확인] |

**1년 넘기기 (0~12살)**

| 항목 | 값 |
| --- | --- |
| 버튼 | HUD 위 가운데 "올해 카드로 넘기기" (0~12살만, 3D 중 언제든) |
| 확인 | "남은 올해를 카드로 보낼까요?" [넘기기] [3D로 계속] |
| 화면 | 카드 3장 연속(그해 카드에서 뽑음) → "올해 결과" 화면 → 다음 해 06:00 |
| 결과 | 고른 카드 효과 + 남은 시간을 자동 행동으로 환산한 능력치 ([하루 구조](../overview/day.md)) |
| 0~6살 | 기어다니기 중에도 같은 버튼 |

**설정**

| 항목 | 선택지 / 기본 |
| --- | --- |
| 배속(1년 길이) | 빠름 12분 · **보통 24분** · 느림 48분 |
| 음량 | 전체 80 · 음악 60 · 효과음 80 · 환경음 60 |
| 그래픽 | 그림자 끔 · 틸트시프트 끔 · 해상도 배율 100% |
| 기타 | 창 비활성 시 음소거 켬, 키 설정, 저장 내보내기 |
