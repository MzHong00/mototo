# 그림체

> 툰 음영 치비 + 장난감 같은 서울 미니어처. 파스텔, 진갈색 외곽선, 브라우저에서 가볍게. 상태 🟡

## 규칙

- 재질: 툰 4칸 램프(185·205·245·255) — 그림자 쪽도 밝게. 조명은 반구광 + 해 1개 (v1 그대로)
- 외곽선: 캐릭터 몸·머리만, 진갈색 `#5a3a32`. 옷·신발·건물·길 없음 ([asset/character](../../dev/asset-pipeline/character/index.md#윤곽선))
- 캐릭터: 몸 1개(`ChibiBody`)에 파츠 갈아입기. NPC·행인도 같은 몸
- 도시 = **미니어처(디오라마)**: 위에서 비스듬히 본 장난감 마을. 건물은 둥근 모서리 블록, 창문은 텍스처
- 건물은 실제 모양을 따르지 않음. 용도별 **일반 모양 + 색**으로 구분 (길만 OSM 실제)
- 실제 상호·로고 없음. 간판은 업종 그림(🍜·☕·💊 같은 아이콘) + 일반 이름("분식", "카페")
- 높이 압축: 실제 층수 대신 **최대 6층**까지 보이고, 그 위는 생략(카메라를 가리지 않게)

## 열린 질문

1. 건물 최대 높이 — 제안: 6층 + "생략 지붕"(위로 갈수록 투명). 실제 고층은 높이 표시만
2. 미니어처 느낌을 틸트시프트(가장자리 흐림)로 강조할지 — 제안: 설정에서 켜기, 기본 끔(성능)
3. 구마다 색 테마(예: 강남 회청, 마포 붉은 벽돌) — 제안: 나중. MVP는 공용 1벌
