# 외형·꾸미기

> 아기 → 지금 몸 → 노년. 얼굴 생김새는 7살에 부모 외모로 정해지고, 성형으로만 바뀜. 머리·옷은 자유. 상태 🟡

## 규칙

- 모든 나이가 같은 몸(`ChibiBody`). 나이는 **뼈 크기 + 파츠 + 텍스처**로만 표현
- **아기(0~6)**: 모두 같은 얼굴(기본 `look_1`), 머리카락 없음/배냇머리 1종, 기저귀만(색 4종 고름)
- **지금 몸(7~64)**: 7살 생일에 얼굴 생김새 결정 → 그때부터 머리·옷 고름
- **노년(65~)**: 주름 텍스처 겹침 + 흰머리(머리 색이 해마다 회색으로 섞임) + 허리 굽힘. 얼굴·머리 모양은 그대로
- 얼굴 = **생김새(눈·눈썹 모양)** + **외모 등급(1~5, 숫자)**. 등급은 그림으로 못생기게 그리지 않음 → 매력 시작값에만 반영
- 성별은 탄생 때 고름. 머리 선택지만 다름(옷은 모두 공용)
- 옷: 가게에서 사면 옷장에 들어감 → 꾸미기 창에서 자유 교체. 비싼 옷 = 매력 보너스(입은 동안만)

## 수치·데이터

| 나이 | 키 배율 | 머리 비율 | 동작 |
| --- | --- | --- | --- |
| 0~2 | 0.55 | +15% | 기어다니기 |
| 3~6 | 0.65 | +10% | 아장걸음 |
| 7~12 | 0.80 | +5% | 기본 |
| 13~18 | 0.92 | 0 | 기본 |

| 65~79 / 80~ | 0.98 / 0.95, 등 굽힘 8° / 15° | 0 | 걷기 −10% / −25% |

**7살 얼굴 결정**
1. 부모 외모 각각 1~5 (못생김 1 · 평범 3 · 예쁨 5)
2. 아이 등급 = 부모 평균(반올림) + 무작위 −1/0/+1, 1~5로 자름 ([탄생·부모](../life/birth.md))
3. 생김새(눈 모양): 엄마 쪽 45% · 아빠 쪽 45% · 무작위 10% (부모 생김새도 탄생 때 고름)
4. 매력 보정 = 등급 1~5 → +0/+5/+10/+15/+20 (7살 적용, [탄생·부모](../life/birth.md))

| 성형(19살~, 성형외과) | 비용 | 효과 | 회복 |
| --- | --- | --- | --- |
| 눈 | 150만 원 | 생김새 자유 변경, 등급 +0 | 게임 1달 붓기 |
| 코 | 400만 원 | 등급 +1 (최대 5) → 매력 +5 | 게임 2달 |
| 윤곽 | 1,000만 원 | 등급 +1 (최대 5) → 매력 +5 | 게임 3달 |

- 성형 1번당 부작용 5%: 매력 −3, 기분 −10 (회복 후 재수술 가능). 회복 중 얼굴에 반창고 파츠
- 옷 매력 보너스: 등급·점수는 [쇼핑](../economy/shopping.md), **최대 +10**. 미용실 컷 2만 원(매력 0), 염색 8만 원

## 열린 질문

1. 외모 등급을 화면에 보여줄지 — 제안: 숫자 대신 매력 값만. 등급은 숨김
2. 7살 전에 머리 모양 고를지 — 제안: 아니요. 7살 생일에 꾸미기 창이 처음 열림
3. 성형 나이 — 제안: 19살부터(부모 동의 이벤트로 17살 카드 1장은 나중)
