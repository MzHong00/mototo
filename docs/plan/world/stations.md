# 역 목록

> 2호선 51역(본선 43 + 성수지선 4 + 신정지선 4). 역 하나 = 맵 하나. 상태 🟡

## 규칙

- 역 수 = **51** (시청·성수·신도림은 본선에만 셈). 본선은 순환, 지선 2개는 왕복
- 소속 구 = 2호선 승강장 기준 1개 (경계 역도 1개만)
- 환승 표시는 **정보만**(노선도에 색 점). 다른 노선 타기는 2차
- 등급(1~5)은 [district-tiers.md](district-tiers.md) 값 그대로
