# 장소·건물

> 건물 종류 16가지. 역마다 등급·OSM 땅 용도로 자동 배치. 들어가는 건물은 내부 맵, 나머지는 외관만. 상태 🟡

## 규칙

- 건물 = 우리 그림체의 **일반 모양 + 간판 글자(종류 이름만)**. 실제 상호 X
- 배치 순서: ① 고정 건물(역마다 1번 정함) → ② OSM `landuse`로 블록 성격 → ③ 등급 비율로 나머지 채움
- 블록 성격: `commercial·retail` = 가게·회사 / `residential` = 집 / `education` = 학교 / `park·grass` = 공원
- 큰 길(대로·중로) 옆 = 1층 가게 + 위층 회사·집 (주상 혼합). 골목 안 = 집
- 들어가기: 문 앞 칸에서 상호작용 → 페이드 → 내부 맵(작은 방 하나). **들어가는 곳은 기능이 있는 건물만**
- 외관만 건물: 문 장식만. 다가가면 이름만 뜸
- 건물 높이(층) = 등급·길 폭으로 정함: 대로변 8~20층, 골목 2~5층 (그림체상 실제 높이 ×0.5)

## 열린 질문

- 내부 맵 공유? → 제안: 종류마다 내부 1~2개 틀 공유 (편의점 내부는 모두 같음)
- 학교 위치 OSM 실제 사용? → 제안: `amenity=school` 있으면 그 블록, 없으면 무작위
- 건물 크기 실제 OSM `building` 윤곽 사용? → 제안: 안 씀(블록만), 가볍게
