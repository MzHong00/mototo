# 서울 구조

> 서울 > 구 > 역. 역 하나 = 맵 하나(2m 칸, 평평). 길만 OSM 실제, 건물은 일반 모양. 상태 🟡

## 규칙

- 묶음: **서울 > 구(15개, 2호선 지나는 구) > 역(51)**. 구는 이름·동네 등급 기준값만 가짐, 맵 단위는 역
- 역 맵 = 역 출구 중심 **800×800m 정사각형(400×400칸)**. 맵 밖은 이웃 역 맵이 아닌 "회색 가장자리"
- **경계 = 가장 가까운 역 기준(보로노이)**. 이웃 역 맵과 겹치는 부분은 더 가까운 역 쪽만 남김 → 실제 맵은 800m보다 작아짐(역 간격 짧은 강남·중구)
- 걸어도 시간 60배 그대로(확정) → 맵 끝에서 끝(800m)은 게임 약 3시간. 먼 곳은 지하철 ([transport.md](transport.md))
- 맵 사이는 **지하철로만** 이동(MVP). 걸어서 경계 넘기는 나중 (가장자리 칸 밟으면 이웃 역 맵 로드)
- 땅 높이 = 0 하나. 언덕·계단 없음. 한강만 물 칸
- 좌표: 역 2호선 출구(OSM `railway=subway_entrance` 평균점) = 맵 (200,200)칸. 북쪽 = 위
- 저작권: 화면 구석 "© OpenStreetMap contributors", 변환 지도 파일 ODbL 공개

## OSM → 칸 지도 변환

| OSM `highway` | 게임 길 | 폭(칸, 1칸=2m) | 비고 |
| --- | --- | --- | --- |
| motorway·trunk | 큰 도로 | 12 (24m) | 도시고속도로(올림픽대로 등)는 **지움** |
| primary | 대로 | 10 (20m) | 횡단보도 있는 곳만 건넘 |
| secondary | 중로 | 7 (14m) | |
| tertiary | 소로 | 5 (10m) | |
| residential·unclassified | 골목 | 3 (6m) | 차 없음(MVP) |
| service·living_street | 이면길 | 2 (4m) | |
| footway·pedestrian | 보행로 | 2 | 광장은 면으로 칠함 |
| 차도 양옆 | 인도 | +1씩 | primary·secondary·tertiary만 |

- 선 → 칸: 길 중심선을 폭만큼 칠함(래스터화). 칸 종류 = 차도·인도·횡단보도·건물땅·공원·물
- 길 사이 남은 땅 = **블록**. 블록마다 [장소·건물](places.md) 규칙으로 건물 채움
- 다리(`bridge=yes`): 물 위 길만 남김(평평한 땅 높이, 난간만). 물 아닌 곳 위 다리·고가(`layer≥1`)는 **지움**
- 터널·지하차도(`tunnel=yes`, `layer<0`): 지움
- 철도 지상 구간(`railway=rail`): 넘을 수 없는 선(폭 4칸) + 건널목 없음. 2호선 지상 구간(성수~잠실 등)은 고가지만 **지움**(평평)
- 한강·하천(`natural=water`, `waterway=riverbank`): 물 칸. 못 들어감. 둔치(`leisure=park`) = 공원 칸
- 변환은 빌드 때 1번(오프라인 스크립트) → 역마다 JSON 1개

## 서울 밖

- **서울 밖 장소 없음**(확정). 맵은 지하철 역 맵만. 서울 밖 근무지(광부 등)는 맵 없이 근무 화면(자동 근무·미니게임)만
- **예외: 군부대 맵 1개** (입영 규칙은 [career/military.md](../career/military.md))

| 항목 | 값 |
| --- | --- |
| 크기 | 100×100칸(200×200m), 울타리로 막힘, 평평 |
| 구성 | 막사(들어감, 침상·관물대) · 연병장 · 식당 · 행정반 · 위병소(정문, 휴가·외출 → 서울 집) · PX(편의점 틀 공유) |
| 길 | OSM 아님, 손으로 만든 고정 맵 1개 |
| 사람 | 행인 없음. 같은 부대원 10~20명(정해진 대사) |
| MVP | 카드 화면만 (military.md 기준), 맵은 나중 |

## 수치·데이터

| 항목 | 값 |
| --- | --- |
| 칸 크기 | 2m |
| 맵 최대 | 400×400칸 = 160,000칸 |
| 맵 파일 | 칸 1바이트(종류) + 건물 목록, 압축 후 역당 ≤200KB 목표 |
| 로드 | 페이드 0.3초 + 빌드 ≤500ms, 최근 맵 2장 캐시 (v1 규칙 재사용) |
| 한강 닿는 역 | 강변·잠실나루·뚝섬·당산·합정 (물 칸 있음) |

## MVP / 나중

- MVP: 2~3역 맵, 지하철로만 이동, 차 없음
- 나중: 걸어서 이웃 역 넘기, 차·버스 길 위 주행, 2차 노선 역 추가, 군부대 맵

## 열린 질문

- 경계 밖 표현? → 제안: 회색 땅 + 안개, 큰 길 끝에 "→ ○○역 방면" 표지판
- 도시고속도로(강변북로·올림픽대로) 완전 삭제 vs 평면 대로? → 제안: 삭제 (한강 접근 좋아짐)
