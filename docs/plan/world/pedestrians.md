# 행인

> 거리를 걷는 이름 없는 사람. 수는 동네 등급·시간대로 정하고, 화면 근처만 그림. 상태 🟡

## 규칙

- 행인 = 대화 없는 배경 인물. **AI 주민(친구·동료·연인)과 다름** → people/
- 생성: 맵 안 무작위 인도 칸 + 건물 문·역 출구에서 나옴. 목적지(다른 문·출구)로 걷고 사라짐
- 길 찾기: 인도 칸 그래프 미리 계산(빌드 때) → 실시간 A* 안 씀
- 외형: 나이대(아이·청년·중년·노인) × 옷 세트 무작위. 등급 높을수록 정장·비싼 옷 비율 ↑
- 플레이어와 부딪히면 멈추고 비켜 감. 밀기 없음
- 상호작용: 다가가면 정해진 한 줄 대사(인사 20개). 대화 없음
- 행인 중 같은 나이대 일부는 **나중에 AI 주민으로 승격** 가능(친구 만들기 씨앗)

## 수치·데이터

맵당 기본 수 (동시에 살아 있는 수)

| 등급 | 기본 | 비고 |
| --- | --- | --- |
| 5 | 80 | 회사 많음 |
| 4 | 65 | |
| 3 | 55 | 대학가는 밤 ×1.3 |
| 2 | 45 | |
| 1 | 40 | |

시간대 배율

| 시간 | 배율 | 주로 보이는 사람 |
| --- | --- | --- |
| 00~05 | 0.1 | 취객·야간 근무 |
| 06~08 | 0.8 | 출근·등교 (역 쪽으로) |
| 08~10 | 1.0 | 출근 절정 |
| 10~17 | 0.5 | 노인·주부·배달 |
| 17~20 | 1.0 | 퇴근·하교 (역에서 나옴) |
| 20~24 | 0.6 | 식당·카페 근처 몰림 |

- 실제 수 = 기본 × 배율 × 날씨(비 0.6) × 주말(회사 많은 역 0.6, 상권 역 1.3)
- 최대 **120명** 상한

성능

| 항목 | 값 |
| --- | --- |
| 화면에 그리는 수 | 최대 60 (카메라 반경 80m) |
| 멀리(80m 밖) | 위치만 갱신, 그리지 않음 |
| 그리기 | 인스턴싱, 옷 세트 8종 텍스처 아틀라스 |
| 동작 | 걷기·서기 2개만 (Mixamo), 30m 밖은 애니 10fps |
| 갱신 | 가까운 것 매 프레임, 먼 것 0.5초마다 |
| 목표 | 행인 전체 CPU ≤ 2ms/프레임 |
