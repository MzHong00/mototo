# 집 안

> 집 4종(원룸·빌라·아파트·고급 아파트) + 고시원. 실제 전용면적 기준 크기, 방 구성 고정 틀. 상태 🟡

## 규칙

- 집 안은 **별도 내부 맵**. 문으로 들어가면 페이드 → 현관에서 시작
- 실내 칸 = **0.5m** (가구 배치용). 바깥 2m 칸과 따로
- 집 종류마다 **고정 틀 2개** (좌우 반전 포함 4가지 모양). 등급이 같아도 틀 무작위
- 방 이름 = 기능: 잠(침실), 씻기(욕실), 먹기·요리(주방), 쉬기(거실)
- 0~6살 기어다니기 = 부모 집 안 ([daily/baby.md](../daily/baby.md)) → 바닥 장애물 = 가구
- 가구는 기본 세트 포함. 사서 바꾸기는 나중
- 이사하면 집 종류 바뀜. 같은 종류는 틀만 다름

## MVP / 나중

- MVP: 원룸·빌라·아파트·고급 아파트 각 틀 1개, 기본 가구
- 나중: 틀 2개씩, 고시원·반지하, 가구 사기·꾸미기, 단독주택

## 열린 질문

- 실내 칸 0.5m vs 바깥과 같은 2m? → 제안: 0.5m (2m면 원룸이 2×2.5칸이라 너무 거침)
- 아이 방 수 < 가족 수일 때? → 제안: 형제 같은 방, 불편 이벤트 카드
- 반지하 넣나? → 제안: 나중, 등급 1 빌라 변형으로
