# 지하철

> 역 맵 사이 유일한 이동(MVP). 개찰구 → 승강장 → 전동차 안에서 내릴 역 고름 → 도착. 실제 요금. 상태 🟡

## 규칙

- 흐름: 역 출구 입장 → **개찰구(요금 차감)** → 승강장 → 열차 도착 대기 → 탑승 → **노선도에서 내릴 역 클릭** → 전동차 안 장면(빠름) → 도착 역 출구로 나옴
- 내선(시계)·외선(반시계) 중 **짧은 쪽 자동**. 지선은 성수·신도림에서 자동 갈아탐(+대기 1회)
- 요금은 **탈 때 기본요금, 내릴 때 거리 추가분** (교통카드 기준). 돈 없으면 개찰구 못 지남
- 운행: 05:30~00:30. 막차 끊기면 역 안 못 들어감 → 걷기·택시(나중)·역 근처 잠
- 출퇴근: 회사 역 ≠ 집 역이면 매일 지하철. **자동 출근** 선택 시 장면 건너뛰고 시간·요금만 처리
- 전동차 안: 서서/앉아 가기(무작위, 혼잡 시간 앉기 확률 ↓), 휴대폰 사용 가능. 짧은 랜덤 이벤트 카드 가끔(만남·소매치기 없음)

## 수치·데이터

요금 (2025.6~)

| 대상 | 기본(10km) | 추가 |
| --- | --- | --- |
| 성인(19~64) | 1,550원 | 10~50km 5km마다 +100원 |
| 청소년(13~18) | 900원 | 성인 추가분 ×0.8 (제안: 단순히 +100원 같게) |
| 어린이(6~12) | 550원 | 추가 없음(제안) |
| 6살 미만·65살 이상 | 무료 | 우대 |

- 거리 = 지나는 역 수 × **1.1km** (본선 48.8km ÷ 43역 ≈ 1.13km)

시간 (게임 시간 기준, 60배)

| 항목 | 게임 시간 | 실제 시간 |
| --- | --- | --- |
| 역 간 1구간 | 2분 | 2초 |
| 열차 대기(출퇴근 7~9시·18~20시) | 2~3분 | 2~3초 |
| 열차 대기(평시) | 5~7분 | 5~7초 |
| 입구~승강장 걷기 | 3분 (고정) | 연출 3초 |
| 예: 신림 → 강남 (8구간) | ≈ 25분 | ≈ 25초 |
| 한 바퀴 최장(반바퀴 21구간) | ≈ 50분 | ≈ 50초 |

- 혼잡도(행인 수·앉기 확률): 출퇴근 100% / 낮 40% / 밤 20%

노선도 화면

| 요소 | 규칙 |
| --- | --- |
| 모양 | 본선 원 + 지선 2개 가지, 2호선 초록 |
| 역 점 | 등급 색(1~5), 가 본 역은 진하게, 집·회사 아이콘 |
| 환승 | 다른 노선 색 작은 점(정보만) |
| 선택 시 | 시간·요금 미리 보기 → 확인 |
| MVP | MVP 역만 내릴 수 있음, 나머지 회색 |

## MVP / 나중

- MVP: 탑승 흐름, 요금, 노선도, 자동 출근
- 나중: 다른 노선 환승, 전동차 안 이벤트 확장, 정기권, 막차·첫차 연출

## 열린 질문

- 거리 추가 요금 넣나? → 제안: 넣음 (실제와 같게, 최대 +300원 정도)
- 전동차 안 직접 걷기? → 제안: 안 함, 앉은 장면 + 노선도 진행 막대
- 0~6살 혼자 못 탐? → 제안: 부모 동행 이벤트로만
