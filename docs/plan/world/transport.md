# 다른 이동

> 역 맵 안은 걷기·뛰기. 자동차·버스·택시·자전거는 나중. 상태 🟡

## 규칙

- 걷기 = 기본. 뛰기 = Shift 누르는 동안, **체력 소모**(상태 아님, 숨 게이지)
- 숨 게이지 0 → 3초 동안 걷기만. 걷거나 멈추면 회복
- 나이·능력치가 속도를 바꿈 (아래 표). 배고픔 20↓ 또는 건강 30↓이면 뛰기 불가
- **걸어도 시간은 항상 60배**(확정). 순간이동·시계 늦추기 없음 → 400m 걷기 = 게임 약 100분이 정상
- 먼 곳은 지하철로: 역 맵을 작게(반경 400m) 두고 맵 사이는 [subway.md](subway.md)
- 차도는 횡단보도로만 건넘(MVP는 차가 없어 막지 않음, 무단횡단 평판 −는 나중)
- 0~6살: 집 안 기어다니기만 ([home-interior.md](home-interior.md)). 바깥은 부모가 안고 다님(카드 장면)

## 수치·데이터

속도 (게임 화면 속도)

| 나이 | 걷기 | 뛰기 | 비고 |
| --- | --- | --- | --- |
| 0~6 기기 | 0.8 m/s | — | 집 안만 |
| 7~12 | 3.5 m/s | 6 m/s | |
| 13~64 | 4 m/s (2칸/초) | 7 m/s | 기준 |
| 65~79 | 3.2 m/s | 5 m/s | |
| 80~ | 2.8 m/s | 불가 | |

- 체력 능력치 보정: 뛰기 속도 ×(0.9 + 체력/500) → 체력 0 = ×0.9, 100 = ×1.1
- 숨 게이지: 100, 뛰기 −10/초(체력 100이면 −6/초), 회복 +20/초

시간 비용 (60배, 맵 끝~역 400m)

| 방법 | 실제 시간 | 게임 시간 |
| --- | --- | --- |
| 직접 걷기 4m/s | 100초 | 1시간 40분 |
| 직접 뛰기 7m/s | 57초 | 57분 |

나중 이동 수단

| 수단 | 조건 | 비용 | 메모 |
| --- | --- | --- | --- |
| 자전거 | 7살↑ | 30만 원 구입 | 맵 안 8m/s |
| 버스 | 7살↑ | 지하철과 같은 요금 | 지하철 없는 동네(2차 맵) |
| 택시 | 돈 | 기본 4,800원 + 거리 | 막차 후, 역 사이 |
| 자동차 | 19살↑ 면허 | 차값·유지비 | 차도 주행, 주차 |
