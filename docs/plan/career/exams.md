# 자격·시험

> 직업으로 가는 관문 시험. 정해진 나이·달에 이벤트로 치르고, 능력치+준비로 합격 확률이 정해짐. 상태 🟡

## 규칙
- 시험 = 정해진 달(게임 1달 = 실제 2분)에 열리는 **이벤트**. 신청 → 준비 → 당일 결과
- **준비**: "시험 준비" 상태로 1년(하루)을 보내면 준비도 +1. 학원(인강) 쓰면 +0.5 추가
- **합격 확률** = `기준 합격률 × (1 + (주 능력치 - 기준치)/50) × 준비 보정` (5~99%로 자름)
  - 준비 보정: 0년 0.3 · 1년 1.0 · 2년 1.2 · 3년↑ 1.3
- 시험 당일 건강·기분 30 미만이면 ×0.8
- 실패: 다음 해 재응시(제한 있는 시험은 횟수 표시). 준비 중엔 수입 없음 → 알바 병행 가능(준비도 절반)
- 자격증은 한 번 따면 평생. 이력서에 쌓여 취업·연봉에 보너스
- 공채(회사·공무원) = 서류 → 필기 → 면접. 면접은 **매력·평판**이 주로 봄

- 자격증 보너스: 직무 맞는 자격 1개당 연봉 +3%(최대 +9%)

## MVP / 나중
- MVP: 의사국시, 9급 공무원, 사무직 채용, 조리기능사, 오디션 (MVP 직업 맞춤)
- 나중: 나머지 전부, 면접 미니게임, 인강 상품

## 열린 질문
- 공무원 시험 준비(공시) 장기화 → 제안: 3년 넘으면 기분 -10/년 카드("공시 낭인")
- 시험 미니게임? → 제안: MVP는 확률만, 나중에 짧은 문제 풀이(합격률 ±10%)
- 합격률을 실제 그대로? → 제안: 그대로 두고 능력치 보정으로 체감 조절
