# 근무

> 근무일 하루 = 1년 일함. 출근해서 자동 근무 또는 미니게임 → 성과 → 승진·이직·해고. 상태 🟡

## 규칙
- **출근**: 집 → (걷기·지하철) → 직장 건물 입구. 09:00까지 도착(직업마다 시각 다름)
  - 지각: 성과 -5 · 결근: 성과 -20 · 3번 결근 = 해고 위험
- **근무 시간**: 보통 09~18시(실제 9분). 들어가면 두 가지 중 고름
  - **자동 근무**: 화면 빠르게 넘김, 성과 = `주 능력치 평균 × 0.8 + 무작위 ±10` (최대 80)
  - **미니게임**: 직업별 30~60초 게임 3판, 성과 = 점수(0~100). 잘하면 자동보다 높음
- **야근**(선택): 2시간 더 → 성과 +10, 건강 -3, 기분 -5
- 근무 중 카드 1~2장(동료 갈등·칭찬·사고)
- **연 성과** = 그날 성과. 퇴근 때 정산 → 다음 해 연봉·승진에 반영
- 일하면서 주 능력치 +1~2/년, 스트레스로 기분 -3/년(직업별)
- **서울 밖 근무지**(광부 등): 맵·이동 없음. 출근 시각이 되면 바로 근무 화면(자동 근무·미니게임) → 퇴근 때 집으로
- 교대 근무 직업(간호사·경찰·소방·의사)은 시간대만 다름(밤 근무 = 기분 -2 추가)

## 수치·데이터

- 연봉 = [직업 목록](jobs.md)의 연차 곡선(보통 사람 기준, 보통 승진 포함) × **성과 보정** × **직급 보정**
- 회사 규모(대기업·중소기업) 구분 없음. 직급은 회사 직업(사무직·개발자·연구원·디자이너·기자 등) 공통

| 연 성과 | 성과 보정(누적, ±30% 한도) | 비고 |
| --- | --- | --- |
| 90~100 | +4% | 승진 가산 2년 |
| 70~89 | +2% | 승진 가산 1년 |
| 50~69 | 0% (곡선 그대로) | 기본 |
| 30~49 | -2% | 경고 |
| 0~29 | -2%, 경고 | 2년 연속 = 권고사직 |

| 직급(회사) | 보통 도달 연차 | 승진 조건 |
| --- | --- | --- |
| 사원 | 0 | |
| 대리 | 4 | 최근 3년 평균 성과 50↑ |
| 과장 | 8 | 평균 60↑ |
| 차장 | 12 | 평균 65↑ |
| 부장 | 16 | 평균 70↑ |
| 임원 | 20 | 평균 85↑ + 매력 60↑, 확률 10% |

- 직급 보정: 보통 도달 연차보다 1단계 빠를 때마다 +8%, 늦을 때마다 -8%. 임원은 15년차 연봉 ×2
- 공무원·교사·경찰·소방: 호봉 = 연차 곡선 그대로(성과 보정 없음) + 계급 승진(9급→5급, 7~10년 간격, 승진마다 +5%)
- 전문직(의사·변호사·약사·회계사): 직급 없음, 15년차 **개업** 선택(수입 ×1.3, 대신 망할 위험 5%/년)
- 현장직(광부·요리사 등): 3단계(보조 → 기능공 → 반장·셰프), 보통 도달 0·5·12년차, 빠르면 단계마다 +8%
- 팬 직업: 성과 = 팬 수 증가([팬](../people/fans.md))

| 이직·해고 | 조건 | 결과 |
| --- | --- | --- |
| 이직 | 3년차↑, 최근 평균 성과 60↑ | 같은 직업 다른 회사, 성과 보정 +5~10% |
| 전직 | 다른 직업 조건 충족 | 그 직업 1년차부터 |
| 권고사직 | 성과 30 미만 2년 | 실업, 퇴직금 지급 |
| 구조조정 | 불황 + 40살↑ 회사원, 확률 5%/년 | 실업 + 위로금 연봉 50% |
| 징계 | 공무원 성과 10 미만 3년 | 감봉, 해고는 없음 |
| 사고 | 현장직(광부·건설) 1%/년 | 건강 -30, 산재 보상 |

- **실업**: 구직급여 = 이전 평균임금 60%, 하루 상한 68,100원·하한 66,048원(2026), 120~270일
  - 게임: 매달 약 204만 원 이하, 4~9달(실제 8~18분). 끝나면 수입 0 → [노숙·재기](../life/homeless.md) 위험
- 실업 중: 구인 앱 지원, 직업훈련(국비 무료, 자격증 준비도 +1)

## MVP / 나중
- MVP: 출근(지각·결근), 자동 근무, 성과 → 연봉, 회사 직급 6단계, 권고사직·실업급여, 미니게임 1개(요리사)
- 나중: 직업별 미니게임 31개, 야근, 개업, 산재, 구조조정, 동료 AI 대화

## 열린 질문
- 근무 중 캐릭터를 볼 수 있나? → 제안: 건물 안으로 들어가면 근무 화면(2D 패널), 3D는 출퇴근만
- 자동 근무 상한 80 → 제안: 그대로(미니게임 할 이유)
- 주말·휴가 → 제안: "대표 하루"라 없음, 연차는 카드로("휴가 다녀옴: 기분 +10")
