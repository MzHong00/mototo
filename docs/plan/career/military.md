# 병역

> 남자 19살 병역판정검사 → 20~30살 사이 반드시 입대(현역 18개월)·대체복무·면제. 여자는 지원 시만. 상태 🟡

## 규칙
- **대상**: 남자 전원. 19살 하루 시작에 **병역판정검사** 이벤트
- 판정 등급 = 건강·체력·힘으로 계산 + 무작위(병 카드가 있으면 낮아짐)
- **시기**: 20~30살 사이 반드시 입대(실제 기준). 입영 날짜는 플레이어가 고름(보통 대학 1~2학년 뒤 20~21살)
- **연기**: 사유가 있으면 1년 단위로 미룸 — 대학·대학원 재학, 질병 치료(7급 재검), 국가시험 응시 1회. 어떤 사유든 **30살을 넘길 수 없음**
- 30살 하루가 끝날 때까지 안 갔으면 **강제 입영** 이벤트
- **복무 시간**: 18개월 = 게임 1.5일. **부대 하루는 4배속 고정** → 실제 약 9분 + 군대 카드 10장 (확정, 이 문서가 기준)
- 복무 중: **군부대 맵 1개**(서울 밖 장소 중 유일한 맵, 확정)에서 지냄. 일과 자동 + 군대 카드. 휴가 때 서울 집으로
- 사회복무요원은 부대 맵 없이 서울 관공서로 출퇴근
- 복무 중 능력치: 힘 +3/년, 체력 +4/년, 기분 -5/년. 학업력 -2/년(공부 안 하면)
- 월급은 돈으로 들어옴 + 적금 매칭 → 전역 시 목돈
- 회피(일부러 체중 조절 등)는 범죄라 넣지 않음. 기피 선택지 없음
- 여자: 20~27살에 **부사관·장교 지원** 가능(직업 [직업군인](jobs.md))

## 수치·데이터

| 판정 등급 | 조건(제안) | 결과 |
| --- | --- | --- |
| 1~3급 | 건강 60↑, 체력 40↑ | 현역 |
| 4급 | 건강 40~59 또는 만성 병 | 보충역 → 사회복무요원 |
| 5급 | 건강 20~39 또는 큰 병 | 전시근로역(사실상 면제) |
| 6급 | 장애·중병 | 면제 |
| 7급 | 병 치료 중 | 1년 뒤 재검 |

| 복무 종류 | 기간 | 조건 |
| --- | --- | --- |
| 육군·해병대 | 18개월 | 현역 기본 |
| 해군 | 20개월 | 현역 지원 |
| 공군 | 21개월 | 현역 지원, 지능 40↑ |
| 사회복무요원 | 21개월 | 4급. **출퇴근**(서울 관공서), 집에서 생활 |
| 산업기능요원 | 34개월(보충역 23) | 특성화고·자격증 + 지정 회사 취업 |
| 전문연구요원 | 36개월 | 석·박사 + 연구소 |
| 공중보건의사 | 36개월 | 의사 면허 |
| 예술·체육요원 | 34개월 | 올림픽 메달·아시안게임 금·국제 콩쿠르 입상 |
| 장교(학군) | 28개월 | 대학 + 지능·체력 |

| 계급 (2025~2026) | 월급 | 적금 매칭(최대) |
| --- | --- | --- |
| 이병 | 75만 | 55만 |
| 일병 | 90만 | 55만 |
| 상병 | 120만 | 55만 |
| 병장 | 150만 | 55만 |

- 18개월 합계(이병 2·일병 6·상병 6·병장 4달): 월급 약 2,010만. 적금(본인 55만×18 + 매칭 990만) → 전역 때 목돈 약 2,000만

## MVP / 나중
- MVP: 판정검사, 입영·연기(30살 한도), 육군 18개월 / 사회복무 21개월 / 면제 3갈래, **군부대 맵 1개 + 카드 + 4배속**
- 나중: 해군·공군, 산업기능·전문연구·공보의·예술체육, 여자 지원, 장교
