# 학교

> 7~18살 학교 하루 = 1년. 매년 학업력이 쌓이고 고3 끝에 수능. 상태 🟡

## 규칙
- 학교 하루: 등교(08:30) → 수업 → 하교(15:30~16:30) → 자유 시간(학원·놀기·알바)
- 수업 시간은 **자동 진행**(화면 빠르게 넘김). 수업 중 카드 1~2장
- 매년 **학업력**(숨은 값 0~100)이 오름. 시험 점수·등급은 학업력에서 나옴
- 학업력 연간 증가 = `기본 2 + 지능×0.04 + 공부시간(h)×0.5 + 학원 보너스` × 기분 보정(기분<30이면 ×0.7)
- 시험 점수 = 학업력 + 무작위 ±8. 같은 학년 NPC 분포(평균 50, 표준편차 15)와 비교해 백분위 → 등급
- 결석 많음(기분 0·병) → 학업력 증가 절반
- **카드로 1년 넘기기**(0~12살, 해마다 고름): 3D 하루 대신 그해 카드 3장을 고르고 바로 다음 해로
  - 학교 1년은 자동 처리: 출석 100%, 학원은 정해 둔 단계 그대로(비용 차감), 학업력 = 공식에서 공부시간을 학년 평균(2h)으로 넣은 값
  - 3D로 보낸 해보다 이득 없음(공부시간 추가 불가). 카드 결과로 능력치 받음 ([카드 규칙](../events/cards.md))
- 유치원(5~6살)은 아기 시기 카드로만 처리 ([아기 시기](../daily/baby.md) 가정)

## 수치·데이터

| 단계 | 나이 | 게임 일수 | 특징 |
| --- | --- | --- | --- |
| 유치원 | 5~6 | 반나절×2 | 카드만, 성적 없음 |
| 초등학교 | 7~12 | 6일 | 성적표만(등급 없음), 학원 시작 |
| 중학교 | 13~15 | 3일 | 성적 A~E, 고교 선택 |
| 고등학교 | 16~18 | 3일 | **내신 5등급**(2025 고1~ 실제 제도), 고3 끝 수능 |

내신 5등급(상대평가): 1등급 상위 10% · 2등급 34% · 3등급 66% · 4등급 90% · 5등급 100%

| 고교 종류 | 들어가는 조건 | 효과 | 학비/년 |
| --- | --- | --- | --- |
| 일반고 | 기본(근처 학교 배정) | 없음 | 0 (고교 무상교육) |
| 특성화고 | 중3 선택 | 졸업 시 기능사 1개, 취업 이벤트 | 0 |
| 과학고 | 중3 성적 상위 3% + 지능 70↑ | 학업력 +3/년, 내신 등급 불리(경쟁 센 반) | 약 300만 원 |
| 외고·국제고 | 중3 상위 10% | 학업력 +2/년, 매력 +1/년 | 약 800만 원 |
| 자사고 | 상위 20% + 집안 재력 중상↑ | 학업력 +2/년 | 약 900만 원 |
| 예술고·체고 | 감성 또는 힘·체력 60↑ + 실기 | 연예인·운동선수 길 보너스 | 약 500만 원 |

| 학원 | 월 비용 | 학업력 +/년 | 기분 -/년 |
| --- | --- | --- | --- |
| 없음 | 0 | 0 | 0 |
| 보통(단과 1~2) | 40만 | +2 | -3 |
| 많음(종합·여러 개) | 80만 | +4 | -8 |
| 최상위(대치동급 과외) | 150만 | +6 | -12 |
| 예체능(피아노·태권도·미술) | 20만 | 감성·힘·손재주 중 +2 | +2 |

- 참고: 2025 초중고 사교육 참여율 75.7%, 참여 학생 1인당 월 60.4만 원
- 학원비는 부모 돈에서 나감. 재력 낮으면 "최상위" 선택 불가

## MVP / 나중
- MVP: 초·중·고 3단계, 일반고만, 학원 3단계, 내신 5등급, 수업 자동
- 나중: 특목고·자사고·특성화고, 수업 미니게임, 전학·검정고시·자퇴

## 열린 질문
- 학교에 실제로 출석해야 하나? → 제안: 등교하면 자동, 안 가면 결석 처리(이동은 자유)
- 검정고시·자퇴 길 → 제안: 나중에 넣되 수능 응시는 가능하게
