# 직업 목록

> 실제 한국 직업 32개. 세전 연봉은 **중소·중견기업 / 보통 사람** 기준(2024~2026 자료, 2026년 물가 고정). 상위권·대기업 값은 쓰지 않음. MVP 8개 ⭐. 상태 🟡

## 규칙
- 직업은 **직업 단위 하나**. 회사 규모(대기업·중소기업)로 나누지 않음
- 연봉 = 하루(1년) 근무로 받는 1년치, 게임 1달(실제 2분)마다 1/12씩 입금
- 연차별 연봉 = `초봉 + (15년차 - 초봉) × min(연차/15, 1)` × 성과·직급 보정([근무](work.md))
- 표 값은 "보통 사람"의 중앙값. 성과·승진·이직으로 위로 올라감(상위권은 플레이로 도달)
- 팬 직업(연예인·유튜버): 고정 연봉 없음. 수입 = **팬 수 × 단가** ([팬](../people/fans.md))
- 자영업자: 고정 연봉 없음. 매출·비용으로 계산 ([사업](../economy/business.md))
- 실제 회사·학교 이름 대신 일반 이름(예: "병원", "회사")
- 서울 밖 근무지(광부의 광업소 등)는 **맵 없이 근무 화면**(자동 근무·미니게임)으로만 처리 ([근무](work.md))
- 범죄 직업 없음. 무직·노숙은 직업이 아니라 상태([노숙·재기](../life/homeless.md))

## 열린 질문
- 출처 1개인 직업(요양보호사·회계사·은행원·직업군인·연구원·기자·조종사·건설·환경미화원·정비사·자영업·야구) → 제안: 지금 값으로 두고, 임금직업포털에서 직접 조회해 확정
- 의사 기준 → 제안: 수련 5년은 7,000 고정, 전문의 이후 18,500까지 오름(개원하면 [근무](work.md) ×1.3)
- 부모 직업 선택지도 32개 그대로? → 제안: 그대로, 연예인·유튜버 부모는 "재력 무작위 폭 큼"
