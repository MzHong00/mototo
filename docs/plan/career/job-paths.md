# 직업 조건

> 직업마다 실제와 같은 길(학력 → 시험 → 수련). 해금은 없고, 조건만 맞추면 누구나 갈 수 있음. 상태 🟡

## 규칙
- 길 = 단계 목록. 단계마다 **조건**(학력·시험·능력치·돈·나이)을 맞춰야 다음 단계
- 구직: 휴대폰 "구인" 앱에서 지원 → 조건 확인 → 합격 확률([자격·시험](exams.md)) → 다음 해 1월 출근
- 나이 제한이 없는 직업은 언제든 다시 도전 가능(이직·재도전). 늦을수록 초봉 -5%/10년(제안)
- 최소 능력치 미달이면 지원 버튼은 보이지만 "조건 부족" 표시 + 무엇이 부족한지 안내
- 나이는 남자 기준 군 복무(1.5~3년) 제외. 군 전후 순서는 자유

## 열린 질문
- 연습생 기간 압축? → 제안: 연습생 1년 = 하루 그대로, 데뷔 확률 매년 15%(매력·감성 보정)
- 야구선수 길이 7살부터라 늦게 못 감 → 제안: 실제처럼 16살 전에 야구부 아니면 불가(유일한 예외)
- 공무원 나이 제한 → 제안: 실제처럼 없음(9급 18살↑)
