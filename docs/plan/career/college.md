# 수능·대학

> 고3 끝에 수능 이벤트 → 9등급 → 대학 등급·학과 선택. 대학 하루 = 1년. 상태 🟡

## 규칙
- **수능**: 18살 하루 끝(11월) 이벤트. 수능 점수 = 학업력 + 무작위 ±10 + 당일 컨디션(건강·기분 각 30 미만이면 -5)
- 같은 해 NPC 50만 명 분포와 비교 → 백분위 → **9등급**(실제 비율)
- 대학 지원: 등급으로 갈 수 있는 대학 등급·학과 목록에서 최대 3곳(실제 정시 가·나·다군)
- 합격선 근처면 확률 합격(경계 ±0.5등급에서 50%)
- 떨어지면: 재수(1년, 학업력 +3 + 학원비) / 전문대 / 바로 취업
- 내신(학종) 길은 MVP에서 수능과 같은 공식에 내신 등급을 섞음: `최종 = 수능×0.7 + 내신×0.3`
- 대학 이름은 실제 학교를 쓰지 않음. 등급 이름만 씀
- 대학 생활: 학점(A~F) = 학업력 + 출석. 동아리·연애·알바·휴학 카드

- 휴학: 1년 단위, 최대 2년. 남자는 보통 1~2학년 뒤 [병역](military.md)

## 다른 그룹과 연결

- [연애·결혼](../people/romance.md): 대학 카드에서 연애 시작

## MVP / 나중
- MVP: 수능 1회+재수, 대학 등급 5개(의대·S·A·B·전문대), 계열 3개(인문·이공·의학)
- 나중: 교대·사관학교·예체능 실기, 대학원(석·박사), 편입, 학점 미니게임

## 열린 질문
- 재수 횟수 제한? → 제안: 제한 없음, 다만 해마다 기분 -10
- 학과를 고르는 시점 → 제안: 수능 뒤 지원 화면에서 대학 등급 × 학과 표로 고름
- 대학 등급 이름 → 제안: "최상위대·상위대·중위대" 같은 일반 명칭
