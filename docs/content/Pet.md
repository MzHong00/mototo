# 펫 시스템 (Phase 12)

## 알 획득

특정 맵 고정 위치에 알 오브젝트(`PetEgg`) 배치. Space 키로 상호작용하면 **즉시 해당 펫이 도감에 등록**된다.  
이미 등록된 펫의 알과 상호작용하면 "이미 소지한 펫입니다" 토스트 출력 후 아무 일도 일어나지 않는다.  
알은 픽업 후 일정 시간이 지나면 리스폰된다. 리스폰 타이머는 `petStore.pickedEggs` 타임스탬프로 개인별 관리.

### 알 속성 (Element)

알의 **색상**이 속성을 나타내며, 어떤 펫이 등록될지 결정한다.  
빛·어둠은 **특수 속성** — 다른 속성에는 없는 고유한 스킬 효과를 가지며, **숨겨진 위치**에만 등장한다.

| 색상   | 속성 | 영문        | 색상 코드 | 역할 및 특화                                       |
| ------ | ---- | ----------- | --------- | -------------------------------------------------- |
| 빨강   | 불   | `fire`      | `#FF4422` | 자동공격 데미지 특화                               |
| 파랑   | 물   | `water`     | `#3388FF` | HP 회복 특화                                       |
| 초록   | 자연 | `nature`    | `#44BB44` | 복합 버프 효율 상승                                |
| 노랑   | 번개 | `lightning` | `#FFDD00` | 자동공격 주기 단축 (빠른 타수)                     |
| 보라   | 마법 | `arcane`    | `#9933CC` | 주인 스킬 쿨타임 단축                              |
| 주황   | 땅   | `earth`     | `#CC7722` | DEF 버프 특화                                      |
| 하늘색 | 바람 | `wind`      | `#88DDFF` | 이동속도 버프 특화                                 |
| 분홍   | 요정 | `fairy`     | `#FF88CC` | 골드·아이템 드롭률 버프                            |
| 흰색   | 빛   | `light`     | `#F0F0FF` | 광역 힐 + 보호막 동시 제공 (고유 스킬 특화)        |
| 검정   | 어둠 | `shadow`    | `#222233` | 주인 스킬 데미지 증폭 + 크리티컬 (고유 스킬 특화) |

### 맵별 알 출현

- **보스방에는 알 없음**
- 불·번개·마법 속성 알은 추후 맵 추가 시 배치 예정

| 지역      | 알 속성    |
| --------- | ---------- |
| 에버그린  | 자연, 요정 |

| 단풍골    | 땅, 바람   |
| 황혼 벌판 | 미구현     |

## 활성 펫

- 펫 도감에서 펫 1마리를 **활성화**하면 전투에 동행한다
- 활성 펫: 자동공격 + 특수스킬 발동
- 펫 창(`PetWindow`) → 펫 도감 탭에서 언제든 교체 가능

---

## 펫 레벨

각 펫은 개별 레벨을 가지며, 레벨이 오르면 새로운 스킬 슬롯이 해금된다.

**레벨 획득:** 활성 상태일 때 주인이 몬스터를 처치하면 EXP를 획득한다.

| 레벨 | 해금 내용               |
| ---- | ----------------------- |
| 1    | 스킬 1 (현재 구현됨)    |
| 5    | 스킬 2 (추후 추가 예정) |
| 10   | 스킬 3 (추후 추가 예정) |

- 최대 레벨: **10**
- 레벨은 개체별로 유지됨 — 활성 펫 교체 시 EXP 그대로 보존

---

## 펫 도감

알과 상호작용하면 즉시 도감에 등록되며, 최초 등록 시 **영구 능력치 보너스(ATK +1)** 를 획득한다.  
같은 펫을 중복으로 발견해도 보너스는 최초 1회만 적용된다.  
도감에서 원하는 펫을 선택해 **활성화**할 수 있다.

도감 최대 등록 수: **84종** — 전체 완성 시 ATK +84

## 자동공격

| 항목        | 값                               |
| ----------- | -------------------------------- |
| 인식 범위   | 반경 3m                          |
| 공격 데미지 | 주인 totalAtk × 30%              |
| 공격 주기   | 1.5초                            |
| 대상 선택   | 범위 내 가장 가까운 몬스터 1마리 |

---

## 펫 속성 정의

펫의 **속성(Element)** 은 알의 속성에서 이어진다. 속성이 펫의 스킬 테마와 역할 방향을 결정한다.

| 속성 | 스킬 테마                   | 특수스킬 방향                    |
| ---- | --------------------------- | -------------------------------- |
| 불   | 화염 공격·연소              | 범위 화염 공격                   |
| 물   | 회복·방어                   | 주인 HP 회복                     |
| 자연 | 복합 버프·상태이상          | 주인 모든 스탯 소폭 버프         |
| 번개 | 빠른 타격·감전              | 빠른 연속 타격                   |
| 마법 | 스킬 증폭·쿨타임            | 주인 스킬 데미지 증폭            |
| 땅   | 방어·디버프                 | 주인에게 보호막 부여             |
| 바람 | 이동·넉백                   | 주인 이동속도 일시 대폭 상승     |
| 요정 | 드롭·골드                   | 몬스터 처치 시 골드 추가 드롭    |
| 빛   | 광역 힐 + 보호막 동시 발동  | 광역 힐 + 보호막 동시 발동       |
| 어둠 | 스킬 데미지 증폭 + 크리티컬 | 주인 스킬 데미지 증폭 + 크리티컬 |

---

## 특수스킬

펫마다 **고유한 특수스킬 1개**를 보유한다. 전투 중 쿨타임 경과 시 자동 발동.  
쿨타임은 펫마다 개별 설정되며, 각 펫의 스킬명·스킬 효과는 펫 종류 항목에 기재.

---

## PetWindow 탭 구조

| 탭      | 아이콘 | 설명                                            |

| 펫 스킬 | ✨     | 현재 활성 펫 스킬 목록 + 쿨타임 게이지          |
