# 마을

> 본 맵 가운데의 안전 지대. 기본 구조물이 놓여 있고, NPC 빼고 전부 철거해 건축으로 다시 짓는 나만의 마을.

## 확정 사항

- **1인 게임**. 다인은 나중.
- 기본 구조물이 처음부터 있다.
- **NPC를 제외한 모든 것**은 철거 가능. 건축 기술로 재건 ([Housing.md](Housing.md), [Skills.md](Skills.md)).
- 사육 기술로 동물을 마을에 배치 ([Animals.md](Animals.md)).
- 마을마다 전투맵 입구 1개 ([World.md](World.md)).

## 규칙과 수치

### 마을 구역

- 본 맵 안 약 48×48칸. 지도 `marks`의 `V` 칸 = 안전 지대(전투 없음, 몬스터 안 들어옴).
- 건축 가능 칸 = `b`. 처음 구조물은 모두 `b` 칸 위에 있다.
- 마을 5곳 모두 같은 규칙. 꾸민 상태는 마을마다 따로 저장.

### 기본 구조물 (마을당 초기값)

| 구조물 | 칸 | 개수 | 기능 | 철거 |
| --- | --- | --- | --- | --- |
| 광장 바닥 | 12×12 | 1 | 행사·NPC 모임 | 가능 |
| 게시판 | 2×1 | 1 | 의뢰([Quests.md](Quests.md)) | 가능 (치우면 의뢰는 NPC에게 직접) |
| 우체통 | 1×1 | 1 | 우편 | 가능 |
| 상점 | 6×6 | 2 (잡화점 + 마을 전문 상점 1) | 사고팔기([Economy.md](Economy.md)) | 가능 (주인 NPC는 노점으로) |
| 내 집 | 8×8 | 1 (에버그린만) | 집 꾸미기, 내부 씬([Housing.md](Housing.md)) | 가능 |
| 주민 집 | 6×6 | 3~4 | NPC 거주 | 가능 (아래 규칙) |
| 우물·가로등·울타리·벤치 | 1×1~1×3 | 여러 개 | 장식 | 가능 |
| 다리 | 3×5 | 0~2 | 개울 건너기 | 가능 (대신 경사로 우회로가 반드시 있음) |

철거 불가 (지형 취급): 맵 출구, 전투맵 입구, 선착장, NPC, 텐트.

- 내 집은 **첫 마을(에버그린) 1채만**. 다른 마을엔 집이 없다(별장은 나중). Housing과 통일 — 더 단순한 쪽.

### 철거·재건 규칙

| 항목 | 규칙 |
| --- | --- |
| 철거 | 편집 모드([Housing.md](Housing.md))에서 구조물 선택 → 확인창 → 3초 연출. 재료 50% 돌려받음 |
| 기본 구조물 재건 | "원래 설계도"가 남는다. 재료 100%로 같은 자리·다른 자리 모두 가능 |
| 새 건물 | 건축 기술 등급으로 설계도 해금 |
| 배치 | 1칸 격자, 90° 회전. `b` 칸 위에만. 길(`p`)·출구 3칸 이내 막기 금지 |
| 길 보장 | 배치 후 마을 입구 ↔ 모든 출구·전투맵 입구가 걸어서 이어져야 함. 막히면 배치 거부 |
| 되돌리기 | 편집 모드 안에서 Ctrl+Z 20단계(철거 포함, 재료 그대로 복구). 모드를 나가면 기록 삭제 |
| 주민 집 철거 | NPC는 마을에 남고 광장에 텐트(1×1, 철거 불가)를 친다. 집을 새로 지으면 이사 |
| 상점 철거 | 상점 주인은 노점(2×2)에서 같은 기능 유지 |

### NPC 자리

- NPC마다 집·일터·쉼터 3곳을 가진다. 자리는 구조물에 붙어 있다 (예: 상점 계산대, 우물 옆 벤치).
- 구조물을 철거하면 그 자리는 가장 가까운 같은 종류 자리로 옮긴다. 없으면 광장.
- 생활 시간표와 AI 대화는 [Npc.md](Npc.md).
- 마을당 NPC 2~3명(에버그린 3, 나머지 2). 초기 전체 12명, 맵당 상한 6 ([Npc.md](Npc.md)).

### 동물 배치 구역

- 동물은 동물 집 주변 활동 구역(반경 6칸) 또는 울타리 안에서 돌아다닌다. 지도의 `a` 칸은 처음부터 있는 방목 구역.
- 마을당 동물 최대 **20마리**, 집당 수용(닭장 4·외양간 4·개집 1·캣타워 1)은 [Animals.md](Animals.md)가 기준.
  - 통일 이유: 덜 가혹한 쪽(20). 성능은 종당 메시 공유·화면 밖 정지로 감당.
- 강아지·고양이는 마을 전체(`V`)를 돌아다닌다.

## 데이터 모델

배치·건물 정의는 [Housing.md](Housing.md)의 `BuildingDef`·`PlacedObject`를 그대로 쓴다. 마을 추가분만:

```ts
/** BuildingDef 에 더하는 필드 */
interface NpcSlotDef { role: 'home' | 'work' | 'rest'; offset: [number, number] } // BuildingDef.npcSlots

interface VillageDef {
  mapId: string;                // 'evergreen'
  initial: PlacedObject[];      // 기본 구조물 (original: true)
  npcIds: string[];
  shopIds: string[];            // 잡화점 + 전문 상점 (Economy.md)
}

/** 저장: 마을별 현재 상태 (Save.md `village`) */
interface VillageState {
  mapId: string;
  objects: PlacedObject[];
  removedOriginals: string[];   // 철거한 기본 구조물 defId (원래 설계도)
  animals: AnimalData[];        // Animals.md
}

export const VILLAGE_REFUND_RATE = 0.5;
export const VILLAGE_MAX_ANIMALS = 20;   // = ANIMAL.maxInVillage
export const EDIT_UNDO_STEPS = 20;
```

## 단계 (MVP → 이후)

1. **MVP**: 에버그린 기본 구조물 배치(고정, 철거 없음). `V` 안전 지대. NPC 자리 표시만.
   - 수용 기준: 마을 안에서 몬스터가 생기지 않음. 구조물은 종류별 인스턴싱.
2. 편집 모드: 철거·재건·격자 배치·길 막힘 검사. `VillageState` 저장.
   - 수용 기준: 출구로 가는 길을 막는 배치는 빨간 미리보기로 거부. 주민 집을 철거하면 그 주민이 광장 텐트에서 산다.
3. 동물 구역과 울타리.
4. 마을 5곳 각자 꾸미기, 마을별 특산 구조물.

## 열린 질문

- 맵 출구·전투맵 입구도 옮길 수 있게? — 제안 기본값: 불가 (지형 취급).
- 내 집이 마을마다 있나? — 정리됨: 에버그린 1채만. 다른 마을 별장은 나중.
- 철거 환급률? — 제안 기본값: 50%.
- 마을 구역 밖(필드)에도 건축 허용? — 제안 기본값: 불가.
