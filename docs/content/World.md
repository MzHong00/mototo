# 세계 구조

> 계층: **세계 지도 → 마을(노드) → 갈래길(필드·던전)**

## 세계 지도

- 3D 지도 위에 마을 노드들이 길로 연결된다. 마을 사이 이동은 지도에서 고른다.
- 각 맵은 던전이 아니다. **모든 맵의 중심은 마을**이다.

## 마을과 갈래길

- 마을에는 상점·NPC·집터가 있다. 안전 지대(전투 없음).
- 마을에서 갈래길이 하나 이상 뻗어 나간다. 갈래길끼리 이어질 수도 있다.
- 갈래길 종류: 채집 숲, 낚시터, 광산, 몬스터 필드, 던전

```
            [광산] ── [깊은 광산]
               │
[숲길] ── (에버그린 마을) ══ (블루 코브 항구) ── [해변 낚시터]
               │
           [초원 필드]
```

`( )` 마을 · `[ ]` 갈래길 · `══` 마을 간 길

## 데이터 모델 (초안)

```ts
type NodeKind = 'village' | 'gather' | 'fishing' | 'mining' | 'combat' | 'dungeon';

interface MapNode {
  id: string;            // 'evergreenVillage'
  name: string;          // '에버그린 마을'
  kind: NodeKind;
  village: string;       // 소속 마을 id (마을 자신이면 자기 id)
  position: [number, number, number]; // 세계 지도 위 좌표
  links: string[];       // 연결된 노드 id
}
```

새 마을·갈래길은 목록에 한 줄 추가로 늘린다.

## 초기 마을 (기존 지역 이름 재활용)

| 마을 | 분위기 | 갈래길 후보 |
| --- | --- | --- |
| 에버그린 마을 | 따뜻한 숲 마을 (시작) | 숲길(채집), 초원(전투), 광산(채광) |
| 블루 코브 항구 | 바닷바람 항구 | 해변 낚시터, 산호 암초, 파도 동굴(던전) |
| 단풍골 마을 | 붉은 단풍 산골 | 단풍 숲(채집), 산 개울(낚시), 바위 협곡(채광·전투) |
