# 세계 구조

> 첫걸음 섬(작은 맵) → 본 맵 5개(큰 마을 맵, 가장자리 출구로 이어짐) → 마을마다 전투맵 1개(방 그래프). 미니맵과 노선도 같은 지도로 길을 찾는다.

## 확정 사항

- 캐릭터 생성 직후 맵은 작아도 된다. 본 맵은 크게, 초기 5개.
- 마을마다 전투맵 1개. 마을의 전투맵 입구로 들어간다.
- 전투맵 안에 갈래가 여러 개. 엘리트방·보스방이 있다.
- 미니맵과 지도가 있다. 지도는 3D 느낌 + 지하철 노선도처럼 깔끔하게.
- 1인 게임.

## 규칙과 수치

### 맵 목록 (초기값)

| id | 이름 | 크기(칸) | 분위기 | 지형 특징 | 출구 → 도착 | 전투맵 |
| --- | --- | --- | --- | --- | --- | --- |
| `start-island` | 첫걸음 섬(가칭) | 48×48 | 조용한 아침 바닷가 | 0~2층, 모래·풀. 지금 테스트 섬 재활용 | 남 선착장 → 에버그린 북 | 없음 |
| `evergreen` | 에버그린 마을 | 144×144 | 따뜻한 숲 마을 (시작) | 1~2층 언덕, 개울, 숲 | 북 선착장 → 첫걸음 섬 · 동 → 블루 코브 · 서 → 단풍골 | 도토리 숲굴 (북서 숲) |
| `bluecove` | 블루 코브 항구 | 160×128 | 바닷바람 항구 | 해안 절벽, 넓은 모래, 부두 | 서 → 에버그린 · 북 → 달빛 호숫가 | 파도 동굴 (동쪽 절벽) |
| `danpung` | 단풍골 마을 | 128×160 | 붉은 단풍 산골 | 3~5층 고저차, 계곡, 긴 경사로 | 동 → 에버그린 · 북 → 구름 고원 | 바위 협곡 (북 계곡) |
| `cloudhill` | 구름 고원 마을 | 144×144 | 바람 부는 고원 | 4~7층 평평한 대지, 낭떠러지 | 남 → 단풍골 · 동 → 달빛 호숫가 | 바람 탑 (고원 끝) |
| `moonlake` | 달빛 호숫가 마을 | 160×160 | 밤이 예쁜 호수 | 가운데 큰 호수, 섬·다리 | 남 → 블루 코브 · 서 → 구름 고원 | 잠긴 사원 (호수 섬) |

- 연결은 고리 모양: 에버그린 ─ 블루 코브 ─ 달빛 호숫가 ─ 구름 고원 ─ 단풍골 ─ 에버그린. 어느 쪽으로 돌아도 된다.
- 해금 순서(권장 동선): 첫걸음 섬 → 에버그린 → (블루 코브 | 단풍골) → (달빛 호숫가 | 구름 고원).
- 본 맵 한 장 = 마을(가운데, 약 48×48) + 둘레의 채집 숲·낚시터·광산·필드. 예전 "갈래길"은 별도 맵이 아니라 **본 맵 안의 구역**이다.
- 마을 구역은 안전 지대(전투 없음). 구역 밖 필드에는 약한 몬스터만. 엘리트·보스는 전투맵에만.
- 시작 섬 이름·크기 통일: 표시 이름 "첫걸음 섬"(가칭), 48×48(지금 테스트 섬 재활용이 가장 단순). 튜토리얼은 [Quests.md](Quests.md).

### 맵 사이 이동

| 항목 | 규칙 |
| --- | --- |
| 출구 모양 | 맵 가장자리 길 끝, 폭 3~5칸. 아치·표지판으로 표시. 표지판에 도착 맵 이름 |
| 발동 | 출구 칸에 들어서면 바로 이동 (확인창 없음). 되돌아오는 실수 방지: 도착점은 출구에서 안쪽 3칸 |
| 연출 | 0.3초 페이드 아웃 → 맵 빌드 → 0.3초 페이드 인. 로딩 목표 500ms 이하 |
| 도착 | 짝 도착점(`entryId`)에 출구 반대 방향을 보고 선다 |
| 캐시 | 최근 맵 2장의 지형 버퍼를 메모리에 둔다 (왕복 즉시) |
| 선착장 | 첫걸음 섬 ↔ 에버그린은 배. 선착장에서 상호작용 키 → 확인창 → 이동 |
| 전투맵 입구 | 문·동굴 입구에서 상호작용 키 → 확인창("들어갈까요?") → 전투맵 입구방 |
| 빠른 이동 | 지도에서 **방문한 마을 역**을 고르면 그 마을 광장으로 이동. 무료. 전투맵 안에서는 불가 |

### 전투맵 (방 그래프)

- 전투맵 = 작은 방(각각 작은 칸 지도) 여러 개를 문으로 이은 그래프. 방 하나씩 로딩한다.
- 흐름: 입구방 → 2~3갈래 → 갈래가 엘리트방 앞에서 합류 → 휴식방 → 보스방.
- 방에 들어오면 문이 잠긴다. 적을 다 잡으면 열린다. 각 문 위에 **다음 방 종류 아이콘**이 뜬다(고르는 재미).

| 방 종류 | 크기(칸) | 내용 | 규칙 |
| --- | --- | --- | --- |
| 입구 `entry` | 16×16 | 적 없음. 나가는 문 | 항상 1개 |
| 전투 `combat` | 24×24 | 일반 몬스터 2~3무리 | 다 잡으면 문 열림 |
| 엘리트 `elite` | 28×28 | 엘리트 1 + 졸개 | 입구와 바로 붙지 않음. 보상 좋음 |
| 보물 `treasure` | 16×16 | 상자 1 | 적 없음 |
| 채집 `gather` | 20×20 | 광석·약초 칸 3~5 | 적 없음. 채집 기술 경험치 |
| 휴식 `rest` | 16×16 | 체력 전부 회복, 모닥불 | 보스방 바로 앞에 반드시 1개 |
| 보스 `boss` | 36×36 | 보스 1 | 끝. 깨면 나가는 문 → 마을 입구 |

- 문 규칙: 한 방에서 나가는 문 1~3개. 문은 방의 북·동·서 벽 가운데. 들어온 문(남쪽)은 되돌아가기 불가.
- 깊이(층): 입구 0 → 보스 5~6. 한 판 10~15분 목표.
- 재입장·초기화:
  - 전투맵을 나가거나 쓰러지면 진행(방 위치)이 사라진다. 다시 들어가면 입구방부터, 몬스터·상자 모두 새로.
  - 쓰러지면 그 마을의 전투맵 입구 앞(마을 안)으로 돌아온다. **얻은 것은 하나도 잃지 않는다** ([Combat.md](Combat.md) 쓰러짐 규칙과 같음).
  - 보스 첫 처치 기록은 영구. 하루 첫 보스 처치 보너스는 하루 초기화([Time.md](Time.md))에 다시 생김.
- 고정 vs 절차 생성: **MVP는 손으로 짠 고정 그래프** (전투맵당 방 9~11개). 방 지도는 종류별 틀 2~3개를 돌려쓴다. 나중에 같은 틀로 그래프만 섞는 반자동 생성으로 확장.

예: 도토리 숲굴 (고정 그래프)

```
            ┌─ combat ── treasure ─┐
entry ──────┼─ combat ── gather ───┼── elite ── rest ── boss
            └─ combat ── combat ───┘
```

### 미니맵

| 항목 | 값 |
| --- | --- |
| 위치·크기 | 화면 오른쪽 위, 160×160px 원형. 설정에서 끄기 가능 |
| 방향 | 북쪽 고정 (카메라 각도가 고정이라 화면과 일치). 내 위치는 가운데 화살표, 바라보는 방향으로 회전 |
| 보이는 범위 | 반경 24칸 |
| 그리기 | 맵 들어올 때 칸 데이터로 오프스크린 캔버스(1칸=2px) 1회 그림. 매 프레임은 CSS `transform`으로 이동만 |
| 색 | 바닥 종류 색 + 높이 층마다 8% 어둡게. 절벽 경계는 짙은 선 |
| 아이콘 | 출구(화살표), 전투맵 입구(칼), 상점(주머니), 내 집(집), NPC(점), 동물(발자국). DOM 위에 따로, 초당 10회 갱신 |
| 전투맵 안 | 칸 대신 방 그래프 축소판 (지나온 방·현재 방·다음 문 종류) |

### 지도 (전체 지도 화면)

- 열기: 지도 키(기본 M). 창 열림 시 정지 규칙은 [Ui.md](Ui.md) (전투맵 안에서는 정지, 밖에서는 시간 흐름·입력만 막음).
- 표현: 노선도. **역 = 본 맵**, **노선 = 맵 사이 길**, 마을 역에서 짧은 가지로 전투맵 역.
- 시각 규칙:
  - 선은 가로·세로·45°만 (옥타리니어). 역은 정수 격자 위.
  - 실제 지리보다 깔끔함 우선. 역 간격은 균일.
  - 노선 색: 숲선 초록 `#5fae6b`, 바다선 파랑 `#4f9fd6`, 산선 주황 `#e08a4f`, 고원선 하늘 `#8ab8e8`, 호수선 보라 `#9b87d6`. 한 길 = 한 색.
  - 역: 흰 원 + 굵은 테두리. 마을 역은 크게, 전투맵 역은 작은 마름모.
  - 3D 느낌: 지도 판을 `rotateX(35°)`로 살짝 눕히고 얇은 두께·그림자. 선은 판 위에 살짝 떠 있는 띠.
- 현재 위치: 내 캐릭터 머리 아이콘이 역 위에서 통통 뛴다. 맵 안 위치까지는 안 보여줌(미니맵 담당).
- 해금 안 된 곳: 역은 회색 "?", 이어지는 선은 점선. 이웃한 역만 "?"로 보이고 그 너머는 숨김.
- 구현 추천: MVP는 **SVG + CSS 3D transform** (R3F 씬 추가 없음, 가볍다).

## 데이터 모델

코드 기준: `src/types/world.ts` (구현 중). 출구·도착점은 지형 `marks` 글자로 찍는다 ([Terrain.md](Terrain.md)).

```ts
type Dir = 'n' | 'e' | 's' | 'w';
type RoomKind = 'entry' | 'combat' | 'elite' | 'treasure' | 'gather' | 'rest' | 'boss';
type ExitMode = 'walk' | 'boat' | 'dungeon'; // walk=밟으면 이동, 나머지는 상호작용+확인창

interface TravelTarget { map: string; entry: string }  // 맵 id + 도착점 글자(1~9, @)

interface MapExit {
  mark: string;          // 출구 글자 A~H (D 제외). 같은 글자 칸들 = 한 출구
  to: TravelTarget;
  mode: ExitMode;
  label: string;         // 표지판·확인창에 보일 목적지 이름
}

interface MapDef {
  id: string;            // 'evergreen' · 'acorn-hollow/r3'
  name: string;          // '에버그린 마을'
  kind: 'start' | 'main' | 'room';
  tiles: TileMapData;    // Terrain.md
  exits: MapExit[];
  dungeonId?: string;    // 전투맵 방이면 소속 전투맵
  roomKind?: RoomKind;
  bgm?: string;          // Audio.md
}

/** 노선도 */
interface WorldNode {
  id: string;            // 맵 id 또는 전투맵 id
  label: string;
  kind: 'start' | 'village' | 'dungeon';
  grid: [number, number];       // 노선도 격자 좌표(정수)
  fastTravel?: TravelTarget;    // 빠른 이동 도착점(마을 광장 @)
}
interface WorldLine { id: string; color: string; stops: string[] } // 인접 역은 0/45/90°

/** 전투맵 */
interface DungeonRoom {
  id: string;            // 'r3'
  kind: RoomKind;
  next: string[];        // 다음 방 id (북·동·서 문 순서)
  template?: string;     // 방 칸 지도 틀 id
  spawns?: string[];     // 몬스터 무리 id
}
interface DungeonDef {
  id: string;            // 'acorn-hollow'
  name: string;          // '도토리 숲굴'
  village: string;
  returnTo: TravelTarget; // 나가거나 쓰러지면 돌아갈 곳(마을 전투맵 입구 앞)
  rooms: DungeonRoom[];  // 첫 방 = 입구방
}

/** 저장 */
interface WorldProgress {
  visited: string[];
  bossCleared: string[];        // 전투맵 id
  lastBossBonusDay?: string;    // 'YYYY-MM-DD' (Time.md 날짜 키)
}
```

검사(개발용): 모든 출구의 `to.entry` 글자가 도착 맵에 있음, 모든 방이 입구에서 도달 가능, 보스 직전 휴식방, 엘리트가 입구와 붙지 않음, 노선 인접 역 각도 0/45/90°.

## 단계 (MVP → 이후)

1. **MVP**: 첫걸음 섬(48) + 에버그린(144) 2장. 걸어서 출구 이동·페이드. 미니맵(캔버스 1회 그림). 전투맵 1개(도토리 숲굴, 고정 그래프, 방 틀 4종).
   - 수용 기준: 출구 밟고 1초 안에 도착 맵에서 조작 가능. 왕복 10회해도 메모리 증가 없음. 미니맵 켜도 프레임 차이 1ms 이하.
2. 본 맵 5장 전부 + 노선도 지도(SVG) + 빠른 이동.
3. 전투맵 5개, 문 위 다음 방 아이콘, 보스 보너스.
4. 같은 방 틀로 그래프만 섞는 반자동 생성. 지도 핀 찍기.

## 열린 질문

- 첫걸음 섬으로 돌아갈 수 있나? — 제안 기본값: 가능 (선착장 배).
- 지도 열면 게임 멈춤? — 정리됨: 전투맵 안에서만 정지 ([Ui.md](Ui.md)).
- 빠른 이동 비용? — 제안 기본값: 무료, 방문한 마을끼리만.
- 쓰러짐 벌칙 — 정리됨: 잃는 것 없음, 진행만 초기화 (1인·생활게임 톤에 맞춰 덜 가혹한 쪽).
- 새 마을 2곳 이름(구름 고원·달빛 호숫가)? — 제안 기본값: 이대로.
- 전투맵 한 판 중 나가기(포기) 가능? — 제안 기본값: 휴식방에서만 "나가기" 문 제공.
