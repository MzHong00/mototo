# 집짓기

## 개요

- 마을의 집터에 내 집을 갖는다. (집터를 마을마다 둘지, 한 곳만 둘지는 미정)
- 집 안팎에 가구를 배치·회전·삭제한다. 격자 단위 배치로 시작한다.
- 가구는 채집·채광·낚시 재료로 **제작**하거나 상점에서 산다.

## 단계

1. 집 내부 한 칸, 격자 배치, 가구 몇 종
2. 가구 색 변경 (캐릭터와 같은 틴트 방식)
3. 집 확장, 마당·외관 꾸미기
4. 다른 플레이어 집 방문 (서버 연동 후)

## 기술 메모

- 같은 가구는 인스턴싱으로 묶어 그려 성능을 지킨다.
- 배치 도구는 개발용 맵 에디터로도 재사용한다.
