## 세부 목록

### 캐릭터 — Character.md
- ✅ 몸체 1개 + 파츠 갈아입기, 성별(여·남, 성별별 머리)
- ✅ 파츠: 머리, 얼굴, 상의, 하의, 신발 / 색 바꾸기 (머리·상의·하의·신발·피부·눈)
- ✅ 닉네임 규칙 (2~12자), 머리 흔들림, 눈 깜빡임, 툰 음영, 외곽선
- 🟡 시작 외형 최소(티셔츠·반바지·운동화), 나머지는 외형 기술로 해금
- 🟡 장비 8칸(무기·모자·상의·하의·한벌·신발·장신구·망토), 능력치 6개
- 🟡 외형 칸(글래머): 도감 기준 등록, 숨김, 세트 5개
- 🟡 무기 손 소켓(`Hand.R`), 기본 8색 무료 + 염색약 색
- ⬜ 체형(키·뼈 길이), 표정 바꾸기

### 조작 — Controls.md
- ✅ 기본 키: WASD·방향키 이동, Shift 달리기, Space 점프 (J 공격은 임시)
- ✅ 걷기·달리기·부드러운 가속, 점프 약 1m(공중 재점프 불가), 공격 모션
- ✅ 경사로, 35cm 이하 턱 자동 오르기, 떨어지면 시작 위치로 복구
- ✅ 카메라: 고정 각도로 따라오기
- 🟡 키 설정: 자판 그림에 기능 끌어 놓기·맞바꾸기 (메이플식), `settings` 저장
- 🟡 기본 배치: F 상호작용, I/T/E/O/N/M 메뉴, B 편집 모드, 1~8 빠른 칸
- ⬜ 카메라 회전·확대, 모바일 터치·게임패드

### 지형 — Terrain.md
- ✅ 1m 칸 글자 지도(층 + 바닥), 풀·길·모래·물(+돌바닥·막힘)
- ✅ 층 높이 1.2m, 절벽 자동, 경사로 `^ v < >`, 물가 투명벽, 바다 수면, 바닥 얼룩
- ✅ 32칸 청크 분할, 먼 바다 칸 생략
- ✅ 표시 글자(`marks`): 출구 A~H, 도착점 1~9, 광장 `@`, 전투맵 입구 `D`
- 🟡 표시 글자: 건축 `b`, 동물 `a`, 안전 지대 `V`
- ✅ 큰 맵 설계도(`MapBlueprint`) → 칸 지도: 노이즈 해안선, 층 칠하기, 길이 층 경계를 지나면 경사로 자동, 나무·바위 자동 배치(인스턴싱)
- ✅ 맵 검사 `npm run maps:check` (도달 가능·출구 짝·빌드 시간)
- ⬜ 강·폭포, 다리, 지도 편집 도구

### 세계 — World.md
- ✅ 첫걸음 섬(48×48) → 선착장 배로 에버그린 (튜토리얼 내용은 🟡)
- ✅ 본 맵 5개(128~160칸) 고리 연결: 에버그린 ─ 블루 코브 ─ 달빛 호숫가 ─ 구름 고원 ─ 단풍골 (지형·길·광장·나무까지, 건물·주민은 🟡)
- 🟡 본 맵 = 마을(안전 지대) + 채집 숲·낚시터·광산·필드 구역
- ✅ 마을별 전투맵 1개: 방 그래프(입구→3갈래→엘리트→휴식→보스), 문 위 다음 방 이름표, 방 종류 표식 물체
- 🟡 전투방 문 잠김·몬스터 (전투 구현 후)
- ✅ 출구 밟으면 이동(페이드 0.3초), 배·전투맵 입구는 확인창, 빠른 이동(방문한 마을)
- ✅ 미니맵(원형, 칸 지도 1회 그림 + 화살표·출구), 노선도 지도(SVG + 3D 기울임, M키, ? 이웃 역)
- ⬜ 반자동 방 그래프 생성, 지도 핀

### 마을 — Village.md
- 🟡 1인 게임, 마을 5곳 각자 꾸미기
- 🟡 기본 구조물(광장·게시판·우체통·상점 2·주민 집·장식), NPC 빼고 철거 → 재건
- 🟡 주민 집 철거 시 텐트, 상점 철거 시 노점, 길 막힘 검사
- 🟡 내 집은 에버그린 1채, 마을당 주민 2~3명, 동물 최대 20
- ⬜ 마을별 특산 구조물, 다른 마을 별장

### 시간 — Time.md
- 🟡 오전 5시 하루 초기화, 하루 처리(동물·바위·주민 기억)
- 🟡 낮·밤 4구간 실제 시각 연동 + "항상 낮"
- 🟡 날씨(맑음·흐림·비, 겨울 눈), 계절(실제 월)

### 기술 — Skills.md
- 🟡 생활 5(채집·채광·낚시·요리·목공), 외형 6(미용·분장·재봉·제화·세공·염색), 마을 2(건축·사육), 전투 직업
- 🟡 기술별 Lv 1~100, `100×1.05^(L-1)` 곡선, 레벨 차 감쇠
- 🟡 등급 5단계(견습~명인), 칭호·종합 칭호
- 🟡 레벨 해금(레시피·스타일·도구 등급·장소) + 도안
- ⬜ 캐릭터 레벨 없음(확정 방향) — 수치 밸런스는 플레이 테스트 후

### 채집 — Gathering.md
- 🟡 꽃·풀·가지·흙더미·과일나무·나무·단단한 나무·목화·버섯
- 🟡 맨손 / 도끼, 도구 등급 0~4(낡은~별빛, 채집·채광·낚시 공통)
- 🟡 실시간·하루 초기화 재생, 타격 손맛(히트스톱)

### 낚시 — Fishing.md
- 🟡 던지기·가짜 입질·진짜 입질(0.6초)·원형 타이밍 게이지
- 🟡 물고기 8종(바다·개울·연못, 시간대·날씨), 크기 기록, 완벽 낚기
- 🟡 낚싯대 등급, 미끼, 물결 자리

### 채광 — Mining.md
- 🟡 돌·구리·철·은·보석 바위·정동, 반짝점
- 🟡 곡괭이 등급, 하루 초기화 재생
- 🟡 용광로 제련(주괴, 채광 경험치)
- ⬜ 깊은 광산 무작위 층

### 전투 — Combat.md
- ✅ 공격 모션 1개
- 🟡 숨겨진 조건으로 전투 직업 해금(행동 누적 + 숨은 NPC 시험 제안)
- 🟡 스킬 A→B→C→D, 각 4단 콤보, 단계별 변형 2개 이상 골라 조립
- 🟡 입력 버퍼 0.2초·유지 0.6초, 캔슬 규칙, 능력치 6개·피해 공식
- 🟡 엘리트(일반 몹 + 수식어)·보스(예고·틈·2페이즈), 무기(몽둥이 등)
- 🟡 쓰러져도 잃는 것 없음, 전투맵 진행만 초기화

### 제작 — Crafting.md
- 🟡 제작대 8종(작업대·조리대·재봉틀·제화대·세공대·염색통·용광로·거울대)
- 🟡 레시피: 레벨·도안·발견 힌트 / 품질 4단계(실패 없음)
- 🟡 도구·무기·가구는 목공(대장 기술 없음)

### 아이템 — Items.md
- 🟡 분류 10종(재료·전리품·무기·장비·가구·건물·소비·염색약·동물·중요)
- 🟡 희귀도 5단계, 가방 24→60칸, 창고 60→300칸, 빠른 칸 8
- 🟡 도감(달성 보상, 물고기 최대 크기)

### 경제 — Economy.md
- 🟡 골드 하나, 가격 공식(재료 가치 × 제작·희귀도·품질 배율), 판매 50%
- 🟡 마을마다 잡화점 + 전문 상점 1, 되사기 10칸
- 🟡 진행 속도 목표(하루 30분 기준 수입)
- ⬜ 플레이어 간 거래 (다인 이후)

### 집짓기 — Housing.md
- 🟡 집 내부(0.5m 칸)·마을 외부(1m 칸) 같은 편집 모드
- 🟡 배치·회전·집어넣기·철거·옮기기, 되돌리기 20단계
- 🟡 건물 짓기(건축 Lv, 공사 시간), 집 확장 6×6→10×10→2층, 가구 색
- ⬜ 테라포밍, 소품 올리기

### 나날빛 — Nanalbit.md
- 🟡 하루 1회 누적 출석(오전 5시 기준)
- 🟡 9단계 색 (노을빛 ~ 흰빛, 365일)
- 🟡 보상: 염색약 색 계열, 이름표 테두리, 발밑 오라

### 의뢰 — Quests.md
- 🟡 첫걸음 섬 튜토리얼 11단계(약 10분)
- 🟡 주민 의뢰: 규칙이 목표·보상, AI는 사연만
- 🟡 일일 할 일 3개 + 도장 → 주간 선물

### 주민 — Npc.md
- 🟡 일과표 + 욕구(유틸리티 AI)로 스스로 생활
- 🟡 LLM 대화(서버 프록시, 오프라인 템플릿 대체), 하루 1회 기억 요약
- 🟡 호감도 5단계, 선물, 베이스 메시 커스텀 외형, 초기 12명
- ⬜ 주민끼리 대화·관계

### 동물 — Animals.md

- 🟡 돌봄(먹이·쓰다듬기·빗질), 친밀도 → 생산물 희귀도
- 🟡 배회 AI(길찾기 없음), 반려 동물 따라오기·선물
- ⬜ 번식, 탈것
