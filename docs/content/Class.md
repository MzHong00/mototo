### 특성 트리 (Tripod)

> 스킬 레벨업과 별개로, 각 스킬의 특성을 찍으면 스킬 동작 자체가 바뀐다.  
> Tier 1은 Lv. 3, Tier 2는 Lv. 5에 해금. 각 Tier에서 1개만 선택 가능.

**플레이 방향성 — 한 방향을 일관되게 찍으면 하나의 컨셉이 완성된다.**

| 방향 | 컨셉 | 풀빌드 느낌 |
| ---- | ---- | ----------- |
| 🔴 **광전사** | 단일 폭발, 처형, 쿨 초기화 연계 | 한 명씩 처형하고 쿨 초기화, 쉬지 않고 달린다 |
| 🔵 **지배자** | 광역, CC, 피해 반사·연계 | 도발로 끌어모아 회전베기·광역으로 한 번에 쓸어낸다 |

#### 베기 (`slash`)

| Tier | 🔴 광전사 | 🔵 지배자 |
| ---- | --------- | --------- |
| 1 (Lv.3) | **강타** — 데미지 +40%, 단일 타격 유지 | **회전베기** — 360° 원형 광역으로 전환 |
| 2 (Lv.5) | **맹공** — 동일 적 3타 연속 적중 시 다음 타격 데미지 +60% (조건부) | **충격** — 매 5타마다 피격 적 넉백 (0.3초 밀려남) |

#### 돌진 (`charge`)

| Tier | 🔴 광전사 | 🔵 지배자 |
| ---- | --------- | --------- |
| 1 (Lv.3) | **강습** — 돌진 거리 비례 데미지 (최대 ATK × 2.0) | **관통** — 경로 위 모든 적 연속 타격 |
| 2 (Lv.5) | **연쇄** — 적 처치 시 쿨타임 즉시 초기화 | **충격파** — 착지점 AOE 폭발 추가 |

| 2 (Lv.5) | **폭발적 분노** — 도발 해제 직후 다음 돌진·파멸의 일격 데미지 +80% (1회 한정) | **집결** — 도발 범위 내 적 모두 내 발 아래로 순간 당김 (CC) |

## 스킬 레벨업

스킬 포인트(레벨업 시 +1)로 각 스킬을 최대 레벨 5까지 강화.

| 스킬 종류   | 강화 효과                                     |
| ----------- | --------------------------------------------- |
| 공격 (단일) | 데미지 배율 +0.05× /레벨 (0.80 → 1.00)       |
| 공격 (광역) | 데미지 배율 +0.2× /레벨 (1.60 → 2.40)        |
| 회복        | 회복량 최대 HP × +5%p /레벨 (30% → 50%)      |
| 버프·이동   | 쿨타임 -10% /레벨 (100% → 60%)               |

## 특성 트리 시스템

> 현재 전사(Warrior)만 구현. 나머지 클래스는 동일 구조로 순차 적용 예정.

- 각 스킬은 **Tier 1 · Tier 2** 특성을 가짐. 각 Tier에서 선택지 중 **1개만** 선택 가능
- Tier 1 해금: 해당 스킬 레벨 3 / Tier 2 해금: 레벨 5
- 특성 선택은 **무료** (스킬 포인트 소모 없음). 언제든 자유롭게 변경 가능
- 특성이 선택되면 스킬의 **동작 자체**가 바뀜 (수치만 오르는 게 아님)
- `disabled` 표시 특성은 Phase 13 이후 구현 예정 (틱 버프 루프 시스템 필요)
