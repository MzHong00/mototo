# 사용자 확인할 결정

> 각 문서의 열린 질문 중 방향을 크게 바꾸는 것만 모았다. 지금은 **제안 기본값**으로 진행한다. 바꾸려면 해당 문서와 이 표를 함께 고친다.

## 검토자가 통일한 것 (뒤집으려면 확인)

| 주제 | 통일한 값 | 원칙 |
| --- | --- | --- |
| 쓰러짐 벌칙 | 잃는 것 없음. 전투맵 진행만 초기화 | 덜 가혹 |
| 마을 동물 상한 | 20마리, 집당 수용은 Animals 기준 | 덜 가혹 |
| 내 집 | 에버그린 1채만 | 더 단순 |
| 시작 섬 | "첫걸음 섬"(가칭), 48×48 | 더 단순 |
| 대장 기술 | 없음. 도구·무기 = 목공 | 더 단순 |
| 능력치 | hp·atk·def·crit·speed·gather 6개 | 더 단순 |
| 캐릭터 레벨 | 없음. HP·무기 착용은 직업 기술 레벨 | 사용자 확정(모든 성장 = 기술) |
| 빠른 칸 | 소비 8칸(키 1~8) + 스킬 4칸 | 더 단순 |
| 창 열림 정지 | 전투맵 안은 정지, 그 밖은 시간 흐름(설정·키 설정만 정지) | 덜 가혹 |
| 주민 집·상점 철거 | 가능(텐트·노점으로 기능 유지) | 사용자 확정 |
| 기본 8색 | 무료로 언제든 변경, 그 밖의 색만 염색약 | 덜 가혹 |
| 에셋 라이선스 | CC0만, 루트 `CREDITS.md` | 더 단순 |
