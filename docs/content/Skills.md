# 기술

> **모든 성장은 기술**이다. 캐릭터는 여러 기술을 동시에 가진다. 외형(머리·얼굴·옷)도 처음부터 주어지지 않고 기술로 해금한다.

## 기술 목록 (초안)

| 분류 | 기술 | 해금하는 것 |
| --- | --- | --- |
| 생활 | 채집 | 나무·과일·꽃 |
| 생활 | 채광 | 돌·광석·보석 |
| 생활 | 낚시 | 물고기 |
| 생활 | 요리 | 회복 음식 |
| 생활 | 목공 | 가구 |
| 외형 | 미용 | 머리 모양 |
| 외형 | 분장 | 얼굴(눈·입·표정) |
| 외형 | 재봉 | 상의·하의·한벌·망토 |
| 외형 | 제화 | 신발 |
| 외형 | 세공 | 모자·안경·장신구 |
| 외형 | 염색 | 색 (나날빛과 연결) |
| 마을 | 건축 | 마을 건물·구조물 |
| 마을 | 사육 | 동물 (강아지·고양이·소 …) |
| 전투 | 전투 직업 | 숨겨진 조건으로 해금 ([Combat.md](Combat.md)) |

- 기술마다 레벨과 경험치가 **따로** 있다. 해당 활동을 해야만 오른다.
- 만렙 100 (필요 경험치 곡선은 구현 시 결정)

## 기술별 등급

| 등급 | 레벨 | 예시 칭호 |
| --- | --- | --- |
| 견습 | 1~19 | 견습 낚시꾼 |
| 숙련 | 20~39 | 숙련 낚시꾼 |
| 장인 | 40~59 | 낚시 장인 |
| 달인 | 60~79 | 낚시 달인 |
| 명인 | 80~100 | 낚시 명인 |

## 종합 등급

모든 기술이 같은 등급 이상이면 종합 칭호가 붙는다.

| 조건 | 칭호 |
| --- | --- |
| 전 기술 숙련 이상 | 솜씨꾼 |
| 전 기술 장인 이상 | 만물 장인 |
| 전 기술 달인 이상 | 만물 달인 |
| 전 기술 명인 | 만물 명인 |
