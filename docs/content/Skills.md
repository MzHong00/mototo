# 생활·전투 기술과 등급

## 기술

| 기술 | 도구 | 하는 곳 | 얻는 것 |
| --- | --- | --- | --- |
| 전투 | 무기 | 몬스터 필드, 던전 | 전리품, 골드 |
| 채집 | 맨손·도끼 | 숲, 초원 | 나무, 과일, 꽃 |
| 낚시 | 낚싯대 | 낚시터, 해변, 개울 | 물고기 |
| 채광 | 곡괭이 | 광산, 협곡 | 돌, 광석, 보석 |
| (추가 예정) | | | 요리, 제작 |

- 기술마다 레벨과 경험치가 **따로** 있다. 해당 활동을 해야만 오른다.
- 만렙 100 (필요 경험치 곡선은 구현 시 결정)

## 기술별 등급

| 등급 | 레벨 | 예시 칭호 |
| --- | --- | --- |
| 견습 | 1~19 | 견습 낚시꾼 |
| 숙련 | 20~39 | 숙련 낚시꾼 |
| 장인 | 40~59 | 낚시 장인 |
| 달인 | 60~79 | 낚시 달인 |
| 명인 | 80~100 | 낚시 명인 |

## 종합 등급

모든 기술이 같은 등급 이상이면 종합 칭호가 붙는다.

| 조건 | 칭호 |
| --- | --- |
| 전 기술 숙련 이상 | 솜씨꾼 |
| 전 기술 장인 이상 | 만물 장인 |
| 전 기술 달인 이상 | 만물 달인 |
| 전 기술 명인 | 만물 명인 |
