# 지형

> 1m 칸 글자 지도(높이 층 + 바닥 종류)로 맵을 만든다. 메시·충돌체는 지도에서 자동 생성. 성능 최우선.

## 확정 사항

- 1m 칸 ASCII 지도. 높이 층 숫자 + 바닥 글자.
- 층 높이 1.2m (점프 약 1m로 못 오름) → 경사로로만 오르내림.
- 절벽 자동, 물가 투명벽.
- 성능 최우선: 드로우콜 최소, 반복 물체는 인스턴싱.

## 규칙과 수치

### 현재 구현 (✅)

| 항목 | 값 | 코드 |
| --- | --- | --- |
| 칸 크기 | 1m (`TILE_SIZE`) | `src/constants/game/terrain.ts` |
| 층 높이 | 1.2m (`LEVEL_HEIGHT`), 층 0~9 | 같음 |
| 바닥 글자 | `g` 풀 · `p` 흙길 · `s` 모래 · `w` 물 | `src/types/terrain.ts` |
| 경사로 | `^ v < >` 화살표 쪽으로 올라감. 같은 글자가 이어지면 그 칸 수에 걸쳐 한 층 오름 | `src/utils/terrain.ts` |
| 경사로 높이 숫자 | 아래층 값을 적는다 | |
| 절벽 | 이웃보다 높은 쪽 가장자리마다 벽 자동. 모래면 물가 벽 색 | |
| 물 | 물 칸 바닥은 땅보다 0.5m 낮음. 수면은 400m 판 1장 (`WATER_PLANE_SIZE`) | |
| 물가 투명벽 | 땅→물 경계에 3m 높이 충돌벽 (물에 못 들어감) | |
| 지도 밖 | 물로 취급 | |
| 바닥 얼룩 | 값 노이즈 2겹, 꼭짓점 위치 기반 → 칸 경계 안 보임 | |
| 메시 | 지도 전체 = 메시 1개 (드로우콜 1) + 트라이메시 충돌체 1개 | `useTerrainGeometry.ts` |
| 좌표 | 지도 가운데 = 월드 원점. 행 = z, 열 = x | |
| 예시 지도 | 첫걸음 섬 48×48 (옛 테스트 섬) | `src/constants/maps/startIsland.ts` (본 맵·전투맵 지도 구현 중) |

### 큰 맵용 확장

**1) 지도 층(레이어)** — 모두 같은 크기의 글자 배열

| 레이어 | 내용 | 비고 |
| --- | --- | --- |
| `heights` | 층 0~9 | 그대로 |
| `kinds` | 바닥 글자 | 새 글자 추가: `r` 돌바닥(마을 광장), `x` 막힘(지나갈 수 없는 칸, 숲 가장자리 등) |
| `marks` | 표시 글자, 없으면 `.` | 새로 추가. 아래 표 |
| `objects` | 물체 배치 목록 (글자 아님) | 나무·바위·건물. JSON 배열 |

**2) 표시 글자 (`marks`)**

| 글자 | 뜻 |
| --- | --- |
| `.` | 없음 |
| `A`~`H` (D 제외) | 출구 칸. 같은 글자끼리 묶어 한 출구 (`MapExit`은 [World.md](World.md)) |
| `1`~`9` | 도착점. 출구와 짝 (`MapEntry`) |
| `@` | 광장 = 빠른 이동·필드에서 쓰러졌을 때 도착점. 첫걸음 섬에선 시작 위치 |
| `D` | 전투맵 입구 (출구 글자와 겹쳐서 출구에선 D를 쓰지 않음 — 코드 `src/types/terrain.ts`와 같음) |
| `b` | 건축 가능 칸 (마을 집터·건물 터) |
| `a` | 동물 구역 |
| `n` | NPC 자리 (상세 역할은 Village 데이터에서) |
| `V` | 마을 안전 지대 (전투 없음) |

- 출구 칸은 바닥이 `p` 길이어야 하고 지도 가장자리에 붙어야 한다(검사).
- 지도 가장자리 중 출구가 아닌 땅은 **투명벽**을 둔다 (지금은 물만 막음 → 큰 육지 맵에서 밖으로 나가지 않게).

**3) 물체 배치 (`objects`)**

- 물체 = `{ type, x, z, rot }`. 같은 `type`은 `InstancedMesh` 1개 → 종류 수만큼 드로우콜.
- 충돌: 나무·바위는 원기둥/상자 충돌체를 타입별로 한 번에 생성 (고정 물체).
- 채집 물체(나무·광석)는 상태(베임, 다시 자람)를 따로 저장. 지도 데이터는 원본 위치만.

**4) 지도 파일 형식**

| 크기 | 형식 | 이유 |
| --- | --- | --- |
| 64칸 이하 (첫걸음 섬, 전투맵 방) | TS 파일 글자 배열 (지금처럼) | 손으로 고치기 쉬움 |
| 128~160칸 (본 맵) | 설계도 `MapBlueprint`(도형: 칠하기·길·표시·숲) → 불러올 때 칸 지도로 | 코드에서 구현 중(`src/types/world.ts`). PNG(아래)는 대안 |

- (대안) PNG 규칙: R = 층(0~9 → `층×25`), G = 바닥 종류 색표, B = 표시 색표. 빌드 때 스크립트가 `TileMapData`로 변환 (`scripts/mapFromPng.ts`).
- JSON: `objects`, 출구 목적지, 이름 등 글자로 못 담는 것.
- 같은 결과 타입(`TileMapData`)이라 지형 빌더는 하나.

**5) 청크 분할**

- 160×160 = 25,600칸. 맵 전체 메시 1개도 삼각형은 감당 가능하지만, 화면 밖까지 다 그린다.
- 결정: **32×32 청크로 나눔** (160맵 = 25청크, 같은 재질). 화면 밖 청크는 프러스텀 컬링으로 빠짐.
- 충돌체는 맵 전체 1개 유지 (Rapier 트라이메시는 내부 BVH가 있어 큰 메시도 빠름).
- 바다 칸 최적화: 땅과 2칸 이상 떨어진 물 칸은 바닥 사각형을 만들지 않음 (수면 판이 덮음).
- 48칸 이하 맵은 청크 1개 = 지금과 동일.

### 성능 목표 (160×160 본 맵)

| 항목 | 목표 |
| --- | --- |
| 지형 삼각형 | 12만 이하 (윗면 2/칸 + 절벽) |
| 지형 드로우콜 | 화면에 보이는 청크 수, 12 이하 |
| 물체 드로우콜 | 물체 종류 수, 20 이하 |
| 씬 전체 드로우콜 | 80 이하 |
| 지형 빌드 시간 | 150ms 이하 (M1 기준). 넘으면 Web Worker로 |
| 프레임 | 60fps (내장 GPU 노트북) |
| 메모리 | 맵 1장 버퍼 20MB 이하, 캐시는 최근 2장 |

## 데이터 모델

```ts
/** 칸 종류 — 기존 + r 돌바닥 · x 막힘 */
export type TileKind = 'g' | 'p' | 's' | 'w' | 'r' | 'x' | '^' | 'v' | '<' | '>';

/** 표시 글자 */
export type TileMark = '.' | 'A' | 'B' | 'C' | 'D' | 'E' | 'F' | 'G' | 'H'
  | '1' | '2' | '3' | '4' | '5' | '6' | '7' | '8' | '9' | '@' | 'b' | 'a' | 'n' | 'V';

export interface ObjectPlacement {
  type: string;   // 'tree-oak' (에셋 id)
  x: number;      // 칸 좌표 (소수 가능)
  z: number;
  rot: number;    // y축 회전(라디안). 코드와 같음
}

export interface TileMapData {
  id: string;
  heights: string[];
  kinds: string[];
  marks: string[];             // '.' 없음
  objects: ObjectPlacement[];
  colors?: Partial<Record<TileKind, string>>; // 맵별 바닥 색
}

/** 청크 하나의 화면 메시 */
export interface TerrainChunk {
  cx: number; cz: number;      // 청크 번호
  buffers: Pick<TerrainBuffers, 'positions' | 'normals' | 'colors' | 'indices'>;
}

export const CHUNK_SIZE = 32;          // 칸
export const SEA_SKIP_DISTANCE = 2;    // 땅에서 이 칸 수 넘게 떨어진 물 칸은 바닥 생략
```

## 단계 (MVP → 이후)

1. **MVP**: `marks` 레이어 + 출구·도착점·시작점 읽기. 가장자리 투명벽. 테스트 섬 → 첫걸음 섬으로 재활용.
   - 수용 기준: 출구 글자로 `MapExit` 영역 자동 계산. 육지 가장자리에서 밖으로 못 나감.
2. 청크 분할 + 바다 칸 생략. 144맵 1장으로 성능 목표 측정.
3. PNG → `TileMapData` 변환 스크립트. `objects` 인스턴싱.
4. 강·폭포, 다리(물 위 걸을 수 있는 칸), 지도 편집 도구(집짓기 배치 도구 재사용, [Housing.md](Housing.md)).

## 열린 질문

- 층이 10개 넘게 필요한가(고원)? — 제안 기본값: 0~9 유지. 구름 고원은 맵 전체 기준층을 올리지 않고 상대 높이로 그림.
- 본 맵 원본 형식? — 제안 기본값: 설계도(`MapBlueprint`, 코드 진행 중). 손그림 필요하면 PNG, 에디터는 4단계.
- `x` 막힘 칸 모양? — 제안 기본값: 풀 바닥 + 위에 덤불 물체 자동 배치.
