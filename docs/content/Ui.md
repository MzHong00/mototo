# 화면 (UI)

> 화면 흐름, HUD, 메뉴, 알림. 게임 화면을 가리지 않는 작고 둥근 파스텔 UI.

## 확정 사항

- 첫 흐름: 캐릭터 만들기 → 작은 시작 맵(첫걸음 섬) → 본 맵 ([World.md](World.md)).
- 미니맵과 지도가 있다. 지도는 3D 느낌 + 지하철 노선도처럼 깔끔 ([World.md](World.md)).
- 키는 고정하지 않는다. 키 설정 화면은 자판 그림에 기능을 끌어다 놓는 방식 ([Controls.md](Controls.md)).
- 외형은 장비를 "외형 칸"에 등록 ([Character.md](Character.md)).

## 규칙과 수치

### 화면 흐름

```
[부팅] → 저장 있음? ─아니오→ [캐릭터 만들기] → [첫걸음 섬 도착 연출]
              └─예→ [게임] (마지막 맵·위치)
[게임] ⇄ [메뉴 창들] (게임은 계속 돌되 입력만 막음)
[게임] → [맵 이동 페이드 0.3초] → [게임]
```

- 타이틀 화면은 MVP에 없다. 바로 게임으로. (설정은 게임 안 메뉴에서)
- 하루 첫 접속이면 게임 진입 직후 나날빛 팝업 ([Nanalbit.md](Nanalbit.md)).

### HUD 배치 (1280×720 기준)

| 위치 | 요소 | 크기 | 비고 |
| --- | --- | --- | --- |
| 왼쪽 위 | 닉네임 + 나날빛 테두리, 체력 바 | 240×56 | 마을(안전 지대)에선 체력 바 흐리게 |
| 오른쪽 위 | 미니맵(원형) + 시각·날씨 + 맵 이름 | 지름 160 | 클릭하면 지도 |
| 아래 가운데 | 스킬 4칸(A~D) + 빠른 칸 8칸(소비 아이템) | 칸 48 | 각 칸에 배치된 키 글자 표시 ([Controls.md](Controls.md)) |
| 오른쪽 아래 | 메뉴 버튼 줄 (가방·장비·기술·스킬·주민·지도·설정) | 아이콘 40 | 각 버튼에 단축키 표시 |
| 왼쪽 가운데 | 알림 토스트 스택 | 폭 280 | 아래 참조 |
| 캐릭터 위 | 상호작용 안내 "[F] 말 걸기" (배치된 키 글자) | — | 가까운 대상 1개만 |
| 화면 위 가운데 | 보스 체력 바 | 폭 50% | 보스방에서만 |

- 전투맵이 아니면 스킬·빠른 칸은 절반 투명(마우스 올리면 진하게).
- HUD 전체 숨기기 키(스크린샷용). 기본 배치 없음, 키 설정에서 지정.

### 메뉴 창

| 창 | 내용 | 관련 문서 |
| --- | --- | --- |
| 가방 | 칸 격자, 분류 탭, 정렬, 골드 | [Items.md](Items.md) |
| 장비 | 장비 칸 ↔ 외형 칸 두 줄, 가운데 캐릭터 미리보기(회전) | [Character.md](Character.md) |
| 기술 | 기술 목록(분류 탭) + 레벨·경험치 바 + 다음 해금 | [Skills.md](Skills.md) |
| 스킬 | A~D 콤보 4단 조립: 단계별 변형 카드 고르기 | [Combat.md](Combat.md) |
| 지도 | 노선도 지도, 방문한 마을 역 → 빠른 이동 | [World.md](World.md) |
| 주민 | 주민 목록, 호감도 하트, 생일 | [Npc.md](Npc.md) |
| 키 설정 | 자판 그림 + 기능 아이콘 끌어 놓기 | [Controls.md](Controls.md) |
| 설정 | 음량, 그래픽 품질, 카메라, 언어, 저장 내보내기 | [Audio.md](Audio.md), [Save.md](Save.md) |

- 창은 한 번에 1개(오른쪽 패널). 같은 단축키 다시 누르거나 Esc로 닫기.
- Esc: 열린 창 닫기 → 없으면 설정 창.
- 정지 규칙(통일): 창이 열리면 이동 입력 무시.
  - 마을·필드: 게임 시간은 흐름. 단 **설정·키 설정 창은 정지**.
  - **전투맵 안: 어떤 창이든 정지** (1인 게임, 덜 가혹한 쪽. World의 "지도 열면 적 공격 안 함"을 단순화).

### 대화창

- 화면 아래 1/4. 주민 이름 + 표정 아이콘 + 글자 하나씩 나오기(초당 40자, 클릭하면 전부).
- 입력칸 + 빠른 선택지 3개 ([Npc.md](Npc.md)). LLM 대기 중엔 "…" 말풍선.

### 알림 토스트

| 종류 | 예 | 표시 시간 | 색 |
| --- | --- | --- | --- |
| 획득 | "사과 ×3" (아이콘) | 2초 | 기본 |
| 기술 레벨업 | "낚시 Lv.12" | 3초 + 효과음 | 기술 분류 색 |
| 해금 | "새 머리 모양 해금!" | 4초 | 강조(금색) |
| 호감도 | "미라와 친구가 되었어요" | 3초 | 분홍 |
| 경고 | "가방이 가득 찼어요" | 3초 | 주황 |

- 최대 4개 쌓임. 같은 아이템 획득은 1초 안이면 합쳐서 수량만 증가.
- 큰 일(직업 해금, 보스 처치)은 토스트 대신 화면 가운데 배너 2초.

### 공통 규칙

- 글꼴: 둥근 한글 글꼴 1종(OFL, 예: 지마켓 산스·나눔스퀘어라운드 중 라이선스 확인).
- 최소 글자 14px, 버튼 최소 40×40.
- 색은 디자인 토큰만 사용 (`src/styles/_semantic.scss`). 하드코딩 금지 (AGENTS.md).
- UI는 R3F 캔버스 위 DOM(React)으로. 3D 안에 그리는 건 이름표·말풍선만.
- 모바일·터치·게임패드는 나중 (화면 비율만 미리 고려: 최소 1024×600).

## 데이터 모델

```ts
type Screen = "create" | "game"; // 기존 uiStore
type MenuPanel = "bag" | "equip" | "skills" | "combo" | "map" | "npcs" | "keys" | "settings";

interface UiState {
  isEditing: boolean; // 기존: 꾸미기 화면
  openPanel: MenuPanel | null; // 열린 메뉴 창
  dialogNpcId: string | null; // 대화 중인 주민
  isHudHidden: boolean; // HUD 숨김
  toasts: Toast[]; // 알림 스택
}

interface Toast {
  id: string;
  kind: "gain" | "levelUp" | "unlock" | "affinity" | "warn";
  text: string;
  iconId?: string; // 아이템·기술 아이콘
  count?: number; // 합쳐진 수량
  expiresAt: number; // ms
}

const TOAST_RULES = {
  MAX_STACK: 4,
  MERGE_WINDOW_MS: 1000,
  DURATION_MS: { gain: 2000, levelUp: 3000, unlock: 4000, affinity: 3000, warn: 3000 },
} as const;
```

## 단계 (MVP → 이후)

1. **MVP**: HUD(닉네임·체력·상호작용 안내), 토스트, 가방 창, 설정 창(음량). Esc 규칙.
   - 수용: 아이템을 주우면 토스트가 뜨고 1초 안 연속 획득은 합쳐진다. 창이 열린 동안 캐릭터가 안 움직인다.
2. 미니맵 + 지도 창, 대화창, 기술 창.
3. 장비 창(외형 칸), 스킬 조립 창, 키 설정 창.
4. 주민 창, 보스 체력 바, HUD 숨기기.
5. 모바일 터치 HUD.

## 열린 질문

- 메뉴가 열려도 시간이 흐를까? — 정리됨: 마을·필드는 흐름(설정·키 설정만 정지), 전투맵 안은 정지.
- 미니맵 모양 원형 vs 사각? — 제안: 원형(아기자기).
- 빠른 칸 수 — 정리됨: 소비 8칸(키 1~8, Controls 데이터 모델) + 스킬 4칸. 가방 칸과 분리.
- 타이틀 화면 필요? — 제안: MVP 없음, 출시 전 추가.
