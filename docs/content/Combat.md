# 전투

## 전투 직업 (숨겨진 해금)

- 처음엔 직업이 없다. 모험 중 **숨겨진 조건**을 채우면 전투 직업이 해금된다.
- 해금 조건 방식은 미정.

## 콤보 스킬

- 스킬 개수는 **최대한 적게**. 대신 스킬 하나가 **4단 콤보**다.
- 예: 검사 기본형 스킬을 `A`키에 등록 → `A`를 누를 때마다 A1 → A2 → A3 → A4 순서로 나간다.
- 각 단계(A1~A4)마다 **2개 이상의 변형** 중 하나를 골라 **나만의 기본형 콤보**를 조립한다.
- 이후 B, C, D 스킬을 차례로 해금한다. 각각도 4단 콤보 + 단계별 변형.
