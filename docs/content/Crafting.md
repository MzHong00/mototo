# 제작

> 제작대에서 레시피대로 재료를 써서 물건을 만든다. 요리·목공·재봉·제화·세공·염색·제련이 같은 규칙을 쓴다.

## 확정 사항

- 모든 성장은 기술 ([Skills.md](Skills.md)). 제작하면 그 제작대 기술 경험치.
- 외형 전용 아이템은 없다. 옷·신발·모자는 **능력치 있는 장비**로 만들고, 외형 칸에 등록해 모습만 바꾼다 ([Character.md](Character.md)).

## 규칙과 수치

### 제작대

| id | 제작대 | 기술 | 만드는 것 | 시작 위치 |
| --- | --- | --- | --- | --- |
| `workbench` | 작업대 | 목공 | 가구, 도구(도끼·곡괭이·낚싯대), 무기, 판자 | 첫걸음 섬·마을 |
| `stove` | 조리대 | 요리 | 회복·강화 음식 | 마을 |
| `sewingMachine` | 재봉틀 | 재봉 | 천, 상의·하의·한벌·망토 | 첫걸음 섬 |
| `cobblerBench` | 제화대 | 제화 | 신발, 가죽 손질 | 마을 (제화 첫 의뢰 후) |
| `jewelBench` | 세공대 | 세공 | 원석 다듬기, 모자·안경·장신구 | 마을 (세공 첫 의뢰 후) |
| `dyeVat` | 염색통 | 염색 | 염색약, 장비 물들이기 | 마을 |
| `furnace` | 용광로 | 채광 | 주괴 ([Mining.md](Mining.md)) | 마을 |
| `mirror` | 거울대 | 미용·분장 | 머리·얼굴 스타일 적용 (아이템 아님) | 집 |

- 제작대 2m 안에서 상호작용 키 → 제작 창. 제작대 자체도 목공으로 만들어 집·마을에 놓을 수 있다.

### 레시피 얻기

1. **레벨 도달**: 기본 레시피 대부분. 자동 해금.
2. **도안**(아이템): 상자·엘리트/보스 전리품·주민 의뢰 보상·상점. 쓰면 영구 해금. 레벨이 모자라면 "Lv25부터 배울 수 있어요".
3. **발견**: 처음 보는 재료를 얻으면 그 재료가 들어가는 레시피 1개가 "?" 로 목록에 보임 (힌트).

### 제작 진행

- 제작 창: 레시피 목록(제작 가능 먼저) → 개수 선택(최대 99) → 제작.
- 시간: 개당 1~5초. 진행 바 + 손 모션. 이동하면 일시정지, 다시 오면 이어감.
- 재료는 **시작할 때가 아니라 1개 완성될 때마다** 소모. 중간 취소해도 손해 없음.
- 실패 없음. 대신 **품질**이 갈린다.
- 재료는 가방 + 창고에서 같이 꺼내 쓴다 (아무 마을 안이면, [Items.md](Items.md)).

### 품질

| 품질 | 장비 능력치 | 음식 회복·지속 | 판매가 |
| --- | --- | --- | --- |
| 보통 | ×1.0 | ×1.0 | ×1.0 |
| 좋음 ★ | ×1.1 | ×1.2 | ×1.25 |
| 훌륭 ★★ | ×1.2 | ×1.4 | ×1.5 |
| 최상 ★★★ | ×1.35 | ×1.6 | ×2 |

- 확률: `gap = 내 Lv − 레시피 Lv`. 좋음 이상 `min(60%, 10% + gap×1.5%)`, 훌륭 이상 그 1/3, 최상 그 1/10.
- 품질은 **제작한 장비·음식에만**. 재료·가구는 품질 없음 ([Items.md](Items.md)의 희귀도와 별개).

### 경험치

- 레시피마다 `baseXp`. 레벨 차 감쇠는 [Skills.md](Skills.md) 규칙.
- 처음 만드는 레시피는 경험치 ×3 (다양하게 만들게).

### 외형 기술 특수 규칙

- **재봉·제화·세공**: 결과물은 장비. 처음 손에 넣는 순간 그 모양이 **옷장 도감**에 등록된다 → 외형 칸에 쓸 수 있다.
- **염색**: 염색약 1개 + 장비 1개 → 그 장비의 색 1부위 변경. 색 계열은 나날빛 단계로, 색 수(밝기·채도 변형)는 염색 Lv로 열린다 ([Nanalbit.md](Nanalbit.md)).
- **미용·분장**: 거울대에서 해금된 스타일을 고르고 헤어 크림/화장품 1개 소모. 이미 써 본 스타일로 돌아가는 건 무료.
  - 경험치: 새 스타일 첫 적용 30, 주민 머리 해주기 의뢰 50 ([Quests.md](Quests.md)).

```ts
type StationId = 'workbench' | 'stove' | 'sewingMachine' | 'cobblerBench' | 'jewelBench' | 'dyeVat' | 'furnace' | 'mirror';
type Quality = 0 | 1 | 2 | 3; // 보통·좋음·훌륭·최상

// ItemStack 은 Items.md 정의(quality 포함)를 쓴다

interface RecipeDef {
  id: string;                 // 'hoodie'
  skill: SkillId;
  station: StationId;
  minSkillLevel: number;
  needsBlueprint: boolean;    // 도안 필요 여부
  inputs: ItemStack[];
  output: ItemStack;
  craftMs: number;            // 개당 시간
  baseXp: number;
  hasQuality: boolean;
}

interface CraftJob {
  recipeId: string;
  total: number;      // 요청 개수
  done: number;       // 완성 개수
  elapsedMs: number;  // 현재 1개 진행 시간
}

interface CraftingState {
  knownRecipes: string[];      // 해금된 레시피
  craftedOnce: string[];       // 처음 제작 보너스 판정
  hintRecipes: string[];       // "?" 힌트
  wardrobe: string[];          // 옷장 도감 (장비 모양 id)
  unlockedStyles: { hair: string[]; face: string[] };
}
```

## 단계 (MVP → 이후)

1. **MVP**: 작업대·재봉틀, 레벨 해금 레시피, 개당 제작 시간, 재료 소모, 옷장 도감 등록.
   - 수용 기준: 목화 3 → 천 1, 천 3 → 긴바지. 긴바지를 처음 만들면 도감에 등록되고 외형 칸에서 고를 수 있다. 재료가 모자라면 버튼 비활성 + 부족 재료 빨간 글씨.
2. 조리대·용광로, 품질, 도안.
3. 제화·세공·염색·거울대.
4. 제작대 배치, 창고 재료 연동.

## 열린 질문

- 옷장 도감 등록 후 원본 장비를 팔아도 외형을 쓸 수 있나? — 정리됨: 예 (Character.md와 같음).
- 대장 기술 — 정리됨: 두지 않음. 무기·도구는 작업대(목공).
- 제작 실패를 둘까? — 제안 기본값: 없음, 품질만.
- 오래 걸리는 제작(맡겨 두기)이 필요한가? — 제안 기본값: 없음. 큰 가구도 5초 이내.
