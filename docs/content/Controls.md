# 조작

## 키 설정

- 기능을 특정 키에 고정하지 않는다. **키보드 자판 그림에 기능 아이콘을 끌어다 놓는** 방식으로 직접 배치한다 (메이플스토리 키 설정과 같은 방식).
- 배치 가능한 것: 이동·점프·달리기·상호작용, 스킬(A·B·C·D 콤보), 소비 아이템, 메뉴 열기
- 기본 배치: WASD·방향키 이동, Shift 달리기, Space 점프 (공격 키는 고정하지 않음 — 현재 J는 임시)

## 이동

- 걷기·달리기, 부드러운 가속·방향 전환
- 점프 약 1m, 공중에서 다시 점프 불가
- 경사로 오르내리기, 35cm 이하 턱은 자동으로 올라섬
- 떨어지면 시작 위치로 복구

## 카메라

- 고정 각도로 캐릭터를 따라온다
