# 게임 기획 개요

> 작업명 **모토토**. 브라우저에서 바로 즐기는 아기자기한 3D 생활 + 모험 게임.
> 새 프로젝트로 처음부터 시작. 이전 RPG 시도는 `~/Desktop/vsc/mototo-legacy`에 보관.

## 콘셉트

- **치비 캐릭터 커스터마이징**이 중심. 같은 몸체에 파츠를 갈아입는다. 전투 직업은 처음에 고르지 않고 숨겨진 조건으로 해금 ([Combat.md](Combat.md)).
- 세계: 작은 **첫걸음 섬** → 큰 본 맵 5개(고리로 연결, 마을 + 채집·낚시·광산·필드 구역) → 마을마다 **전투맵** 1개(갈래 방 그래프, 엘리트·보스방) ([World.md](World.md)).
- 채집·낚시·채광·전투로 재료를 모으고, 제작으로 장비·가구를 만들고, **마을과 집**을 철거·재건하며 꾸민다 ([Village.md](Village.md)).
- 매일 접속하면 **나날빛**(출석 색 레벨)이 물들어 간다. 우리 게임만의 특색.

## 플레이 형태

- **1인 게임**으로 만든다. 다인은 서버·동기화 기술이 커서 나중에 검토.
- 1인의 고립감은 AI 주민으로 채운다 ([Npc.md](Npc.md)).
- 모든 성장은 기술이다. 외형·마을·동물·전투 직업까지 기술로 해금한다 ([Skills.md](Skills.md)).

## 핵심 루프

```
접속 → 나날빛 +1 → 마을에서 준비 → 본 맵 구역·전투맵 탐험(채집·낚시·채광·전투)
     → 재료·기술 경험치 → 제작·판매 → 마을·집 꾸미기 / 외형 칸 꾸미기 → 주민과 대화 → 다음 날 접속
```
