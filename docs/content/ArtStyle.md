# 그림체

> 툰 음영 + 갈색 외곽선 + 파스텔. 치비 캐릭터와 둥글고 단순한 세계. 가볍게 그려서 브라우저에서 빠르게.

## 확정 사항

- 툰 음영, 외곽선, 파스텔 색 (구현됨: `src/engine/chibi/character.js`).
- 몸체 베이스 1개(`chibi_v9`) + 파츠. 파츠는 회색조 텍스처 × 틴트로 색 변경 ([Character.md](Character.md)).
- NPC도 같은 베이스 메시 커스텀 → 파츠 에셋이 매우 많이 필요 ([Npc.md](Npc.md), [AssetPipeline.md](AssetPipeline.md)).
- 외부 에셋은 CC0만(+ 직접 제작). 출처는 저장소 루트 `CREDITS.md` 한 곳에 모은다.
- 성능 최우선: 드로우콜 최소, 인스턴싱 ([Terrain.md](Terrain.md)).

## 규칙과 수치

### 음영·외곽선 (현재값 기준)

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 재질 | `MeshToonMaterial` + 4칸 램프(185·205·245·255) | 그림자 쪽도 밝게 → 파스텔 유지 |
| 외곽선 | 뒤집은 껍데기(BackSide), 색 `#5a3a32`(진갈색) | 검정 금지: 부드러운 인상 |
| 외곽선 두께 | 몸 0.012, 머리카락 0.009~0.010 | 단위 m(노멀 방향) |
| 세계 물체 | 같은 램프 재질. 외곽선은 캐릭터·주민·몬스터·상호작용 물체만 | 지형·나무 외곽선 없음(드로우콜 절약) |
| 그림자 | 캐릭터 발밑 둥근 그림자 원판(가짜) | 실시간 그림자는 해 1개, 낮은 해상도(1024) 선택 옵션 |
| 조명 | 반구광(하늘·땅) + 방향광 1개 | 낮·밤은 색만 바꿈 ([Time.md](Time.md)) |

### 치비 비율

| 항목 | 값 |
| --- | --- |
| 키 | 약 2.5~3등신 (머리 높이 ≈ 키의 35~40%) |
| 캐릭터 키 | 약 1.1m (층 높이 1.2m보다 작게 → 절벽이 "벽"으로 느껴짐) |
| 손·발 | 작고 둥글게, 손가락 표현 최소 |
| 눈 | 얼굴 폭의 30% 이상. 텍스처로 표현 |
| 주민·몬스터 | 같은 등신. 보스만 2~4배 크기 |
| 소품·가구 | 실제보다 약간 크고 두툼하게(문 높이 1.6m, 의자 0.5m) |

### 색 팔레트 원칙

- **채도 중간·명도 높음**(HSL 기준 S 35~65%, L 60~85%)이 기본. 순수 원색 금지.
- 배경(지형·나무)은 캐릭터보다 채도 낮게 → 캐릭터가 눈에 띔.
- 맵마다 주색 1개 + 보조 2개 ([World.md](World.md) 분위기와 맞춤):

| 맵 | 주색 | 보조 |
| --- | --- | --- |
| 첫걸음 섬 | 모래 베이지 | 하늘색, 연두 |
| 에버그린 | 연두 | 나무 갈색, 크림 |
| 블루 코브 | 하늘색 | 흰색, 산호 |
| 단풍골 | 주홍 | 노랑, 진갈색 |
| 구름 고원 | 연보라 | 흰색, 연녹 |
| 달빛 호숫가 | 남색 | 은색, 연노랑 |

- 위험·적 표시는 채도를 올린 빨강·보라 계열로만 → 평화 구역과 구분.
- 캐릭터 꾸미기 팔레트는 `src/constants/character/chibiPalette.ts`를 기준으로 하고, 나날빛 염색약 색 계열을 더한다 ([Nanalbit.md](Nanalbit.md)).
- UI 색은 디자인 토큰(`src/styles/`)에서만.

### 폴리곤·텍스처 예산

| 대상 | 삼각형 | 텍스처 | 재질 수 |
| --- | --- | --- | --- |
| 캐릭터(몸+파츠 전체) | 15,000 이하 | 파츠당 512² (얼굴 1024²) | 6 이하 |
| 주민 1명 | 캐릭터와 같음, 15m 밖은 LOD 50% | 같음 | 같음 |
| 일반 몬스터 | 3,000 | 256~512² | 2 |
| 엘리트 / 보스 | 6,000 / 15,000 | 512² / 1024² | 3 / 4 |
| 나무·바위 | 300~1,500 | 공용 팔레트 텍스처 1장 | 1 (인스턴싱) |
| 건물 | 1,000~4,000 | 공용 아틀라스 | 1~2 |
| 가구 | 100~800 | 공용 팔레트 텍스처 | 1 |
| 화면 전체 | 30만 이하 | GPU 메모리 256MB 이하 | 드로우콜 150 이하 |

- 세계 소품은 **팔레트 텍스처 1장**(색 칸 UV) 공유 → 같은 재질로 인스턴싱.
- 형식: glTF(`.glb`), Draco 또는 meshopt 압축, 텍스처 KTX2 (2단계부터).

### 에셋 규칙

| 규칙 | 내용 |
| --- | --- |
| 라이선스 | **CC0만**(+ 직접 제작 `Own`). CC-BY 허용 여부는 열린 질문. NC·ND·출처 불명 금지. 통일 이유: AssetPipeline·Audio·GameDesign이 CC0 기준 |
| 기록 | 들여올 때마다 루트 `CREDITS.md`에 한 줄: 이름, 작가, 라이선스, URL, 받은 날, 수정 여부. 파이프라인 `parts/CREDITS.txt`(동기화되어 `public/chibi/parts/`)도 여기에 옮겨 적는다 |
| 위치 | `public/assets/<분류>/<이름>.glb`, 원본은 `assets-src/`(빌드 제외) |
| 이름 | `camelCase` (예: `treeOakA.glb`) |
| 변환 | 크기 1단위 = 1m, 바닥 원점, +Z 앞, 재질은 툰 램프로 교체 |
| AI 생성 | 학습 데이터·이용 약관 확인. 상업 이용 가능한 도구만 ([AssetPipeline.md](AssetPipeline.md)) |
| 베끼지 않기 | 다른 게임 캐릭터·UI·로고 모양 그대로 금지 ([GameDesign.md](GameDesign.md)) |

- CC0 출처 후보: Kenney(소품·건물), Quaternius(나무·동물·몬스터), Poly Pizza(CC0 필터), VRoid 샘플(CC0, 머리카락 — 이미 사용 중).

## 단계 (MVP → 이후)

1. **MVP**: `CREDITS.md` 만들기(VRoid 머리 포함 기존 에셋 기록). 에버그린 나무·바위 3종을 팔레트 텍스처 + 인스턴싱으로.
   - 수용: 에버그린 화면에서 드로우콜 150 이하, 삼각형 30만 이하(`renderer.info`로 확인).
2. 맵별 팔레트 적용, 몬스터 3종 예산 안에서.
3. KTX2·meshopt 압축, 주민 LOD.
4. 낮·밤 조명 색표.

## 열린 질문

- 지형·나무에도 외곽선을 넣을까? — 제안 기본값: 안 넣음(성능). 상호작용 물체만 가까울 때 외곽선.
- 실시간 그림자 기본 켬? — 제안: 끔(가짜 원판). 설정에서 켬.
- 외곽선 색을 물체마다 다르게? — 제안: MVP는 진갈색 1개.
- CC-BY 에셋도 허용? — 제안 기본값: 안 함(CC0만). 꼭 필요한 에셋이 생기면 `CREDITS.md` 표기 조건으로 허용.
