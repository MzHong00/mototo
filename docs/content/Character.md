# 캐릭터 생성 (Phase 15)

게임 첫 진입 시 직업 선택 → 닉네임 입력의 2단계 플로우.

## 직업 선택 (Step 1)

4종 직업 카드를 hover하면 해당 직업 색상으로 강조 표시되고, 클릭 시 Step 2로 진입.

| 직업   | 클래스 색상 |
| ------ | ----------- |
| 전사   | `#FF6633`   |
| 궁수   | `#33BB55`   |
| 마법사 | `#5BA3FF`   |
| 도적   | `#AA44FF`   |

## 닉네임 입력 (Step 2)

- 2~12자, 한글·영문·숫자 허용 (`/^[a-zA-Z0-9가-힣]{2,12}$/`)
- 실시간 유효성 검사 + Enter 키 확인
- 닉네임은 `gameStore.selectClass(cls, name)` 으로 영속 저장
