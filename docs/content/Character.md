# 캐릭터 생성 (Phase 15)

게임 첫 진입 시 클래스 선택 → 닉네임 입력의 2단계 플로우.

## 클래스 선택 (Step 1)

4종 클래스 카드를 hover하면 해당 클래스 색상으로 강조 표시되고, 클릭 시 Step 2로 진입.

| 클래스 | 색상 |
| ------ | ----------- |
| 전사   | `#FF6633`   |
| 궁수   | `#33BB55`   |
| 마법사 | `#5BA3FF`   |
| 도적   | `#AA44FF`   |

## 닉네임 입력 (Step 2)

- 2~12자, 한글·영문·숫자 허용 (`/^[a-zA-Z0-9가-힣]{2,12}$/`)
- 실시간 유효성 검사 + Enter 키 확인
- 닉네임은 `gameStore.selectClass(cls, name)` 으로 영속 저장

## 성장 시스템

| 항목         | 값                                      |
| ------------ | --------------------------------------- |
| 만렙         | **50**                                  |
| 필요 경험치  | `레벨 × 100` EXP (Lv.1→2: 100, Lv.49→50: 4900) |
| 레벨업 보상  | 최대 HP +20 · 기본 ATK +3 · 스킬 포인트 +1 |
| 만렙 도달 시 | 경험치 획득 중단, 경험치 바 100% 고정  |
