# 모토토 (Mototo)

> 브라우저 기반 3D RPG — 아기자기한 모험

---

## 세계관

**모토토(Mototo)** 세계에서 벌어지는 모험 이야기.
평화롭던 **에버그린**에 불길한 기운이 퍼지고,
바다 너머 **블루 코브**, 단풍빛 **단풍골**에도 수호자들이 잠들어 있다.

> 계층 구조: **세계(모토토) → 지역 → 필드**

## 펫 시스템 (Phase 12)

### 알 획득

특정 맵 고정 위치에 알 오브젝트(`EggObject`) 배치. Space 키로 상호작용하여 획득.

| 등급   | 색상 | 부화 시간 | 배치 맵                  |
| ------ | ---- | --------- | ------------------------ |
| Normal | 흰색 | 30분      | 에버그린 초원            |
| Rare   | 파랑 | 2시간     | 에버그린 숲·늪지         |
| Epic   | 보라 | 6시간     | 에버그린 유적·왕 곰의 굴 |

## 경매장 시스템 (Phase 13)

MapleStory 자유시장 스타일의 **고정가 플레이어 간 거래 마켓**.

### 거래 방식

- 판매자가 아이템 + 가격 등록 → 구매자가 즉시 구매 (경매·입찰 없음)
- 로그인 없이 로컬 UUID로 신원 식별 (`auctionStore` zustand/persist)
- 매물 유효기간 7일, 일일 등록 한도 50건 (rate limit)

### 백엔드

| 항목     | 내용                                                   |
| -------- | ------------------------------------------------------ |
| 서비스   | Supabase free tier                                     |
| DB       | PostgreSQL — `auction_listings`, `transactions` 테이블 |
| API      | `@supabase/supabase-js` 브라우저 직접 호출 (서버리스)  |
| 실시간성 | 폴링 30s + Visibility API (탭 비활성 시 중단)          |

### 주요 기능

| 탭          | 기능                                                  |
| ----------- | ----------------------------------------------------- |
| 전체 시장   | 매물 목록 + 아이템타입/직업/등급/가격범위 필터 + 구매 |
| 내 등록     | 내가 올린 매물 조회 + 취소                            |
| 내 거래내역 | 구매·판매 완료 이력                                   |
| 시세        | 아이템별 최근 50건 평균·최저·최고가 + 거래 건수       |
