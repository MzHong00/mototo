# 모토토 (Mototo)

> 서울에서 치비로 한 번의 인생(0~100살)을 사는 브라우저 3D 게임 (1인)

- 부모 직업으로 시작 재력, 어린 시절 이벤트로 능력치가 쌓인다.
- 실제 직업·돈·주식·연애·친구. 인생이 끝나면 리포트와 업적.
- 맵은 서울 지하철역 단위, 길 구조는 실제와 같게.

## 시작하기

```bash
npm install
npm run dev
```
