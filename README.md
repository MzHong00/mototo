# 모토토 (Mototo)

> 브라우저 기반 3D RPG — 아기자기한 모험

---

## 세계관

**모토토(Mototo)** 세계에서 벌어지는 모험 이야기.
평화롭던 **에버그린**에 불길한 기운이 퍼지고,
동쪽 깊은 곳에는 강력한 수호자가 잠들어 있다는 소문이 돈다.

> 계층 구조: **세계(모토토) → 지역 → 필드**
