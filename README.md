# 모토토 (Mototo)

> 브라우저에서 즐기는 아기자기한 3D RPG

---

## 소개

**모토토**는 React + Three.js 기반의 브라우저 3D RPG입니다.
평화로운 세계 **모토토**를 탐험하며 몬스터를 물리치고, 펫을 키우고, 아이템을 수집하는 모험을 담습니다.

---

## 기술 스택

| 분류      | 기술                                |
| --------- | ----------------------------------- |
| 렌더링    | Three.js · React Three Fiber · Drei |
| 물리      | Rapier (React Three Rapier)         |
| 상태 관리 | Zustand                             |
| 스타일    | CSS Modules · SCSS                  |
| 빌드      | Vite · TypeScript                   |

---

## 시작하기

```bash
npm install
npm run dev
```
