# 모토토 (Mototo)

> 치비 캐릭터로 즐기는 브라우저 3D 생활 + 모험 게임

혼자 즐기는 게임입니다. 모든 성장은 **기술**(생활·외형·마을·전투 직업)로 이루어지고, AI로 사람처럼 사는 주민들과 함께 마을을 철거·재건하며 꾸밉니다. 매일 접속하면 **나날빛**이 물들어 갑니다.

## 시작하기

```bash
npm install
npm run dev
```
