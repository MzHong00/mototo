# 모토토 (Mototo)

> **서울에서, 치비로, 단 한 번의 인생을.**
> 태어나서 최대 105살까지 — 브라우저에서 바로 하는 3D 인생 시뮬레이션 (1인용)

부모를 고르는 순간 인생이 시작됩니다. 어떤 동네에서 자라고, 어떤 학교를 다니고, 무슨 일을 하며, 누구와 살아갈지는 내 선택과 약간의 운에 달려 있어요.
의사가 될 수도, 100억 부자가 될 수도, 노숙자가 됐다가 다시 일어설 수도 있어요. 인생이 끝나면 **인생 리포트** 한 장과 **업적**이 남고, 다음 인생은 처음부터 다시 시작합니다.

> 🚧 개발 초기 단계예요. 지금은 캐릭터 만들기·꾸미기와 임시 맵에서 걸어 다니기까지 돼요. 아래 내용은 대부분 [기획서](docs/plan/index.md)에 있는 목표예요.

## 이런 게임이에요

### 🍼 태어남부터
- **부모 직업 2개와 외모를 고르면** 집안 재력, 사는 동네, 집(원룸~고급 아파트), 시작 능력치가 정해져요.
- 아기 땐 집 안을 기어다니고, 어린 시절 선택이 **지능·힘·체력·매력·손재주·감성** 6가지 능력치로 쌓여요.
- 어린 시절은 직접 보내도 되고, 카드 몇 장으로 1년을 넘겨도 돼요.

### 🎓 진짜 같은 진로
- 학교 → 수능 → 대학 → 병역 → 취업. 한국의 실제 인생 경로를 따라가요.
- **실제 직업 32개** (의사·간호사·교사·소방관·개발자·요리사·미용사·광부·택배기사·유튜버·연예인 …). 해금 없이 누구나 도전할 수 있지만, 의사가 되려면 의대 6년과 국가고시를 거쳐야 해요.
- 연봉은 대부분의 사람이 다니는 **중소·중견기업 기준**의 현실적인 숫자예요.

### 💰 돈과 삶
- 월급, 생활비, 세금, 국민연금까지 **실제 금액 그대로**.
- 월세 → 전세 → 내 집 마련. 동네마다 집값이 달라요.
- 가게를 차리거나, 가상 회사 주식을 사거나, 빚에 쫓기다 파산할 수도 있어요.

### 💞 사람들
- 가족, 친구, 동료, 연인 — 모두 호감도가 있고, 중요한 순간엔 AI와 진짜 대화를 나눠요.
- 연애, 결혼, 자녀. 부모님도 나이 들고 언젠가 떠나요.
- 연예인·유튜버가 되면 팬이 생겨요. 목표는 팬 1억 명.

### 🚇 서울이 무대
- **지하철역 하나 = 맵 하나.** 길 구조는 OpenStreetMap 실제 도로를 따라요.
- 첫 버전은 **2호선 51역**. 지하철을 타고 동네 사이를 오가요 (요금도 실제처럼 1,550원).
- 강남·홍대입구·신림… 동네마다 분위기와 집값이 달라요.

### 📜 인생이 끝나면
- 재산·능력치 그래프, 주요 사건, 묘비 문구가 담긴 **인생 리포트**.
- "의사 되기", "100억 부자", "노숙에서 재기", "천수(105살)" 같은 **업적 51개**.
- 인생 여러 개를 동시에 진행하고, 끝난 인생끼리 비교할 수 있어요.

## 시간이 흐르는 법

| | |
| --- | --- |
| 게임 하루 | 실제 24분 (1초 = 1분) |
| 나이 | **게임 하루 = 1살** |
| 한 인생 | 보통 배속, 평균 수명 기준 약 27시간 |
| 접속 안 할 때 | 시간이 멈춰요 |

## 시작하기

```bash
npm install
npm run dev        # 개발 서버
npm run check      # 포맷 + lint + 빌드
npm run maps:check # 맵 검사
```

## 기술

React 19 · Three.js · React Three Fiber · drei · Rapier · Zustand · Vite · TypeScript · SCSS Modules
캐릭터는 Blender 파이프라인으로 만든 치비 몸 하나에 머리·옷·신발 파츠를 갈아입혀요.
