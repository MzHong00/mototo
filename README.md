# 모토토 (Mototo)

> 치비 캐릭터로 즐기는 브라우저 3D 생활 + 모험 게임

치비 캐릭터를 꾸미고, 마을에서 뻗어 나간 갈래길에서 채집·낚시·채광·전투를 하고, 집을 꾸미며 매일 **나날빛**을 물들여 갑니다.

## 시작하기

```bash
npm install
npm run dev
```
